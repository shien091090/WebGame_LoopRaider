# 美術經驗提案(LoopRaider polish 第 3 輪)

## 提案 1: 合併到「與規格的分界 / 交付自查」中「介面對同一個函式給了兩條互相打架的尺寸約束」那條(魂匠守衛者 polish-6 起頭), 收窄它的判準

- 再現 + 判準修正(LoopRaider polish 第 3 輪建置設計判斷, 非老闆回饋): 開始畫面依試玩回饋「動畫離提示字太近」縮小上移, 規格同時寫「環道半徑約 210、窗直徑約 72、中心 (640,300)」與「整組動畫含窗的光暈限制在 y 54~552」; 頂端窗上緣 300 − 210 − 36 = 54 剛好貼界線, 窗的外框、被掃到時的光暈與彈跳一加就超出 → 原條判準「以描述物件本身的那條(半徑、尺寸)為準」在這裡會選錯: 尺寸寫的是「約」, 界線才是這輪回饋要保證的事(拉開與字的距離), 照尺寸畫等於沒修到回饋 → **判準改成: 先看哪一條是這輪回饋 / 防遮擋要保證的版位或距離, 那條優先, 另一條寫「約」的尺寸讓步縮小**(該作: 環道 200、窗 70、光暈只外擴 8px、彈跳 1.06 倍; 實測上緣 54.5); 兩條都不是回饋保證時才回到原判準(以物件尺寸為準)。照舊在 style.md 判讀約定寫明偏離哪條、改成多少, 回報裡也講。前例(LoopRaider polish 第 2 輪, 同一方向): 解鎖特效「角色放大至多 2 倍」vs「頭頂 ≥ y 64」, 美術以位置為準放大到 1.45 倍並寫進 style.md, 製作人下一輪照實作把介面改成 1.45 倍——兩次都是位置約束勝出且被製作人採納(不掛理念: 屬交付流程; 玩家看到的後果是 P12 / P1 的遮擋)

## 提案 2: 新增到「交付自查」

- 介面本輪把攻擊預告與特效改成「端點 / 範圍由 RD 截在牆面再傳, 美術照給的畫、不自行延伸」(LoopRaider polish 第 3 輪, 起因是試玩 bug「攻擊預告穿牆、懸空」; 本條為建置自查, 非老闆回饋, 預防性) → 上一版的瞄準準星、俯衝十字以端點為**中心**畫、衝撞道的前進箭頭只擋到端點前 6px 但箭頭本身長 7px、粗線的圓頭線帽也會凸出端點半個線寬; RD 把端點截在牆面後, 這些裝飾仍各凸進牆裡 1~12px, 看起來還是「穿牆」, 而外接框量測若只看線段端點抓不到 → 凡是「畫在端點上」的記號(準星、十字、箭頭、圓頭線帽), 一律以「記號外緣 = 端點」往回退畫, 線只畫到記號為止; 自測對每種端點型投影量外接框, 斷言沿線方向不超過端點(容差 < 1px)〔P2〕
