# 音效經驗提案(LoopRaider polish 第 5 輪音效 build)

## 提案 1 → 放進「事件設計」, 新增一條

- `辨識` **規格要「倒帶般的重生 / 復原」約 1.4 秒的音, 跟前面的「碎裂」成對, 只把碎裂聲反轉會有中段空洞** → 碎裂聲只有 0.5 秒, 反轉後擺在結尾, 前面 0.9 秒只剩反轉低鐘很輕的開頭(量得中段 −55~−58 dB, 等於無聲), 聽起來是「靜了一下才突然吸回去」 → 用同一組碎裂層**反轉、時間倒排**收在事件點前 0.03 秒(碎掉 → 倒帶回來, 一聽就成對), 再墊一層週期性的棘輪 / 捲動聲(例: Kenney Interface Sounds 的 `scroll_003`, 每 20 毫秒一響)用變速重新取樣從 0.6 倍加速到 1.9 倍、音量由 −12 dB 線性(dB)漸強, 當「越轉越快」的倒帶; 加上降速的上揚掃音給音高往上爬。驗收看 20 毫秒包絡從開頭一路爬升沒有凹洞(本例約 −50 → −28 dB 再到碎片峰值)、每 60 毫秒音高往上(408 → 544 Hz)。變速取樣讀來源時位置對長度取模, 週期性素材天生可以無限延長。(LoopRaider polish 第 5 輪 build, 聽感待試玩)

## 提案 2 → 放進「素材來源」, 新增一條

- `辨識` **教學 UI 要「羊皮紙卷軸攤開」「卡片一張張排上」「大木板落定」這類紙張 / 木板動作音, Kenney 的 Interface Sounds 只有電子感的按鈕音** → 介面包偏合成音, 跟木作 / 書本風格的遊戲不搭 → Kenney「Casino Audio」(CC0, `https://kenney.nl/assets/casino-audio`)的紙牌錄音很好用: `card-fan-1`(0.72 秒逐漸變密的紙張沙沙)降速 0.85 倍 = 厚羊皮紙攤開; `card-slide-*` = 卡片滑入; `card-shove-1` 降速 0.7 倍 = 大木板滑動摩擦(開頭有 0.1 秒輕前奏, 跳過才會立即出聲)。搭 Kenney「RPG Audio」的 `bookPlace3`(13 毫秒到峰值一成的「嗒」)當翻頁確認、`bookClose` 當「收好」, 全部同一家質感。同一事件連續觸發(四張卡依序排上)時, 在 sound.js 對間隔 < 0.8 秒的同名呼叫每次升 2 個半音, RD 不用多傳參數就有節奏感。(LoopRaider polish 第 5 輪 build, 聽感待試玩)
