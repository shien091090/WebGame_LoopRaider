# 音效經驗提案(LoopRaider polish 第 4 輪音效)

## 提案 1 → 放進「技術」分類, 新增一條

- `辨識` **規格把攻擊冷卻拿掉(每按一次播一次、快手每秒 8~10 下), 要「可快速連播不糊、不爆音」** → 一般連發音的做法是同名各自疊著播(不切掉前一聲), 但揮砍這類峰值高(本例 −3 dBFS)的短音在 0.05 秒內連兩下時, 兩聲的起音疊在一起可能超過 0 dBFS; 反過來硬切前一聲(`src.stop()`)會有喀聲 → 先量素材有效長度(10 毫秒包絡掉到 −30 dB 的時間, 本例 0.10 秒), 比連按間隔(0.1~0.125 秒)短就不換素材; 執行時對這類事件加「choke」: 新一聲起時, 同名前一聲的 GainNode 從目前值 15 毫秒線性淡到 0 並排程 stop, 再配同名 0.05 秒限頻, 同時最多一聲在響。只對峰值高、會被快速連按的事件開, `hit` / `arrow` 這類背景連發音仍疊著播。冒煙測試用假 AudioContext 驗: 0.1 秒間隔兩下都有 start、前一聲有 ramp 到 0 與排程 stop、0.02 秒內第二下被限頻。(LoopRaider polish 第 4 輪 build, 瀏覽器實測待試玩)
