# 音效經驗提案(LoopRaider polish 音效 build)

## 提案 1 → 放進「素材來源」分類(新條目)

- `辨識` **一套遊戲要十幾個「成功 / 失敗 / 獲得」樂句, 還要聽得出是同一家族, 逐支挑樂句很難湊** → 不同包的樂句調性、樂器各異 → Kenney「Music Jingles」(CC0, `https://kenney.nl/assets/music-jingles`)的 Pizzicato / Steel / Sax / 8-Bit 四種樂器, **同編號是同一段旋律**(每 80 毫秒自相關量音高走向, 四種樂器一致): 02 = 0→+10 半音的完整上揚(約 1 秒)、10 = +2→+7 上揚、08 = +2→+4 短上揚(未收尾)、01 / 14 = 下降、03 = 原地。用法: 「目標出現」用 08、「達成」用 02、「失敗」用 14, 大事件把同編號的撥弦 + 鋼鼓兩分軌疊在一起; 換樂器不換旋律就能區分事件(例: 解鎖用鋼鼓 10、獲得道具用薩克斯 10)。注意 Sax 起音 40~90 毫秒, 疊一層同編號撥弦(−8 dB)當起音; Hit 系列不是旋律(音高量不到), 不適用。(LoopRaider polish 音效 build, 聽感待試玩)

## 提案 2 → 合併到「技術」分類「壓低原因變多」那條的(續)

- (續)規格只給一個 `pause` 事件、開與關都呼叫, RD 從暫停面板選「重來 / 回大地圖」離開時常不再呼叫一次 → 只靠切換會讓音樂卡在一半 → `pause` 收 `opts.on`(true / false), 省略時才切換; 另把「只有遊戲在跑才會出現的動作音」(跳、揮砍、受傷、敵人出招等)列一張表, 壓低中聽到這些音且距離設定已過 0.15 秒就自動解除, 當 RD 漏呼叫的保險。冒煙測試加一條「暫停後不呼叫關閉、直接播跳躍音 → 音量回滿」。(LoopRaider polish 音效 build, 瀏覽器實測待試玩)

## 提案 3 → 放進「技術」分類(新條目)

- `辨識` **換曲後舊曲沒停, 在背景以音量 0 一直播** → 淡出邏輯寫成「音量往下減的那一步減到 0 才暫停」, 但曲子剛開始淡入(淡入量還是 0)就被換掉時, 不會進入「往下減」的分支, 永遠不會暫停; 冒煙測試在換曲前沒推進計時器才抓到 → 淡入淡出計時器每一步都檢查「目標是 0 且目前是 0 且還在播」就暫停, 不綁在遞減分支裡。冒煙測試要涵蓋「播了馬上換曲」與「init 前就呼叫過 playMusic」兩種。(LoopRaider polish 音效 build)

## 提案 4 → 合併到「混音與音量」分類(新條目)

- `辨識` **整批背景音樂統一響度時, 安靜的曲子(鋼琴 / 弦樂)被峰值卡住拉不上來** → 本例 Eternal Hope 原響度 −26.8 dB, 拉到 −18 要 +8.8 dB, 但峰值只容許 +4.4 dB → 背景音樂不做限幅(會把鋼琴的起音壓扁), 先照峰值上限輸出, 不足的部分記下來, 在 `sound.js` 的每首曲子音量欄位補回(本例基準 0.45, 安靜曲 × 10^(差值/20) 到 0.75), `<audio>` 的 volume 上限 1, 所以基準要留空間。sound.md 寫實際量到的響度。(LoopRaider polish 音效 build, 聽感待試玩)
