## LoopRaider polish 第 3 輪 RD 提案(製作人審過再併進 rd-lessons.md)

- [放進「自測」或新分類「戰鬥 / 判定」; 與第 72 條(方向判定)同類] (投射物碰牆爆炸後, 貼著牆的目標全被判成「被牆擋住」、炸不到自己也炸不到怪; 或規格的水平帶 ±N 比身高大, 平地上整條帶被地板擋成寬度 0) → (1) 投射物碰到實心格的當幀位置已經在牆裡, 拿它當爆心做「爆心到目標連線穿牆」的遮擋判定, 第一格就是實心; (2) 規格的帶高(±40)大於玩家身高的一半(18), 用帶高逐格找牆會把腳下地板 / 頭頂天花板也當牆 → 碰牆時爆心退回進入實心格之前的最後一個自由點, 遮擋線另跳過起點格與目標格; 帶狀範圍找牆只看身體高度內的格(判定範圍本身仍用規格的帶高), 並在回報註明; 用 vm 測「貼牆丟扣血、平地不扣血、隔牆不扣血、平地帶寬 = 規格寬」
- [放進「Canvas / 渲染」; 合併到「區域型投影 / 特效用 clip 扣掉實心格」] (用「畫面矩形 + 所有實心格 evenodd clip」避免紅圈畫進牆裡, 結果貼地的橢圓 / 裂縫被地板切掉一半) → (美術把貼地圖形畫在頂面上緣附近, 地板頂面那一排格也被整格扣掉) → 頂面外露的格(上方不是實心)只從頂面往下 5px 起扣, 側面外露的牆格整格扣; 另外縮圖重用時 clip 的實心格表要依錄影那一幀的裂岩牆狀態與目前修復狀態重算, 不能讀即時關卡的實心表(回放時它是 null)
