# 玩法驗證文件

## 核心玩法(使用者指定, 每款都必須有)
- 2D 橫向平台跳躍動作, 關卡內有怪物、可撿的素材, 玩家有攻擊與技能可用
- 關卡很短、很快能通關; 通關條件只有「走到終點」
- 通關後在大地圖(關卡選擇畫面)看到該關不斷回放剛才的通關流程, 回放到撿素材的瞬間持有數 +1(平台動作 × 放置)
- 至少 3 種職業, 技能與擅長不同 → 通關過程不同; 關卡內有只有某些職業到得了的地方、只有某些職業能觸發的機關 → 各職業的回放產出類型或數量不同
- 素材用途: 解鎖職業(共 3 個, 開局只能用 1 個)、解鎖下一關、其他(自由發想)
- 核心體驗 1「規劃路線、挑戰速通」: 回放產出速度 = 這趟素材 ÷ 這趟時間, 每趟權衡多撿 vs 跑快, 並利用職業差異找最有效率路線
- 核心體驗 2「越賺越快」: 完成的關卡越多, 同時回放產出的關卡越多
- 不要的體驗(暫定): 純放置、不用操作
- 探索範圍: 3 個以上短關卡 + 大地圖回放 + 素材解鎖下一關與職業
