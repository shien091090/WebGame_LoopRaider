# 玩法驗證文件

## 核心玩法(使用者指定, 每款都必須有)
- 2D 橫向平台跳躍動作, 關卡內有怪物、可撿的素材, 玩家有攻擊與技能可用
- 關卡很短、很快能通關; 通關條件只有「走到終點」
- 通關後在大地圖(關卡選擇畫面)看到該關不斷回放剛才的通關流程, 回放到撿素材的瞬間持有數 +1(平台動作 × 放置)
- 至少 3 種職業, 技能與擅長不同 → 通關過程不同; 關卡內有只有某些職業到得了的地方、只有某些職業能觸發的機關 → 各職業的回放產出類型或數量不同
- 素材用途: 解鎖職業(共 3 個, 開局只能用 1 個)、解鎖下一關、其他(自由發想)
- 核心體驗 1「規劃路線、挑戰速通」: 回放產出速度 = 這趟素材 ÷ 這趟時間, 每趟權衡多撿 vs 跑快, 並利用職業差異找最有效率路線
- 核心體驗 2「越賺越快」: 完成的關卡越多, 同時回放產出的關卡越多
- 不要的體驗(暫定): 純放置、不用操作
- 探索範圍: 3 個以上短關卡 + 大地圖回放 + 素材解鎖下一關與職業

## 已確認的體驗
### 想要
- 打怪掉素材帶來的取捨: 略過怪直接吃場地素材, 還是花時間打怪多賺(explore-1 A)
- 多種素材: 從升級 / 解鎖條件發現自己缺什麼, 有策略地規劃怎麼過關(explore-1 B)
- 一關只留一條回放, 靠「選哪個職業 + 走哪條路線」客製化該關的產出種類與產出速度; 例: 選弓手多賺素材 A, 還是選法師多賺素材 B(explore-1 A、B)
- 職業差異要明顯: 專屬技能觸發不同機關、體型 / 高度決定能走的路(explore-1 A、C); 自動攻擊、衝刺斬這類攻擊方式做成個別職業的特色, 不要全職業共用(explore-1 B、C)
- 角色差異的做法: 擅長某事的角色比較容易 / 比較快達成目標, 其他角色也做得到但要多花時間(例: 有的角色跳得高、快速到高處, 其他角色要多跳幾個平台); 小捷徑、多拿一點的專屬路線可以(explore-1 A、explore-2)
- 戰鬥以 explore-2 A 為標竿: 職業攻擊方式與怪物行為的設計都比其他款好(explore-2 A)
- 怪物要有血量, 要花一點心力策略性地與之戰鬥(explore-2 B)
- 擊退造成連鎖(打出去的怪撞傷別隻)做成某一職業的技能(explore-2 C)
- 重跑時在結算畫面自己選留新的還是舊的(explore-2 A)
- 關卡上有可以裝東西的格子; 想要的改版: 關卡內放寶箱開出道具 → 道具裝到關卡的附魔格(名稱可換)產生不同效果, 可拔下改裝到別的格子, 花素材擴充格數, 讓關卡探索更有目標(explore-2 C)
- 每種素材有專屬用途, 有「某一種素材就是拿來做某種事」的感覺(explore-2)
- 關卡各有特色(explore-2 A)
- 過了 2、3 關後回大地圖, 感覺素材越賺越快(explore-1)
- 大地圖回放每得 1 素材, 就從該關畫面中被吃到的素材位置飛出素材特效、飛進上方資訊列的數量; 過關越多、越多素材在飛, 不斷收穫的即時回饋感(explore-2 深掘需求)
- 素材有更多花用的地方(回放加速器, explore-1 C)
- 回放要完整重演整個過關流程, 怪物與擊殺都要還原(explore-1)
- 怪物要有更多不一樣的行為(explore-1)
- 關卡至少 8 關; 大地圖上關卡區塊要小, 關卡間樹狀連結, 不同路線解鎖的關卡各不相同(explore-2 深掘需求)
- 先選關卡、再選職業(explore-2 深掘需求)
- 操作: 空白鍵 = 跳躍、Z = 攻擊、X = 技能(explore-1)

### 不要
- 殘影干擾畫面(explore-1 A)
- 一關由每個職業各自進去拚速通(explore-1 B)
- 素材單一, 選職業沒有策略性(explore-1 A)
- 怪物戰鬥沒特色、行為單一(explore-1)
- 踩頭踩一下怪就死掉的戰鬥(explore-2 B)
- 讓玩家為了拚獎勵什麼都不撿、直接衝終點的限時獎勵(explore-2 B)
- 整片區域只有某個角色進得去, 其他角色完全做不到(explore-2 B)
- 每關統一分成三層的固定結構(explore-2 A)
- 素材感覺只是三種不同錢幣、沒有各自用途(explore-2 三款)

## 機制清單
### 保留
- 擊倒怪物掉素材(H08)
- 素材產出效率 = 這趟素材 ÷ 這趟時間, 多撿 vs 跑快的取捨(H02)
- 每過一關多一條同時進行的回放(H03)
- 職業專屬技能 / 機關 / 路線, 換職業 = 換路線與產出; 限小捷徑、多拿一點的專屬路線, 或「擅長的職業較快、其他職業多花時間也做得到」(H04、H22)
- 素材解鎖職業與下一關; 解鎖用多種素材的配方(H05、H17)
- 職業決定產出的素材種類(一關一條回放下)(H15)
- 自動攻擊、衝刺斬: 只當某一職業的特色(H13、H19)
- 三職業攻擊方式各異(近戰衝刺斬 / 自動射擊 / 拋物投彈)(H54)
- 四種怪物行為: 衝撞、正面持盾、遠程射擊、跳躍(H34)
- 擊飛連鎖: 限某一職業的擊退技能(H45)
- 關卡格子改造、自選裝什麼(H46、H47)
- 結算由玩家選留新或舊的那趟(H25)
- 回放加速器(H23)
- 自動保留效率較高的那趟: 僅限單一素材; 使用者已決定改多素材後不沿用(H10)
- 短關卡、初見不熟 → 卡卡的就想重跑(H31)

### 避開
- 殘影對手同場重跑(H26)
- 職業差異只落在素材數量(單一素材)(H27)
- 每關每職業各留一條回放(H28)
- 怪物只有巡邏 / 飄浮的單一行為(H29)
- 回放只重現玩家、不重演怪物與擊殺(H30)
- 跳躍不在空白鍵的按鍵配置(H32)
- 踩頭一下就擊倒、怪物沒有血量(H49)
- 標準時間內過關拿金章加成(H50)
- 整片區域只有單一角色進得去(H51)
- 每關統一分三層的固定結構(H52)
- 所有素材只混在同一張解鎖價目表、沒有專屬用途(H53)
