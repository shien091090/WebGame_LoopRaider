# 符石迴廊 — 美術風格 (deepen-1 / game-a)

> RD 只讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文會亂碼。
> 所有函式掛在 `window.Art`, 參數固定 `(ctx, state)`(`drawBackground` / `drawMapBackground` / `drawFailPanel` 只用 ctx), 每個函式自己 save/restore。美術照 1280×720 設計座標畫, 不自己乘縮放。

## 1. 邏輯畫布尺寸

`Art.canvas = { width: 1280, height: 720 }`(= interface.json, 固定寬, 沒有依裝置變寬)。頂端資訊列 y 0~40。

## 3. 形狀語言

扁平幾何、圓角; **玩家白輪廓、怪物深色輪廓 + 紅眼**, 場景物件無輪廓平塗; 每種素材 / 符石一個固定剪影, 在地上、資訊列、卡片、面板、飛行素材裡同一個樣子。

## 4. 理念落實

- **P0 辨識度先於好看**: 素材三種靠剪影 + 色相(圓木棕 / 四芒星紫 / 六角晶青)分; 裂岩牆用斜角磚 + 黑裂痕, 和五種地形的平塗內部手法不同; 背景壓低對比, 不做裝飾動畫。
- **P1 視覺權重跟決策迫切度走**: 黃色 `select` 只給「現在按 Z 會發生的事」(選取框、Z 提示、可解鎖的鎖); 符石座範圍圈是細虛線半透明, 只有裝著符石時加強; 背景、遠山、地圖等高線最暗。
- **P2 規則上存在的東西畫面上要存在**: 符石座 100px 觸發範圍圈常駐畫(空座很淡、封印不畫), 預覽上的回放路線能直接看出有沒有穿過範圍圈; 寶箱開過畫成灰暗空箱; 加速等級畫在卡片縮圖徽章與面板。
- **P3 一個意義一種長相**: 職業色同時用在玩家衣服、頭像、回放路線、HUD 技能鍵框; 時晶青色 = 加速器(徽章、倍率); 符石座上的符石、背包、獲得提示、結算、HUD 共用同一個 `runeIcon`; 說明頁直接呼叫遊戲內畫家。
- **P4 關鍵區分至少兩條通道**: 敵我 = 輪廓色(白 vs 深)+ 紅眼; 蜂彈(紅圓點、無方向)vs 箭(細長、有羽); 爆炸(暖色實心火球)vs 震波(冷白空心環 + 外推短線); 五種符石 = 框色 + 紋章形狀(嫩芽 / 爪痕 / 泉滴+素材)。
- **P7 每個元素要掙得版面**: 符石座只在面板畫號碼, 關卡內不畫號碼字; 縮圖不畫字; 卡片文字區只放名稱、秒數、三個產量; 面板右側選中座的詳情只有一份。
- **P9 以最混亂的那一刻驗收**: 文字一律帶深色描邊; 怪物全有深色外框, 疊在任何地形主題上都分得出; 擊飛中的怪帶白色速度線, 在一串怪裡也看得出誰在飛。
- **P13 事件要排隊**: 「獲得 <符石名>」固定在上方一條, 浮字只在拿到的位置; 美術不另加同時跳出的橫幅。
- **P15 回饋強度和份量成正比**: 撿素材 = 小浮字; 擊倒 = 煙; 連鎖 = 大黃字彈一下; 爆炸與震波 = 範圍等於判定半徑的大圖形。
- **P17 進度圖形與數字分工**: HUD 的技能冷卻只畫圖(鍵帽扇形, 滿了變亮), 不配秒數; 加成剩餘時間是條, 不重寫秒數。
- **P18 重要資訊不只一瞬間**: 「獲得符石」提示之外, HUD 常駐這趟開到的符石小圖示, 結算面板也寫「獲得 <符石名>」。
- **P19 資訊貼著物件**: 符石座的效果直接畫成座上立著的符石 + 同色範圍圈; 浮字冒在撿到的位置; 卡片產量就寫在該卡片下方。
- **P21 示意圖選對錯會分岔的例子**: 第 4 頁兩張圖用同一關、同一個起點與終點, 只有路線不同, 讓「繞路多拿 vs 直衝」是唯一差別。

## 7. 版面細節與判讀約定

**資訊列**: 每格(x0 = 16 / 236 / 456)圖示中心 (36/256/476, 20)、持有數 x0+40(bump 時以左緣為錨放大至 1.3)、「+12.3/分」x0+112(綠)、用途小字 x0+190。`mode='level'` 右側由左到右: 職業頭像 714、技能鍵帽「X」732~756(冷卻中暗底 + 職業色扇形長滿, 好了變白底 + 職業色框)、愛心 774 起每顆 19px、秒數、這趟三種素材、這趟開到的符石圖示、加成(最多 4 個, 每個符石小圖示 + 剩餘時間條)。`buffs` 超過 4 個只畫前 4 個(介面規定)。

**關卡面板**: 照介面版位。面板底以 evenodd 挖空預覽框 (60,96) 640×360, 所以 RD 不論先畫預覽或後畫面板, 預覽都不會被蓋; 預覽框只畫外框。背包標籤「符石背包」小字在 (700,466) 右對齊。職業格 3 格各 150×120, 左上 x = 728 / 886 / 1044, y = 118。符石座 4 小格 58×58, 左上 x = 736 + 70i, y = 288; 選中座詳情在 y≈360~432。加速器三個倍率格 + 右側「下一級 [時晶] N  Z 購買」或「已滿」。回放資訊在 (720,574)。選中列 = 黃色 3px 外框 + 黃色列名; 非作用列中的選中格 = 淺灰框。

**擊飛方向**: 介面沒有給飛行方向, 美術約定 **flung 時的飛行方向 = −facing**(怪物多半面向炸彈工, 被往後打飛), 速度線畫在 facing 那一側框外。RD 若遇到怪背對炸彈工被打飛, 擊飛期間把 facing 設成「飛行方向的反向」即可畫對。

**canAfford**: `drawLevelCard` 吃布林; `drawGoalCard` 吃布林或 `{wood, ench, time}` 布林物件(物件時逐種標紅, 布林 false 時三種都標紅)。建議 RD 傳物件, 才能只標不足的那種。

**動態時間**: 無敵閃爍、選取框脈動、選取游標脈動用 `performance.now()`(state 沒給時間)。其餘動畫只讀 state 的 t / poseT。

**縮圖與預覽**: 關卡內函式在 0.125 / 0.5 縮放下照常可用; 縮圖的開放卡片(open)美術只畫縮圖區底色 `#232a44`, RD 疊靜止關卡。
