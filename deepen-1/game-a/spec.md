# 符石迴廊(路線符石: 回放經過符石座就觸發, 改裝立刻改寫舊回放)

## 概述
單畫面橫向平台動作, 8 個短關卡以樹狀連結在大地圖上。三職業(劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈 + 震波擊飛)各有擅長的地形; 四種怪物都有血量、都會主動移動。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖飛一顆素材進資訊列。
本款的新機制是**符石**: 關卡裡的寶箱開出符石, 符石裝在關卡的**符石座**上; 玩家(含回放裡的玩家)經過符石座就觸發加成。加成依「現在裝的符石」對錄影重新計算, 所以**改裝當下舊回放的產量就跟著變**, 不必重跑。符石座有的在主路上、有的在繞路上, 讓路線規劃多一層「繞去經過符石」的取捨。
三種素材各有一種專屬用途: **木材**開路(解鎖關卡、招募職業)、**符塵**解封符石座、**時晶**買回放加速器; 終極目標「凱旋門」三種都要。
驗證假設: H01、H18、H33、H55~H62

## 核心循環
大地圖看三種素材的產量缺哪種 → 選關卡 → 在關卡面板選職業(與調整符石)→ 進關打怪、撿素材、開寶箱、經過符石座、衝終點 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放產出、素材飛進資訊列 → 用木材開新關 / 招募職業, 用符塵解封更多符石座, 用時晶加速回放, 把符石搬到產量最需要的關 → 再挑一關去跑。

## 規則

### 關卡與錄影
1. 每關是不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、素材與寶箱都不入帳), 跳出失敗面板。
4. 這趟拿到的素材與寶箱道具只在過關時才入帳(不論結算時留新或舊, 都入帳)。
5. 素材 3 種: **木材**、**符塵**、**時晶**。地上的素材碰到即得 1; 擊倒怪物立即得到該怪的掉落(見數值表), 不落地。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、職業、面向、動作)、每隻怪物(位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃)、所有飛行物(箭、炸彈、蜂彈)、爆炸、震波、已拿走的素材、裂岩牆血量、寶箱開關、擊倒煙。另記錄每次「基本得到素材」的時間點、位置、種類、數量(地上素材 / 怪物掉落, 不含符石加成), 與每隻怪被擊倒的時間點。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔); 怪物移動、攻擊、被擊飛、被擊倒都照錄影重現。每播到一個得到素材的時間點, 持有的該種素材 + 該數量(含符石加成, 見規則 17)。
8. 回放在大地圖、關卡內、各面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。該關每種素材的每分鐘產量 = 一圈內該種素材總數(含目前符石加成)÷ 錄影秒數 × 60 × 加速器倍率(小數 1 位)。
10. 開局: 素材全 0, 只開放第 1 關與劍士, 背包沒有符石。

### 大地圖
11. 8 張關卡卡片依樹狀排列(版位見「大地圖版位」), 連線: 1→2、1→3、2→4、2→5、3→6、3→7、5→8、6→8。上分支(2、4、5)多高台與寬坑, 下分支(3、6、7)多怪物與裂岩牆。
12. 卡片狀態: **封鎖**(連到它的前一關都還沒過關; 畫鎖與花費, 不能買)、**可解鎖**(至少一個前一關已過關; `Z` 花木材解鎖)、**已開放**(未過關)、**已過關**(縮圖重演回放、下方顯示三種素材每分鐘產量)。第 8 關的前一關是 5 或 6, 任一過關即可解鎖。
13. **素材飛行**: 大地圖畫面(沒開任何面板)時, 回放每得到 1 個素材, 就從縮圖裡該素材被拿到的位置(錄影位置 × 縮圖倍率 + 縮圖左上角)飛出一顆該種素材, 0.7 秒沿弧線飛進資訊列該種素材圖示, **飛到時持有數才 +1**, 計數跳一下。一次得到 N 個就飛 N 顆(同時出發, 起點各自隨機錯開 ±6px; N > 5 時只飛 5 顆, 最後一顆帶剩下的數量)。開著面板或在關卡內時不飛, 直接 +。
14. 游標: `←` `→` 換到左 / 右一欄中垂直位置最接近的卡片, `↑` `↓` 在同一欄內上下移(到頭不動)。欄由左到右: 第 1 關 / 第 2、3 關 / 第 4~7 關 / 第 8 關 / 凱旋門。
15. 在卡片上按 `Z`: 封鎖 → 不反應; 可解鎖 → 木材夠就扣除並變成已開放, 不夠不反應; 已開放或已過關 → 打開**關卡面板**。在凱旋門上按 `Z`: 三種都夠就買下(勝利), 不夠不反應。

### 關卡面板(先選關卡、再選職業)
16. 面板分三列, `↑` `↓` 換列, 打開時在第 1 列; `X` 關閉回大地圖。左邊是該關的靜態預覽(初始地形、素材、怪物出生位置、寶箱、符石座; 已過關時加畫目前回放的路線線條), 下方是符石背包。
    - **職業列**: `←` `→` 在劍士 / 獵人 / 炸彈工間選, 預設是這關上次用的職業(沒有就是劍士)。選到已擁有的按 `Z` = 用這個職業進關; 選到未招募的按 `Z` = 木材夠就招募(扣除, 變成已擁有, 不進關), 不夠不反應。
    - **符石座列**: `←` `→` 選 1~4 號座, 預覽上的游標跟著移動。選到封印中的座按 `Z` = 符塵夠就解封(扣除), 不夠不反應。選到已解封的座按 `Z` = 換下一個符石, 依序「空 → 背包第 1 顆 → 第 2 顆 → … → 空」循環; 換到正裝在別處(別座或別關)的符石時, 直接從原處搬過來(原處變空)。
    - **加速器列**: `Z` = 時晶夠就買下一級(扣除), 已滿或不夠不反應。

### 符石(本款特有)
17. **符石座**: 每關 4 座(1~4 號, 位置固定)。1 號開局就解封, 2~4 號封印中, 可用符塵依任意順序解封(花費依「這關已解封幾座」, 見數值表)。每座最多裝 1 顆符石。
18. **觸發**: 玩家判定框中心進入符石座中心 100px(外緣)內 → 該座的符石觸發, 每座每趟(回放每圈)只觸發一次。觸發時符石座亮一下。
19. **符石效果**(同一種可疊加: 兩個豐收符石的時窗重疊時, 每撿 1 個額外 +2):
    - **豐收符石**: 觸發後 4 秒內, 每撿到 1 個地上素材額外 +1 同種。
    - **狩獵符石**: 觸發後 6 秒內擊倒的怪物, 掉落 ×2。
    - **木泉 / 塵泉 / 晶泉符石**: 觸發瞬間得到該種素材 2(浮字冒在符石座上)。
20. **加成依現在的配置計算**: 回放每一圈都用「這一刻這關裝了哪些符石」重新判定: 錄影裡的玩家軌跡何時進入哪座的範圍、之後幾秒內有哪些基本得到素材與擊倒。改裝、搬走、解封後, 下一個觸發點起就照新配置算; 卡片與面板上的每分鐘產量立即更新。關卡內遊玩時同樣即時判定, 加成算進這趟。
21. **寶箱**: 每關 1 個, 內含固定的 1 顆符石(見關卡構成)。玩家碰到即打開, 畫面上方提示「獲得 <符石名>」, 過關時放進背包。拿過的寶箱之後的趟數都是打開的空箱。背包最多 8 顆(全遊戲就 8 個寶箱)。
22. 回放與預覽一律畫**目前**裝的符石(不是錄影當時的)。

### 結算
23. 過關時該關沒有回放 → 直接存成回放。已有回放 → 結算面板並列「這一趟」與「目前回放」的秒數與三種素材的每分鐘產量(兩邊都用目前的符石配置計算), `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
24. 玩家血量 3; 碰到怪物(被擊飛中的除外)或蜂彈扣 1, 之後無敵 1 秒並被往反方向彈開 80px。每次進關回滿。
25. **怪物**(四種行為, 全部會主動移動, 都有血量; 被擊倒時冒擊倒煙):
    - **野豬**(衝撞): 以 80px/秒左右巡邏, 撞牆或到平台邊緣回頭。玩家與它上下相差 40px 內、在它面向那側 240px 內 → 停下預備 0.5 秒 → 以 420px/秒朝原方向衝撞, 撞牆或到平台邊緣才停, 停下後暈眩 1 秒, 再回到巡邏。
    - **盾兵**(正面擋): 玩家在水平 400px 內且上下相差 120px 內 → 以 40px/秒朝玩家走; 否則以 40px/秒巡邏(撞牆或邊緣回頭)。不離開所在平台。從它面向那側打來的揮砍、箭、衝刺斬被盾擋下(不扣血, 盾閃一下); 從背後、或攻擊判定中心高於它頭頂時照常受傷。爆炸、震波、被擊飛的怪撞上來都不受盾影響。
    - **射手蜂**(射擊): 在出生點左右 120px 內以 60px/秒來回巡飛(碰到地形回頭), 同時上下飄 ±16px(週期 2 秒)。玩家在 400px 內時每 2 秒射一發: 停下瞄準 0.4 秒 → 朝玩家當下位置射出蜂彈(220px/秒直線, 碰到地形消失)。
    - **跳蛙**(跳躍): 每 1.2 秒跳一次(水平 120px、最高 80px), 落地蹲著等下一跳。玩家在 300px 內時朝玩家跳; 否則朝面向跳, 起跳前若落點沒有地面或是牆就先轉向。
26. **職業**(在關卡面板選; 攻擊 `Z`、技能 `X`; 三職業判定框都是 28×44):
    - **劍士**(開局): 移速 260。攻擊 = 面前揮砍(面向側 50×40, 1 傷害, 冷卻 0.3 秒)。技能 = **衝刺斬**: 朝面向衝 160px(0.18 秒, 期間無敵、不受重力, 沿途怪物受 2 傷害), 冷卻 1.2 秒; 衝刺斬擊倒怪物時冷卻立刻歸零; 空中可用, 每次離地只能用 1 次(落地恢復)。擅長: 跳起再衝刺斬跨過 6 格寬坑。
    - **獵人**: 移速 260。攻擊 = **自動射擊**: 每 0.6 秒自動朝 260px 內最近的一隻怪物射一箭(箭速 700px/秒, 飛向目標當下位置, 1 傷害), 射程圈常駐顯示; 另外按 `Z` 可手動朝面向水平射一箭(冷卻 0.4 秒, 飛 600px, 可打裂岩牆)。技能 = **抓鉤**: 220px 內有鉤環時, 以 700px/秒被拉到鉤環, 到達瞬間獲得向上 500px/秒的速度, 冷卻 0.5 秒; 範圍內沒有鉤環則不反應。擅長: 一下上到 5 格高的高台。
    - **炸彈工**: 移速 230。攻擊 = **投彈**: 朝面向拋出炸彈(初速水平 300、向上 500px/秒, 重力同玩家), 碰到地形或怪物即爆炸, 半徑 60px(外緣)內怪物受 2 傷害、裂岩牆直接碎掉; 冷卻 0.6 秒; 玩家不會被自己的爆炸傷到。技能 = **震波**: 以自己為中心半徑 130px(外緣)內的怪物受 1 傷害並被**擊飛**(規則 27), 範圍內的裂岩牆直接碎掉; 空中可用, 冷卻 1.5 秒。擅長: 破裂岩牆、打盾兵、把怪撞成一串。
27. **擊飛**(只有炸彈工的震波會造成): 被打中還活著的怪物朝「遠離炸彈工」的水平方向以 460px/秒飛出, 最多 0.6 秒或撞到地形為止, 期間不受重力、碰到玩家不傷人。
    - 擊飛中的怪碰到其他怪 → 對方受 2 傷害, 若還活著也被擊飛(方向相同)。同一次擊飛中每隻怪只會撞同一隻別的怪一次。
    - 擊飛中撞到地形 → 自己受 1 傷害, 擊飛結束。
    - 擊飛結束仍活著 → 落地(蜂回到飛行)後恢復原本行為。
28. **連鎖字**: 玩家的同一次攻擊(含它引發的擊飛碰撞)擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」。只是顯示, 不改掉落。
29. **裂岩牆**: 實心, 耐久 3。揮砍、箭、衝刺斬每次 -1; 炸彈爆炸或震波碰到直接碎掉。碎掉後消失(冒擊倒煙)。

### 物理(三職業共用)
30. 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格); 移速 260 全速跳躍水平約 156px(過得了 3 格寬的坑)。按住跳躍鍵短於 0.15 秒時初速減半(小跳)。地形為實心方塊, 沒有單向平台、移動平台。

### 擅長與替代路線(三職業都過得了每一關的每個地方)
31. 三種「擅長地形」每種都有不需技能的替代做法, 只是比較慢:
    - **高台**(離下方地面 5 格): 下方掛鉤環 → 獵人一下上去; 其他職業走旁邊的 3~4 段階梯平台(多花約 2~3 秒)。
    - **寬坑**(6 格寬, 坑底是低一層的小路, 不是尖刺): 劍士跳起 + 衝刺斬直接跨過; 其他職業下到坑底小路走過去、再爬階梯上來(多花約 2~3 秒)。
    - **裂岩牆**: 炸彈工一炸就破; 其他職業打 3 下。
32. 只有小捷徑或多拿一點的地方才放擅長地形; 不做整片區域只有某職業進得去。

### 素材用途(每種一種專屬用途)
33. **木材** = 開路: 解鎖關卡、招募職業。**符塵** = 解封符石座。**時晶** = 回放加速器(每關各自買)。**凱旋門** = 三種都要, 買下即勝利。

- 第 2 關起各放 2~4 個尖刺。
- **符石座位置**: 1 號在主路前 1/3、附近 4 秒路程內至少 3 個地上素材; 2 號在主路後段; 3 號在繞路上(高台、側洞或坑底小路); 4 號在一群怪物旁。四座中心彼此至少相距 240px(範圍不重疊)。符石座不擋路(畫在地面上, 不是實心)。
