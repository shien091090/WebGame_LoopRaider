> RD 注意: `index.html` 必須宣告 `<meta charset="utf-8">`, 否則 `art.js` 裡的中文在 file:// 下會變亂碼。

## 3. 形狀語言

扁平色塊 + 2px 深色描邊 + 圓角; 我方(玩家、箭)用職業色 + 白色元素, 敵方子彈與危險一律紅; 印記一律是「印記色圓徽章 + 白色符號」。

## 4. 理念落實(依 art-lessons.md 的成立理念)

- **P0 辨識度先於好看**: 四種怪物外形各異(橫長野豬 / 直立持盾 / 帶翅飛蜂 / 扁平蛙), 三種素材形狀不同(原木 / 墨滴 / 菱晶), 四種印記符號不同(爆星 / 碗裡滿出素材 / 三個身影 / U 形磁鐵)。大地圖縮圖以 0.125 倍重用關卡函式時, 玩家、怪物、素材、光環自動改畫高對比剪影(玩家 = 整框職業色 + 白框), 細節不糊成一團。
- **P1 視覺權重跟著決策迫切度**: 關卡裡最亮的是會傷人的(紅蜂彈、紅刺尖)與帶印的怪(脈動光環); 背景山丘只用 55% 透明的低對比色。大地圖上「可解鎖」卡片的鎖是金色、「封鎖」卡片整張壓暗。
- **P2 規則上存在的東西必須可見**: 盾兵的盾永遠畫在面向側(擋哪一側一眼可見); 裂岩牆耐久用裂痕數表現(3 / 2 / 1); 印記配置與回放不同時卡片掛「重跑生效」、面板寫「下一趟進關才生效」; 背包每格寫裝在哪(「第3關 2號」/「未裝」)。
- **P3 一個意義一種長相**: 素材圖示在地上、浮字、資訊列、飛行素材、卡片、面板、結算全是同一個 `matIcon`; 印記圖示在光環頭頂、印位標記、面板、背包、獲得提示、結算全是同一個 `markGlyph`; 面板裡的職業頭像與印位怪物小圖示直接呼叫遊戲內的 `drawPlayer` / 怪物函式。
- **P4 關鍵區分走兩條通道**: 爆炸(實心火球、橘)vs 震波(空心環 + 往外箭頭、白藍)vs 磁吸波(空心環 + 往內箭頭、藍): 填色 / 方向都不同。寶箱 關(木色 + 金鎖 + 閃光)vs 開(褪色、蓋子翻後、沒有鎖)。終點旗 未到(黑白格)vs 已到(金旗 + 星)。印記四色色相兩兩差 ≥ 60°, 再加符號形狀。
- **P7 每個元素掙得版面**: 擊飛的方向不另畫箭頭(身體傾斜 + 速度線已表達); 卡片產量列不加「/分」字樣(版面不夠, 資訊列與面板已寫「/分」「每分」)。
- **P9 以最混亂的一刻驗收**: 所有角色都有深色描邊, 疊在爆炸 / 震波 / 光環上仍分得出輪廓; 浮字與連鎖字一律帶深色描邊。
- **P13 事件排隊**: 獲得提示固定在畫面上方中央(440,52), 不和關卡內的浮字 / 連鎖字搶同一塊。
- **P15 回饋強度和份量成正比**: 炸彈爆炸(半徑 60)只有火球; 爆裂印爆炸(半徑 140)多一圈爆裂印色外緣; 連鎖字(多隻)比 +N 浮字(單筆)大且彈跳。
- **P17 進度類圖形與數字分工**: 資訊列技能冷卻只用圖形(職業圖示上的暗色扇形 = 剩餘), 就緒時多一圈白環; 不重複寫秒數。
- **P18 重要資訊不能只閃一下**: 「獲得 <印記名>」除了 1.5 秒提示, 資訊列右端常駐這趟開到的印記圖示, 結算面板再寫一次。
- **P19 資訊貼著物件**: 印記圖示長在帶印怪物頭頂; 印位標記貼在預覽怪物頭上並有小三角指下去; 「重跑生效」貼在該卡片縮圖角上。
- **P21 示意圖選會分岔的例子**: 說明第 4 頁同一張關卡、同一批素材, 只有路線不同, 讓「繞路撿多 vs 直衝」的差別只剩路線。

**怪物共用規則**
- `hit=true`: 全身顏色往白色混 80%(閃白), 不放大。
- `minion=true`: **x, y 是跟班自己(0.75 倍)判定框的中心**; 美術以框底中心 (x, y + 0.75·h/2) 縮成 0.75 倍。
- `state='flung'`: 身體往後仰 0.38 弧度並縮成 0.74 倍(留在框內), 速度線 3 條畫在 **facing 那一側**框外 ≤ 40px。約定: 被打飛時怪物面向攻擊來源、往背後飛, 所以速度線在面向側。RD 若擊飛時要讓線在正確一側, 把 facing 設成「飛行方向的反方向」即可。
- 爆裂印的 0.3 秒爆炸預兆: 介面沒有對應的欄位, 本版光環不另畫預兆(怪物倒下後 RD 不再畫光環時就沒有)。

### 縮圖與預覽(RD 縮放重用)
- `viewScale = |ctx 變換的縮放| ÷ (ctx.canvas.width / 1280)`。**低於 0.3**(即大地圖縮圖的 0.125)時, `drawPlayer` 改畫整框職業色圓角方塊 + 白框, 四種怪物改畫本體色橢圓剪影 + 深框(擊飛時傾斜), `drawPickup` 放大到滿 24px, `drawMarkAura` 改成實心色橢圓; 高 DPI(`ctx.scale(devicePixelRatio)`)已扣掉, 不會誤判。
- 預覽 0.5 倍照一般畫法。

## 8. 判讀約定(介面沒寫死的部分)

- 怪物 `minion` 的 x, y = 跟班自己 0.75 倍框的中心(見第 5 節)。
- 擊飛速度線畫在 facing 側(見第 5 節)。
- `drawGoalCard.canAfford` 建議傳 `{wood, ench, time}` 布林物件(見第 5 節)。
- `drawLevelCard` 的 `canAfford` 只在 buyable 時使用; sealed 的花費一律白字(還不能買, 不判夠不夠)。
- `drawLevelPanel` 背包格的「高亮」是美術自己從 `items[i].where` 與 `index`、`slotSel` 比對出來的, RD 不用另傳。
- 閒置值: 介面的 xxT 閒置時 = xxDur, 美術照「已播完」處理(`drawHud` 的 bumpT = bumpDur 時不放大; 冷卻 skillCdT = skillCdDur 視為就緒)。
- 玩家 invuln 閃爍用系統時鐘(`performance.now`), 不需要 RD 傳時間。卡片選取框、印位游標的脈動也一樣。
