# 捷徑工坊 — 美術規格(deepen-1 / game-c)

RD 只讀這份即可接 `art.js`。所有函式掛在 `window.Art`, 每個函式自己 `save()/restore()`。函式名、參數、state 欄位與 `interface.json` 一對一, 沒有多也沒有少(另加說明頁 `drawGuidePage`)。

## 1. 邏輯畫布尺寸

`Art.canvas = { width: 1280, height: 720 }`(固定寬, 照 interface.json; 上一版沒有依裝置決定寬度的程式, 本版不加)。

## 3. 形狀語言

圓角、深色 `ink` 描邊、扁平填色; **玩家一律白色外框, 怪物一律深色外框 + 紅眼**; 只有尖刺用「一排朝上的尖角」, 其他任何有利物件(機關、素材、寶箱)都不用尖角或並排三角; 機關一律薄荷色。

## 4. 理念落實

- **P0 辨識度先於好看**: 四類物件各有類別層的長相 — 玩家(白框)、怪物(黑框紅眼)、機關(薄荷色)、素材(三種輪廓: 圓木 / 齒輪 / 菱晶); 寶箱關 = 金邊 + 閃光, 開 = 灰褐無金(已用掉)。
- **P1 視覺權重跟著決策迫切度**: 背景丘陵與天空低對比; 範圍圈(收集燈、獵人射程)只畫細線與 5% 淡染, 不遮圈內物件; 「獲得機關」提示固定在資訊列下方中段、不蓋關卡中央。
- **P2 規則上存在的東西畫面上就存在**: 收集燈畫出 200px 範圍(布置時看得到作用範圍)、疾風帶整條鋪出加速範圍並在兩端畫實心端點、機關座封印 / 已解封長得不同、失敗面板寫明「這趟的素材與寶箱不入帳」、暫停面板寫明「回大地圖時這一趟作廢」。
- **P3 一個意義一種長相**: 素材圖示在地上、資訊列、飛行、卡片、面板、結算全是同一個 `matIcon`; 機關圖示(背包、提示、結算、HUD、面板)是關卡內機關本體的縮小版; 職業色在玩家、頭像、回放路線一致; 薄荷色只代表機關(與疾風加速), 黃 `warn` 只代表「待重跑 / 可買」。
- **P4 關鍵區分走兩條通道**: 收集燈範圍圈 = 薄荷色長虛線; 獵人射程圈 = 淺綠圓點線(色 + 線型)。疾風加速 = 薄荷色波浪弧線; 衝刺斬 = 白色直線(色 + 形)。蜂彈 = 紅橘實心球; 箭 = 細長桿(色 + 形)。
- **P7 每個元素掙得版面**: 卡片已過關不再寫「已過關」(縮圖在動就是答案); 已擁有且未選中的職業格不寫「已擁有」(全彩頭像就是答案); 機關座小格不寫機關名(圖示就是)。
- **P9 以最混亂的一刻驗收**: 怪物群擠在一起被震波擊飛時, 速度線帶黑底白芯, 在任何底色上都看得到; 文字一律有深色描邊或深色底板。
- **P13 事件要排隊**: 本美術只負責單一提示的進退場(獲得提示 0.2 秒淡入、0.3 秒淡出); 同時多個事件的排隊由 RD 依規格時序控制, 美術不在提示裡疊多塊。
- **P15 回饋強度與份量成正比**: 「+N」浮字 18px 小圖示 < 「N 連鎖」24px 金字彈跳 < 「獲得機關」帶框橫條 < 過關結算整面板。
- **P17 進度圖形與數字分工**: 技能冷卻只有圖形(頭像上的剩餘扇形, 好了變薄荷色外環), 沒有數字; HUD 持有數只用數字。
- **P18 重要資訊不能只閃一下**: 寶箱開到的機關除了 1.5 秒提示, 也常駐在 HUD 右端(`itemThisRun`)與結算面板, 並進背包格。
- **P19 資訊貼著物件**: 「重跑生效」掛在該卡片縮圖右上角內側; 加速倍率徽章在縮圖左上角內側; 「下一趟進關才生效」掛在機關座列下緣。
- **P21 示意圖要選會分岔的例子**: 說明頁第 4 頁同一關兩條路線並排, 左圖素材已被拿走(頭上浮著三顆素材)、跳蛙化成煙, 右圖素材與跳蛙原封不動 — 讓「多撿 = 多繞」與「直衝 = 少拿」畫出不同的圖。

## 5. 判讀約定(RD 必讀)

- **座標**: 除寫「左上角」的函式外, `x,y` 都是判定框中心。
- **閒置值**: 所有 `xxT / xxDur` 在 `xxT >= xxDur` 時視為沒在播; 一次性特效(`drawTeleportFlash`、`drawExplosion`、`drawShockwave`、`drawPoof`、`drawPopup`、`drawChainText`、`drawItemNotice`)在 `t >= dur` 時不畫任何東西。
- **擊飛方向(重要)**: 介面只給 `facing`, 沒給飛行方向。本美術約定 **`state:'flung'` 時, 飛行方向 = −facing**(怪物面朝炸彈工、往背後飛出)。速度線畫在面向側框外至多 40px、身體往面向側傾。擊飛方向為「遠離炸彈工」, 所以 RD 在擊飛期間把怪物 `facing` 設成**朝向炸彈工**即可(多半就是牠原本的面向)。
- **震波 / 爆炸 / 範圍圈的 radius = 外緣**: 震波環的判定帶是 `[radius − 14, radius]`; 爆炸火球外緣 = radius; 收集燈虛線圈外緣 = radius(線寬 2 往內); 獵人射程圈外緣 = radius。
- **飛行素材拖尾方向**: 由該素材資訊列圖示座標(木材 (36,20)、齒輪 (256,20)、時晶 (476,20))自己算, RD 不必傳方向。
- **凱旋門 `canAfford`**: 介面要「不足的那種看得出」, 但若只傳一個布林, 美術分不出是哪一種不足。本函式接受兩種格式: `true / false`(false 時三個數字都畫紅) 或 `{ wood, ench, time }` 各自布林(只把 false 的那種畫紅)。**建議 RD 傳物件**。
- **職業格 `cost`**: 接受數字(木材數)或 `{ wood, ... }` 物件。
- **布林欄位只認 `=== true`**: `sealed`、`open`、`reached`、`lit`、`hit`、`invuln`、`windBoost`、`pending`、`selected`、`active`、`owned`、`canAfford*`。缺漏一律當 false(例: `sealed` 缺漏會畫成已解封)。
- **表外值的預設外觀**: `kind` → 木材、`type` → 彈跳台、`cls` → 劍士、`theme` → 草原、`pose` → idle、怪物 `state` → 第一個狀態(walk / fly / crouch)。看到不該出現的這些外觀, 請查傳入值。
- **有牆鐘動畫(`performance.now()`)的函式**: 寶箱閃光、玩家無敵閃爍與疾風弧線、卡片 / 凱旋門選取框脈動、機關座游標脈動; 位移都在框內。
- **畫面文字歸屬**: 照介面「每個繪圖函式自己畫它面板 / 卡片內的全部文字(含按鍵提示)」。以下提示字**已由美術畫, RD 不要再畫**: 關卡面板最下方「↑↓ 換列 ←→ 選擇 Z 確定 X 關閉」與各列的「Z 出發 / Z 招募 / Z 解封 / Z 換機關 / Z 加速」; 結算「Z 回大地圖」「Z 採用這一趟 X 保留舊的」; 失敗「Z 重來 X 回大地圖」; 暫停「Esc 繼續 Z 重來 X 回大地圖」/「Esc 繼續」; 結束「Z 重新開始」。大地圖最下方 y=690~714 的操作提示由 RD 畫(美術不畫)。
- **全畫面暗幕**: `drawLevelPanel`、`drawPausePanel` 依介面自帶暗幕; `drawResultPanel`、`drawFailPanel`、`drawEndingPanel` 也自帶一層淡暗幕(0.45~0.55), RD 不必另畫。

## 9. 繪製層級(由下到上)

關卡: `drawBackground` → 地面 / 尖刺 / 裂岩牆 / 鉤環 → `drawSocket` → `drawWindStrip` → 彈跳台 / 傳送門 / 收集燈 → 素材 / 寶箱 / 終點旗 → `drawRangeRing` → 怪物 → 玩家 → 箭 / 蜂彈 / 炸彈 → 爆炸 / 震波 / 擊倒煙 / 傳送閃光 → 浮字 / 連鎖字 → `drawHud` → `drawItemNotice` → 面板。
- 收集燈的範圍圈很大, 但它在怪物與玩家之前畫、只有 5% 淡染, 不會蓋住它們。
- 被擊飛的怪物照樣在玩家之前畫(擊飛期間碰到玩家不傷人, 不需要蓋在玩家上)。

大地圖: `drawMapBackground` → `drawMapLink` → `drawLevelCard` → (RD 縮圖) → `drawCardOverlay` → `drawGoalCard` → `drawFlyingMaterial` → `drawHud` → 面板。
