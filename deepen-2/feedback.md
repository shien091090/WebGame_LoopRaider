## 喜歡

### 修復後解鎖新區域 → 想回去重跑(三款共通)
- 三款修好東西後「都會想 因為會想去開寶箱 或是拿更多素材提高關卡DPS」 → 對應機制: A 工程修復 / B 巢穴打通 / C 建築重建, 修好開出新區域(寶箱、素材、怪物)。deepen-1「沒有重跑動機」的問題這輪解決了

### B 巢穴
- 「解鎖巢穴的設計不錯 可以改成部分關卡是這樣而不是全部關卡 且Boss打死應該要掉落更豐厚的獎勵」 → 對應機制: 打通地下通道開巢穴、巢口湧怪、修祭壇門出巢母。條件: 只放在部分關卡; 巢母(Boss)擊倒的獎勵要更豐厚

### 修復能開更快的路(A)
- 「如果關卡設計得當 修復一條可以更快通關的道路我覺得是不錯的」 → 對應機制: A 捷徑工程(條件見「不喜歡」的修復取捨)

### 底版傾向
- 「如果你要用哪一個當底來做打磨版的話 我會覺得可以用A」; 各款「各有一些可以保留的點」(見本檔各段)

## 不喜歡

### A 修復反而擋路、修 A 犧牲 B
- 「修好橋梁之後反而往下的路被擋住 導致要去下方撿素材要多繞路 修復反而給玩家負面體感」
- 「花素材修復不應該是修A跟修B 讓玩家必須犧牲其一 而是修越多對玩家來說越好 修A就會吃到A的紅利 修A+B就應該要吃到A+B的紅利」 → 對應機制: A 捷徑工程與寶區工程互斥(走捷徑錯過寶區入口)。推論: 修復只能加分不能減分, 修好的結構不能封住原有的路

### C 每關長得差不多
- 「C款每一關都長差不多 這個設計很糟 每一個關卡地形應該都要有差異才對」(同 H52 方向: 關卡要各有特色)

### C 建築決定道具格種類
- 「C款的關卡安裝插件放在廢墟上我覺得蠻沒必要的 畢竟插件提供的效果就是關卡結束後必定獲得的東西 跟是哪個廢墟完全無關」 → 對應機制: 道具格綁在建築上、建築種類決定能裝哪類道具。推論: 道具格放關卡上即可, 不必綁在場景物件

### B 連鎖掉落
- 「目前沒有把怪聚在一起清掉的手段 所以很無感 這個設計我覺得可以拿掉」 → 對應機制: 同一次攻擊連續擊倒掉落 ×2 / ×3。使用者要拿掉

### 尖刺即死(三款共通)
- 「有些關卡地形設計很糟, 例如兩個刺中間只有一個一格的小空地 稍微偏一點就即死 我覺得也可以保留這個設計沒關係 但刺要改成被刺到只會扣1hp 不會即死」 → 改: 碰尖刺扣 1 血(不即死), 窄落腳點可以保留

### 操作卡(三款共通)
- 「現在操作還是覺得很卡 應該要改成"上"鍵是跳才對」; 確認後: 「只用上鍵跳 空白鍵改成無作用」, 攻擊 Z、技能 X 不變
