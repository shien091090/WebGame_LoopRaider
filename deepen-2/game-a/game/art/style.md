# 重建之路 — 美術規格(deepen-2 / game-a)

> RD 只讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。
> 載入方式: `<script src="game/art/art.js"></script>`, 之後用全域 `window.Art`。
> 所有函式自己 `save()/restore()`; 美術照 1280×720 邏輯座標畫, 不自己乘任何縮放。

## 1. 邏輯畫布

`Art.canvas = { width: 1280, height: 720 }`(= interface.json, 固定寬, 沒有依裝置變寬)。

## 3. 形狀語言

圓角、粗深外框、扁平填色; **玩家 = 白外框, 怪物 = 深外框 + 紅瞳, 機關與地形無外框**; 尖角(並排三角)只留給尖刺。

## 4. 理念落實(經驗文件「成立」理念)

- **P0 辨識度先於好看**: 四種素材同時換形狀與色相(圓木 / 灰石塊 / 菱形水晶 / 魂火滴), 地上、資訊列、飛行素材、面板花費用同一個圖示函式; 堵塞亂石(深圓石 + 鐵箍、無裂痕)與裂岩牆(亮砂岩 + 裂痕)明暗相反。
- **P1 視覺權重跟著決策迫切度走**: 背景壓暗低對比; 會傷人的東西(尖刺尖、蜂彈、預警)用全畫面唯一的純紅; 卡片上的「新區域」是卡片層唯一脈動的徽章。
- **P2 規則上存在的東西, 畫面上就必須存在**: 未修斷橋 / 崩梯畫極淡藍圖虛線(看得到「這裡有東西可修」, 但不是實心); 盾兵的盾畫在面向側整片框內, 一眼看出哪側有盾; 花費逐項比對 stock, 不足的那種數字變紅 + 底線。
- **P3 一個意義一種長相**: 素材圖示、職業徽章、工程牌、道具圖示全部共用同一組內部畫法(面板裡的工程牌就是 drawSiteSign 縮 0.9); 「金框 = 選中 / 可行動」全畫面一致。
- **P4 關鍵區分至少走兩條感知通道**: 捷徑牌(藍 + 方板 + 雙箭頭)vs 寶區牌(金 + 菱形板 + 寶箱); 寶箱關(金框 + 閃光)vs 開(掀蓋 + 去飽和 + 黑內部); 震波(空心環 + 朝外 V 記號)vs 爆炸(實心火球 + 鋸齒緣)。
- **P7 每個元素都要掙得它的版面**: 縮圖不畫浮字與工程牌; 卡片第二行只畫四個數字 + 圖示, 不加「每分鐘」字樣(單位在面板與資訊列已寫); 資訊列用途小字用素材色, 不另加框。
- **P9 以最混亂的那一刻驗收**: 怪物受擊一律整隻閃白(保留深外框), 擊飛時身體傾斜 + 面向側速度線, 震波連鎖場面裡仍分得出誰在飛; 縮圖尺度改畫剪影(見 6.1)。
- **P13 事件要排隊**: 獲得道具提示固定在 (440,52) 一條, 前 0.2 秒淡入、最後 0.3 秒淡出; 連鎖字與 +N 浮字在物件位置, 不與獲得提示同區。
- **P15 回饋強度和事件份量成正比**: 撿素材(+N 小浮字)< 連鎖字(24px 彈跳)< 獲得道具(金框橫條 + 圖示)。
- **P17 進度類圖形與數字分工**: 技能冷卻只有圖形(扇形 + X 鍵帽, 冷卻好時整顆亮成職業色); 加速器等級用格子, 倍率用數字。
- **P18 重要資訊不能只存在一瞬間**: 「獲得 <道具>」1.5 秒後消失, 但結算面板、背包、道具格都畫同一個道具圖示與名稱。
- **P19 資訊貼著它描述的物件**: 盾牌長在盾兵面向側; 野豬預備的紅邊與踢灰長在野豬身上; 卡片的工程進度「修 n/2」、加速徽章、「新區域」都在該卡片上。
- **P21 示意圖選對錯理解會分岔的例子**: 說明第 4 頁兩條路線的上層平台與地面之間留 80px 淨空(> 角色 44), 直衝路線真的能從下面穿過, 繞路線真的跳得上去(見 8)。

## 5. 判讀約定(RD 請照這些假設傳值)

1. **擊飛方向 = 面向的反方向**。介面 state 沒有擊飛方向欄位; 被炸彈工震波擊飛的怪物多半正面朝施放者, 所以美術把速度線畫在「面向側框外至多 40px」(= 飛行反方向)。若 RD 擊飛時把 facing 改成飛行方向, 速度線會畫反 — 請**擊飛期間 facing 保持原值**, 或請製作人補一個擊飛方向欄位。
2. **震波 radius = 外緣**: 環寬 12px, 判定帶 = [radius − 12, radius], 白色外緣細線剛好落在 radius 上。爆炸 radius 同樣 = 火球外緣。
3. **縮圖剪影門檻**: 函式讀 `ctx.getTransform()` 的縮放, 先除以底圖倍率 `ctx.canvas.width / 1280`, 小於 **0.2** 時改畫剪影(見 6.1)。RD 用 `ctx.scale(devicePixelRatio)` 做高 DPI 不影響判斷。關卡面板預覽是 0.5 倍 → 畫完整版。
4. **工程結構逐格**: state 沒有「這格是不是缺口兩端 / 是不是最底層」的欄位, 所以未修的斷橋每一格都畫同一個極淡藍圖虛線框(不畫殘樁), 未修的崩梯每一格都畫藍圖虛線輪廓 + 格底一小堆碎石。缺口兩端的「殘樁」由相鄰的實心地面承擔。若要只在端格畫殘樁、只在底格畫碎石, 請製作人加一個欄位(例 `edge: 'left'|'right'|null`、`bottom: true`), 美術再補。
5. **閒置時間值**: 特效函式在 `t >= dur` 時自己不畫(介面閒置值 = dur)。
6. **表外值的預設外觀**: 職業不明 → 劍士; 素材不明 → 木材; 主題不明 → plain; 道具不明 → 空框; 工程 kind 不明 → bridge; role 不明 → shortcut; 怪物 state 不明 → 走路外觀。看到不該出現的劍士 / 木材 / 空框時請查傳入值。
7. **畫面文字歸屬**: 每個面板 / 卡片函式自己畫框內全部文字與鍵帽(含面板最下方提示行「↑↓ 換列 …」)。**大地圖最下方 y=690~714 那一行由 RD 畫**, 美術不畫。說明頁只畫示意圖(見 8), 頁標題 / 說明文字 / 頁碼 / 翻頁提示由 RD 畫。
8. **牆鐘動畫**(用 `performance.now()`, 不讀 state): 玩家無敵閃爍(12Hz)、寶箱關著的閃光、終點旗飄動、選取框脈動、「新區域」徽章脈動、升級所「!」脈動、工程框選虛線流動。位移都在框內。
9. 結算 / 失敗 / 結束面板**不畫**全畫面暗幕(介面沒指定), 只有關卡面板、升級所頁面、暫停面板會畫全畫面暗幕。
