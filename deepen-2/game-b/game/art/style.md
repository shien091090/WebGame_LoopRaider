# 魔巢獵場 — 美術風格表(RD 只讀這份)

> `index.html` 必須宣告 `<meta charset="utf-8">`, 否則 `art.js` 裡的中文會亂碼。
> 載入方式: 一般 `<script src="game/art/art.js">`(不是 module), 之後用全域 `window.Art`。

## 1. 邏輯畫布尺寸

- `Art.canvas = { width: 1280, height: 720 }`(照 interface.json, 固定寬, 沒有依裝置變寬)。
- 美術一律照 1280×720 座標畫, 函式內不自己乘縮放。RD 若做高 DPI(`ctx.scale(devicePixelRatio)`)或整體縮放, 在呼叫前做即可。
- 縮圖判斷: 物件函式讀 `ctx.getTransform()` 的縮放, 先除以底圖倍率(`ctx.canvas.width / 1280`), 低於 **0.2** 時改畫剪影(見 §6)。所以 RD 做高 DPI 不會被誤判成縮圖, 不用另外處理。

- 炸彈工橘 `#ff8a3a` 與木材 `#c8823c` 色相近(24° / 30°): 類別不同(角色 vs 素材圖示)、明度差大、形狀完全不同(人形白描邊 vs 原木), 不靠顏色分。

## 3. 形狀語言

扁平幾何 + 圓角; 玩家白描邊、怪物深描邊、地形無描邊; 危險 = 紅 + 尖角(只有尖刺與蜂彈 / 紅眼); 巢穴 = 紫色發光紋與眼。

## 5. 判讀約定(RD 請照這些傳值)

- **擊飛方向**: state 沒有飛行方向, 美術假設「被擊飛的怪面向炸彈工、往背後飛」, 速度線畫在**面向那一側**框外(至多 40px)。RD 若擊飛時另外把 `facing` 改成飛行方向的**反向**(= 朝向炸彈工), 畫面就一定對。建議製作人之後給 `flungDir` 欄位。
- **震波 / 爆炸的 radius = 判定外緣**。震波環從外緣往內畫 10px 寬(判定帶 = [當下外緣 − 10, 當下外緣]); 爆炸火球外緣 = radius × 擴張進度。
- **drawSiteHighlight**: 框線整條畫在 (x,y,w,h) 內側; `active=false` 時函式什麼都不畫(介面說 false 不呼叫, 呼叫了也安全)。
- **閒置值**: 所有 `xxT` 閒置時要傳 `xxT = xxDur`(介面約定)。巢口 `spawnT < spawnDur` 才噴霧; `state='dormant'` 時不論 `spawnT` 都不噴、5 個點全暗。
- **剩餘隻數**: 巢口 `left` 0~5, 亮點 = 還會湧出。
- **花費不足**: 所有吃 `cost + stock` 的函式, `stock[k] < cost[k]` 的那一種數字紅色 + 底線, 其他照常。`canAfford` 只影響「Z 解鎖 / Z 買下」字是否亮金色。
- **關卡面板道具格**: 「尚無戰利品」以 `items.length === 0` 判斷。
- **箭**: `size` 24×6 是水平時的尺寸, 斜飛時外接框自然變大(最大約 24×24), 屬預期。
- **表外值**: 列舉欄位不認得時畫預設: 職業 → 劍士、素材 → 木材、地形 → plain、怪物狀態 → walk/fly/crouch、巢口 → dormant、戰利品 → 圖示畫「?」並不寫名稱。看到不該出現的劍士 / 木材 / 「?」, 請查傳入值。數字欄位 NaN 當 0, 長寬、時間、半徑都有夾上限。
- **牆鐘動畫**(函式內用 `performance.now()`): 巢口 idle 呼吸光、終點旗飄動、無敵閃爍(每 1/12 秒切換)、選取框脈動、修復處框脈動。都只改亮度或在框內小幅移動, 不出框。
- **縮圖剪影門檻 0.2**(見 §1)。剪影版仍不出判定框; 巢母血條縮圖也照畫。

## 6. 畫面文字歸屬

- 美術畫: 每個卡片、面板、HUD、提示函式裡的全部文字與按鍵提示(含「Z 解鎖」「Z 出發」「Z 修復」「Z 換戰利品」「Z 購買」「Z 招募」「Z 升級」、面板最下方提示列、結算 / 失敗 / 暫停 / 結束面板的按鍵字)。**RD 不要再畫這些**。
- RD 畫: 大地圖最下方 y=690~714 那行操作提示(介面約定); 說明頁的頁標題、說明文字、頁碼、翻頁提示、按鍵說明(含第 2 頁文字裡的「Esc 暫停」)。
- 說明頁示意圖裡美術只畫: 物件旁的短標籤(「你」「終點旗」「素材多 / 秒數長」「素材少 / 秒數短」「12 → 13」)與貼在劍士旁的鍵帽。

## 7. 繪製層級(由下到上)

關卡: `drawBackground` → `drawLairBack` → `drawGround` / `drawCrackWall` / `drawCaveRubble` / `drawAltarGate` / `drawSpike` → `drawNest` → `drawHookRing`(吊繩往上畫 20px, 要在地形**之後**畫也沒關係, 繩子不超過 20px)→ `drawPickup` / `drawGoal` → 怪物 / 巢母 → `drawRangeRing`(獵人時)→ `drawPlayer` → 飛行物 → `drawExplosion` / `drawShockwave` / `drawPoof` → `drawPopup` / `drawChainText` → `drawHud` → `drawItemNotice` → 面板。
- 擊飛中的怪會飛過其他怪, 請把 `state='flung'` 的怪排在一般怪之後畫。

大地圖: `drawMapBackground` → `drawMapLink` → `drawLevelCard` → (RD 縮圖)→ `drawCardOverlay`; `drawWorkshopCard` / `drawGoalCard` → `drawFlyingMaterial` → `drawHud` → 面板。
