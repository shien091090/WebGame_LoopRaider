# 魔巢獵場(巢穴修復: 打通地下通道開出魔物巢穴, 連鎖擊倒掉落加倍, 巢母掉戰利品)

## 概述
單畫面橫向平台動作, 8 個短關卡以樹狀連結在大地圖上。三職業(劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈 + 震波擊飛)各有擅長的地形; 四種怪物都有血量、都會主動移動。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖飛一顆素材進資訊列。
本款的新機制是**魔物巢穴**: 每關地下有一座被坍方封住的巢穴。在大地圖花鐵礦**打通地下通道**後, 巢穴裡的**巢口**每趟會持續湧出怪物(一趟最多 5 隻), 湧出的怪會自己走出通道、掉落比一般怪多; 再**修復祭壇門**, 巢穴深處的**巢母**(精英怪)就會出現, 第一次擊倒牠會掉一件**戰利品**。戰利品裝在關卡的道具格上, 讓指定種類的怪物掉落加倍(或每次通關多送素材), 對該關每一次回放都生效, 不必重跑。
另有**連鎖掉落**: 同一次攻擊接連擊倒的第 2、3 隻怪, 掉落 ×2、×3, 把怪聚成一群再一次清掉最值錢。
獨立的**升級所**: 招募職業、花魔核強化移速 / 血量 / 技能冷卻。
四種素材各有一種專屬用途: **木材**開路(解鎖關卡、招募職業)、**鐵礦**修復巢穴、**時晶**買回放加速器、**魔核**(只有怪物會掉)強化角色; 終極目標「獵王殿」四種都要。
驗證假設: H08、H11、H33、H45、H46、H47、H56、H57、H59、H60、H73、H74、H75、H77、H78、H79

## 核心循環
大地圖看四種素材缺哪種 → 選關卡 → 在關卡面板修巢穴、裝戰利品、選職業 → 進關打怪、撿素材、決定要不要鑽進巢穴清怪 / 打巢母、衝終點 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放產出、素材飛進資訊列 → 用木材開新關 / 招募職業, 用鐵礦打通更多巢穴, 用時晶加速回放, 用魔核強化角色 → 回到剛打通的關卡, 把巢穴打進回放。

## 規則

### 關卡與錄影
1. 每關是不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、素材與戰利品都不入帳), 跳出失敗面板。
4. 這趟拿到的素材與戰利品只在過關時才入帳(不論結算時留新或舊, 都入帳)。
5. 素材 4 種: **木材**、**鐵礦**、**時晶**、**魔核**。地上的素材(木材 / 鐵礦 / 時晶, 地上沒有魔核)碰到即得 1; 擊倒怪物立即得到該怪的掉落(見數值表與規則 26), 不落地。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、職業、面向、動作)、每隻怪物(含巢口湧出的怪與巢母; 位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃)、巢口狀態、所有飛行物(箭、炸彈、蜂彈)、爆炸、震波、已拿走的素材(以素材編號記)、裂岩牆血量、擊倒煙。另記錄每次「基本得到素材」的時間點、位置、種類、數量與來源(地上撿 / 擊倒怪物; 擊倒時另記怪物種類、是否來自巢穴、連鎖倍率), 以及抵達終點的位置。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔); 怪物湧出、移動、攻擊、被擊飛、被擊倒都照錄影重現。每播到一個得到素材的時間點, 持有的該種素材 + 該數量(含連鎖倍率與戰利品加成, 見規則 26、29); 每播到抵達終點, 加上「每次通關」類戰利品的素材。
8. 回放在大地圖、關卡內、各面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。該關每種素材的每分鐘產量 = 一圈內該種素材總數(含目前裝的戰利品加成)÷ 錄影秒數 × 60 × 加速器倍率(小數 1 位)。
10. 開局: 素材全 0, 只開放第 1 關與劍士, 背包沒有戰利品, 所有巢穴未修。

### 大地圖
11. 8 張關卡卡片依樹狀排列(版位見「大地圖版位」), 連線: 1→2、1→3、2→4、2→5、3→6、3→7、5→8、6→8。上分支(2、4、5)多高台與寬坑, 下分支(3、6、7)多怪物與裂岩牆。另有**升級所**卡片(第 1 關下方)與終極目標**獵王殿**卡片(最右)。
12. 卡片狀態: **封鎖**(連到它的前一關都還沒過關; 畫鎖與花費, 不能買)、**可解鎖**(至少一個前一關已過關; `Z` 花木材解鎖)、**已開放**(未過關)、**已過關**(縮圖重演回放、下方顯示四種素材每分鐘產量)。第 8 關的前一關是 5 或 6, 任一過關即可解鎖。
13. **素材飛行**: 大地圖畫面(沒開任何面板)時, 回放每得到 1 個素材, 就從縮圖裡該素材被拿到的位置(錄影位置 × 縮圖倍率 + 縮圖左上角; 擊倒掉落從怪物倒下處、每次通關的戰利品素材從終點旗處)飛出一顆該種素材, 0.7 秒沿弧線飛進資訊列該種素材圖示, **飛到時持有數才 +1**, 計數跳一下。一次得到 N 個就飛 N 顆(同時出發, 起點各自隨機錯開 ±6px; N > 5 時只飛 5 顆, 最後一顆帶剩下的數量)。開著面板或在關卡內時不飛, 直接 +。
14. **新區域標記**: 該關目前回放是在該關最近一次修復之前錄的 → 卡片縮圖角落標「新區域」, 直到存下一條在修好之後錄的回放才消失。
15. 游標: `←` `→` 換到左 / 右一欄中垂直位置最接近的卡片, `↑` `↓` 在同一欄內上下移(到頭不動)。欄由左到右: 第 1 關、升級所 / 第 2、3 關 / 第 4~7 關 / 第 8 關 / 獵王殿。
16. 在卡片上按 `Z`: 封鎖 → 不反應; 可解鎖 → 木材夠就扣除並變成已開放, 不夠不反應; 已開放或已過關 → 打開**關卡面板**。升級所 → 打開**升級所頁面**。獵王殿 → 四種都夠就買下(勝利), 不夠不反應。

### 關卡面板(先選關卡、再選職業)
17. 面板分四列, `↑` `↓` 換列, 打開時在第 1 列; `X` 關閉回大地圖。左邊是該關的靜態預覽(目前地形含修復狀態、素材、怪物出生位置、巢口、巢母出生位置(祭壇門已修時); **不畫任何路線線條**), 下方是戰利品背包與目前回放資訊。
    - **職業列**: `←` `→` 在劍士 / 獵人 / 炸彈工間選, 預設是這關上次用的職業(沒有就是劍士)。選到已招募的按 `Z` = 用這個職業進關; 未招募的格子畫鎖與「到升級所招募」, 按 `Z` 不反應。
    - **修復列**: `←` `→` 選地下通道 / 祭壇門, 預覽上框出該處的位置。未修的按 `Z` = 鐵礦夠就修好(扣除, 地形立即改變), 不夠不反應; **祭壇門要先打通地下通道才能修**(通道未修時畫鎖與「先打通通道」, 按 `Z` 不反應); 已修好的顯示「已完工」。
    - **道具格列**: `←` `→` 選 1、2 號格。按 `Z` = 換下一件戰利品, 依序「空 → 背包第 1 件 → 第 2 件 → … → 空」循環; 換到正裝在別處(別格或別關)的戰利品時, 直接從原處搬過來(原處變空)。背包沒有戰利品時不反應。
    - **加速器列**: `Z` = 時晶夠就買下一級(扣除), 已滿或不夠不反應。

### 升級所(獨立頁面)
18. 大地圖選升級所按 `Z` 打開; `X` 關閉回大地圖。分四列, `↑` `↓` 換列:
    - **招募列**: `←` `→` 選獵人 / 炸彈工; `Z` = 木材夠就招募(扣除, 之後所有關卡面板都能選), 已招募或不夠不反應。
    - **移速列** / **血量列** / **冷卻列**: `Z` = 魔核夠就升一級(扣除), 已滿或不夠不反應。
19. 強化對三職業都有效, 只影響之後的跑關; 已存的回放照錄影重演, 不會變快(想讓回放變快要重跑)。

### 魔物巢穴(本款特有)
20. 每關地下(或岩壁內)有一座**巢穴**: **巢穴室**(約 10×4 格, 地面平坦)與更深處的**巢母室**(約 8×4 格), 位置見關卡構成。開局時巢穴室與主路之間的**地下通道**被坍方的亂石堵住(實心、打不壞也炸不壞, 外觀要和裂岩牆一眼分得出); 巢母室與巢穴室之間是關著的**祭壇門**(實心, 1×3 格)。巢穴室與巢母室裡看得到巢口與祭壇, 但進不去。
21. **打通地下通道**(關卡面板修復列, 花鐵礦): 亂石消失, 通道與主路相連且地面平順(野豬、盾兵、跳蛙都走得出來)。之後每一趟跑關, 巢穴室裡的**巢口**都會運作(規則 22)。
22. **巢口**: 這趟開始後 1 秒湧出第 1 隻怪, 之後每 2.5 秒湧出 1 隻, 一趟最多 5 隻(湧滿後巢口變暗, 這趟不再湧)。湧出的種類照該關的「巢口怪物」清單依序輪流。湧出的怪出現在巢口前方、面向通道, 之後照該種怪物的一般行為行動(野豬、盾兵、跳蛙會沿巢穴室走出通道進到主路; 射手蜂在出生點附近巡飛)。巢口打不壞。玩家沒進巢穴也照湧(湧出的怪可能自己走到主路上)。
23. **巢穴怪**: 巢口湧出的怪身上帶巢穴的記號, 掉落 = 該種怪的一般掉落 + 魔核 1(見數值表)。
24. **修復祭壇門**(花鐵礦, 須先打通通道): 祭壇門打開。之後每一趟跑關, 巢母室裡都有一隻**巢母**(規則 25)。
25. **巢母**(精英怪, 64×56): 血 12。在巢母室與巢穴室內以 50px/秒巡邏(撞牆、到平台邊緣或到通道口就回頭, 不進主路)。玩家與它上下相差 80px 內、在它面向那側 320px 內 → 停下預備 0.8 秒 → 以 380px/秒衝撞, 撞牆或到邊緣 / 通道口才停, 停下後暈眩 1.5 秒; **暈眩中受到的傷害 ×2**。碰到玩家扣 1。不會被擊飛(震波只造成 1 傷害), 被擊飛的怪撞到它照常受 2 傷害。掉落 魔核 6 + 鐵礦 4; 該關**第一次**擊倒巢母時另得該關的**戰利品**(畫面上方提示「獲得 <戰利品名>」, 過關時放進背包), 之後的趟數只有一般掉落。
26. **連鎖掉落**: 玩家的同一次攻擊(含它引發的擊飛碰撞)依序擊倒的第 k 隻怪物, 掉落 ×k(k 最多 3; 第 4 隻起都 ×3)。第 1 隻 ×1。浮字標出倍率。適用所有怪物(含巢穴怪與巢母)。
27. 縮圖與預覽的地形一律畫**目前**的修復狀態; 回放照錄影重演: 錄影當時通道未通, 回放裡就沒有巢穴怪、巢口畫成「沉睡」; 錄影當時沒有巢母, 回放裡也沒有。新區域(巢穴室)裡的地上素材, 這條錄影沒拿走的就一直畫在縮圖上。

### 道具格(戰利品)
28. 每關 2 個道具格(1、2 號), 已開放的關卡就能裝。戰利品效果**依現在的配置**對該關每一圈回放與每一趟跑關生效, 改裝後下一個得到素材的時間點起就照新配置算, 卡片與面板上的每分鐘產量立即更新; 不必重跑。
29. 戰利品(同一關裝兩件相同或作用在同一種怪的, 加成相加: 兩件 = ×3):
    - **野豬牙**: 擊倒野豬的掉落 +100%。**蜂針**: 射手蜂 +100%。**盾徽**: 盾兵 +100%。**蛙蹼**: 跳蛙 +100%。**巢母角**: 巢穴怪與巢母 +100%。
    - **魔核袋**: 每次通關 +3 魔核。**鐵礦袋**: 每次通關 +3 鐵礦。**木材袋**: 每次通關 +5 木材。
    - 擊倒掉落 = 基本掉落 × 連鎖倍率 × (1 + 戰利品加成), 每種素材各自計算後取整。
30. 戰利品來源只有巢母首殺(全遊戲 8 件, 每關固定 1 件, 見關卡構成)。背包最多 8 件。一件戰利品同時只裝在一格。

### 結算
31. 過關時該關沒有回放 → 直接存成回放。已有回放 → 結算面板並列「這一趟」與「目前回放」的秒數與四種素材的每分鐘產量(兩邊都用目前的戰利品配置計算), `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
32. 玩家血量 3(升級後 4 / 5); 碰到怪物(被擊飛中的除外)或蜂彈扣 1, 之後無敵 1 秒並被往反方向彈開 80px。每次進關回滿。
33. **怪物**(四種行為, 全部會主動移動, 都有血量; 被擊倒時冒擊倒煙。巢穴怪行為相同):
    - **野豬**(衝撞): 以 80px/秒左右巡邏, 撞牆或到平台邊緣回頭。玩家與它上下相差 40px 內、在它面向那側 240px 內 → 停下預備 0.5 秒 → 以 420px/秒朝原方向衝撞, 撞牆或到平台邊緣才停, 停下後暈眩 1 秒, 再回到巡邏。
    - **盾兵**(正面擋): 玩家在水平 400px 內且上下相差 120px 內 → 以 40px/秒朝玩家走; 否則以 40px/秒巡邏(撞牆或邊緣回頭)。不離開所在平台(巢穴室與通道、主路地面相連時視為同一平台)。從它面向那側打來的揮砍、箭、衝刺斬被盾擋下(不扣血, 盾閃一下); 從背後、或攻擊判定中心高於它頭頂時照常受傷。爆炸、震波、被擊飛的怪撞上來都不受盾影響。
    - **射手蜂**(射擊): 在出生點左右 120px 內以 60px/秒來回巡飛(碰到地形回頭), 同時上下飄 ±16px(週期 2 秒)。玩家在 400px 內時每 2 秒射一發: 停下瞄準 0.4 秒 → 朝玩家當下位置射出蜂彈(220px/秒直線, 碰到地形消失)。
    - **跳蛙**(跳躍): 每 1.2 秒跳一次(水平 120px、最高 80px), 落地蹲著等下一跳。玩家在 300px 內時朝玩家跳; 否則朝面向跳, 起跳前若落點沒有地面或是牆就先轉向。
34. **職業**(攻擊 `Z`、技能 `X`; 三職業判定框都是 28×44; 移速與技能冷卻再乘升級所的倍率):
    - **劍士**(開局): 移速 260。攻擊 = 面前揮砍(面向側 50×40, 1 傷害, 冷卻 0.3 秒)。技能 = **衝刺斬**: 朝面向衝 160px(0.18 秒, 期間無敵、不受重力, 沿途怪物受 2 傷害), 冷卻 1.2 秒; 衝刺斬擊倒怪物時冷卻立刻歸零; 空中可用, 每次離地只能用 1 次(落地恢復)。擅長: 跳起再衝刺斬跨過 6 格寬坑。
    - **獵人**: 移速 260。攻擊 = **自動射擊**: 每 0.6 秒自動朝 260px 內最近的一隻怪物射一箭(箭速 700px/秒, 飛向目標當下位置, 1 傷害), 射程圈常駐顯示; 另外按 `Z` 可手動朝面向水平射一箭(冷卻 0.4 秒, 飛 600px, 可打裂岩牆)。技能 = **抓鉤**: 220px 內有鉤環時, 以 700px/秒被拉到鉤環, 到達瞬間獲得向上 500px/秒的速度, 冷卻 0.5 秒; 範圍內沒有鉤環則不反應。擅長: 一下上到 5 格高的高台。
    - **炸彈工**: 移速 230。攻擊 = **投彈**: 朝面向拋出炸彈(初速水平 300、向上 500px/秒, 重力同玩家), 碰到地形或怪物即爆炸, 半徑 60px(外緣)內怪物受 2 傷害、裂岩牆直接碎掉(坍方亂石不受影響); 冷卻 0.6 秒; 玩家不會被自己的爆炸傷到。技能 = **震波**: 以自己為中心半徑 130px(外緣)內的怪物受 1 傷害並被**擊飛**(規則 35), 範圍內的裂岩牆直接碎掉; 空中可用, 冷卻 1.5 秒。擅長: 破裂岩牆、打盾兵、把怪撞成一串。
35. **擊飛**(只有炸彈工的震波會造成; 巢母不會被擊飛): 被打中還活著的怪物朝「遠離炸彈工」的水平方向以 460px/秒飛出, 最多 0.6 秒或撞到地形為止, 期間不受重力、碰到玩家不傷人。
    - 擊飛中的怪碰到其他怪(含巢母) → 對方受 2 傷害, 若還活著也被擊飛(方向相同; 巢母只受傷不飛)。同一次擊飛中每隻怪只會撞同一隻別的怪一次。
    - 擊飛中撞到地形 → 自己受 1 傷害, 擊飛結束。
    - 擊飛結束仍活著 → 落地(蜂回到飛行)後恢復原本行為。
36. **連鎖字**: 同一次攻擊擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」。
37. **裂岩牆**: 實心, 耐久 3。揮砍、箭、衝刺斬每次 -1; 炸彈爆炸或震波碰到直接碎掉。碎掉後消失(冒擊倒煙)。

### 物理(三職業共用)
38. 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格); 移速 260 全速跳躍水平約 156px(過得了 3 格寬的坑)。按住跳躍鍵短於 0.15 秒時初速減半(小跳)。地形為實心方塊, 沒有單向平台、移動平台。

### 擅長與替代路線(三職業都過得了每一關的每個已開放地方)
39. 三種「擅長地形」每種都有不需技能的替代做法, 只是比較慢:
    - **高台**(離下方地面 5 格): 下方掛鉤環 → 獵人一下上去; 其他職業走旁邊的 3~4 段階梯平台(多花約 2~3 秒)。
    - **寬坑**(6 格寬, 坑底是低一層的小路, 不是尖刺): 劍士跳起 + 衝刺斬直接跨過; 其他職業下到坑底小路走過去、再爬階梯上來(多花約 2~3 秒)。
    - **裂岩牆**: 炸彈工一炸就破; 其他職業打 3 下。
40. 只有小捷徑或多拿一點的地方才放擅長地形; 不做整片區域只有某職業進得去。巢穴對所有職業都一樣, 打通後所有職業都能進。

### 素材用途(每種一種專屬用途)
41. **木材** = 開路: 解鎖關卡、招募職業。**鐵礦** = 修復巢穴(地下通道、祭壇門)。**時晶** = 回放加速器(每關各自買)。**魔核** = 升級所強化角色。**獵王殿** = 四種都要, 買下即勝利。
