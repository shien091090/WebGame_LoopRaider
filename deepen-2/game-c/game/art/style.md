# 廢墟復興 — 美術規格(deepen-2 / game-c)

RD 只讀這份。`art.js` 掛在 `window.Art`, 一般 `<script src>` 載入(不是 module)。`index.html` 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字會變亂碼。

## 1. 邏輯畫布尺寸

- `Art.canvas = { width: 1280, height: 720 }`(= interface.json 的 canvas, 固定寬, 不依裝置調整)
- 美術一律照這套座標畫, 不自己乘縮放

地形主題(`drawGround` 的 theme): plain 草綠頂 + 棕土 / sky 雲白頂 + 灰藍石 / rock 沙黃頂 + 紅橙岩層紋 / swamp 苔青頂 + 深橄欖泥 / throne 金邊頂 + 紫色菱紋大理石。五種頂面的做法一致: 上緣 8px 頂帶 + 2px 亮邊。

**色彩張力(請製作人驗收)**:
- 木材(色相約 40°)與磚瓦(約 5°)色相只差約 35°, 低於經驗文件「色相差 ≥ 60°」的門檻。不靠顏色單獨區分: 木材是淺色**圓木 + 年輪圓面**, 磚瓦是深色**長方磚 + 灰縫**, 形狀與明度各自成立。最難分的一幀: 縮圖(0.125 倍)裡兩者都簡化成色塊, 只剩明度差(淺金 vs 深紅)。
- 類別色與職業色同色系(倉庫藍 ≈ 劍士藍、獵寮綠 ≈ 獵人綠): 兩者分屬不同類別層(建築 / 道具框 vs 角色衣服), 而且角色有白描邊、建築沒有, 所以判斷不會撞; 有問題時改職業色。

## 3. 形狀語言

扁平幾何、圓角; **我方 = 白描邊, 敵方 = 深描邊 + 白眼紅瞳**; 朝上並排的尖三角只給尖刺(危險), 草叢、雲邊、閃光一律用圓弧; 建築的一切 = 規則磚紋 + 類別色 + 類別標誌(貨箱 / 爪印 / 眼睛)。

## 4. 理念落實

| 理念 | 本作怎麼落實 |
|---|---|
| P0 辨識度先於好看 | 每種物件先定一個類別層長相(角色白描邊、怪物深描邊紅瞳、建築磚紋、落石圓石斷梁、裂岩牆淺灰白裂痕), 背景只用低對比漸層與剪影 |
| P1 視覺權重跟著決策迫切度 | 危險紅只給會傷人的東西; 背景與遠山最淡; 「獲得道具」提示固定在上方 (440,52), 不蓋資訊列; 面板裡只有選中列用金框, 選中格用白框 |
| P2 規則上存在的東西必須看得見 | 盾兵的盾永遠畫在面向側(擋得下的那面); 獵人射程圈常駐; 破損建築的素材與寶箱畫在背牆之上看得見; 每個 cost 逐項比對 stock, 不足那種數字變紅 + 紅底線 |
| P3 一個意義一種長相 | 三種素材圖示在地上、資訊列、飛行素材、浮字、面板裡都是同一支畫法(`matIcon`); 建築類別色 + 標誌同時用在建築招牌、屋頂頂帶、道具格框、道具圖示框、面板「可裝: X」那一行 |
| P4 關鍵區分走兩條通道 | 木材 / 磚瓦: 形狀 + 明度; 落石 vs 裂岩牆: 深色圓石 + 斷梁 vs 淺灰平板 + 白裂痕; 關著的寶箱 vs 開著的空箱: 金亮 + 閃光 vs 暗褐 + 蓋子掀開; 敵我: 描邊明暗 + 眼睛 |
| P7 每個元素都要掙得版面 | 縮圖裡不畫字; 卡片只留數字與小圖示, 不寫「每分鐘」字樣(面板與結算才寫 /分) |
| P9 以最混亂的那一刻驗收 | 怪物一律深描邊、玩家一律白描邊, 擊飛速度線為白色, 疊在任何地形主題上都讀得到; 浮字與連鎖字帶深色描邊 |
| P13 事件要排隊 | 獲得提示只有一個固定版位, 美術不另開; 連鎖字與 +N 浮字由 RD 錯開 y |
| P15 回饋強度和份量成正比 | 擊倒煙(小、灰) < 炸彈爆炸(橘色火球, 半徑 60) < 震波(白色外推環 + 8 個往外箭號, 半徑 130); 連鎖字是金色大字並彈一下, +N 浮字是白色小字 |
| P17 進度圖形與數字分工 | 資訊列技能鈕: 扇形 = 這次冷卻還剩多少(不重述數字), 就緒時整顆亮成職業色 + 白外框; 升級所等級格: 格數 = 已升級數 / 上限 |
| P18 重要資訊不能只存在一瞬間 | 開寶箱的「獲得 X」只亮 1.5 秒, 結算面板會再寫一次, 背包格也常駐 |
| P19 資訊貼著物件 | 道具格就在門楣上(建築本身), 道具效果寫在面板的建築格內; 瞄準記號長在蜂身上, 暈眩星星在野豬頭上 |
| P21 示意圖選分岔的例子 | 說明第 4 頁兩張圖是同一關、同一個起點與終點, 只差路線(繞去打怪撿素材 vs 直衝), 兩張的差別就是要教的取捨 |

## 5. 判讀約定(美術與 RD 對介面的共同解讀)

- **擊飛方向**: state 沒給擊飛方向, 美術約定「被擊飛方向 = 面向的反方向」(被打飛的怪多半正面朝向炸彈工)。速度線畫在**面向那一側**的框外 ≤ 40px。RD 若想畫準確, 擊飛時把 facing 設成「朝向炸彈工」即可, 不用改欄位。
- **半徑 = 外緣**: drawExplosion、drawShockwave、drawRangeRing 的 `radius` 都是判定外緣; 環的線寬往內長(震波環寬 7px, 判定帶 = [radius×進度 − 7, radius×進度])。請 RD 判定也用外緣。
- **飛行素材拖尾**: 方向 = 從目前位置背對資訊列該素材圖示中心(36/206/376/546, 20), 美術自己算, 不需要額外欄位。
- **關卡面板預覽框**: drawLevelPanel 的暗幕與面板底**都挖空了預覽框 (60,96,640,360)**, 外框畫在框外 1px。RD 先畫面板再畫預覽、或先畫預覽再畫面板都可以; 預覽要自己鋪滿(drawBackground 在 0.5 倍下剛好鋪滿)。
- **面板內按鍵提示**: 選中格的「Z 出發 / Z 重建 / Z 換道具 / Z 購買 / Z 招募 / Z 升級」只畫在選中那一格; 該列不是目前列時提示照畫但淡到 45%。
- **花費不足的後備**: 卡片與復興之城卡片照介面讀 `stock` 逐項比對; 沒傳 `stock` 時退回 `canAfford`(true = 全部照常, 其他 = 全部標紅)。
- **牆鐘動畫**: `drawPlayer` 的無敵閃爍(每 1/12 秒切換)與 `drawSiteHighlight` 的脈動用 `performance.now()`, 不需傳時間。
- **縮圖簡化**: 函式用 `ctx.getTransform()` 量目前縮放, < 0.2(縮圖 0.125)時改畫簡化色塊: 素材 = 三色方塊、道具格 = 類別色框 + 道具主色、怪物 = 深框色塊、玩家 = 白框 + 職業色。面板預覽(0.5)照完整畫法。
- **表外值**: 以列舉查表的欄位查不到時一律落到預設(素材 → 木材、職業 → 劍士、建築 → 倉庫、主題 → plain、怪物狀態 → walk / fly / crouch、pose → idle、道具 → 空)。看到不該出現的預設外觀, 請查傳入值。布林欄位一律只認 `=== true`。
- **鉤環吊繩**: state 沒給上方平台的位置, 吊繩固定畫到中心上方 30px(框外 18px, 在介面允許的 20px 內)。鉤環掛在高台邊緣正下方時, 繩頂剛好碰到平台底; 若鉤環離平台更遠, 繩會懸空 — 需要時請製作人在介面補「平台底 y」欄位。

## 6. 畫面文字歸屬

- 美術已畫(RD 不要再畫): 卡片、面板、頁面、資訊列、結算 / 失敗 / 暫停 / 結束面板裡的**全部文字與按鍵提示**, 包括關卡面板與升級所最下方那行提示。
- RD 畫: 大地圖最下方 y=690~714 的操作提示(介面指定)。
- **說明頁**: 介面的文字歸屬沒點名說明頁函式, 依任務分工: 美術**只畫示意圖**, 而且只畫在 `(x, y, w, h)` 框內; 頁標題、說明文字、頁碼、翻頁提示、按鍵說明**一律由 RD 畫**。示意圖內只有物件旁的短標籤(「你」「終點旗」「素材多 / 秒數長」「素材少 / 秒數短」)與第 2 頁的鍵帽。
