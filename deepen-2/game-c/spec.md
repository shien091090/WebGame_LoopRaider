# 廢墟復興(建築重建: 修好的建築開出內部房間, 建築本身就是該關的道具格)

## 概述
單畫面橫向平台動作, 8 個短關卡以樹狀連結在大地圖上。三職業(劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈 + 震波擊飛)各有擅長的地形; 四種怪物都有血量、都會主動移動。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖飛一顆素材進資訊列。
本款的新機制是**建築重建**: 每關有兩棟破損的建築, 種類有三種——**倉庫**、**獵寮**、**瞭望塔**。在大地圖花磚瓦修好一棟, 會同時得到兩樣東西:
1. **內部房間**(新區域): 倉庫裡堆著素材、獵寮裡關著怪物、瞭望塔可以一路爬上屋頂; 三種房間給的重跑理由各不相同。
2. **一個道具格**: 道具裝在建築上, **建築種類決定能裝哪一類道具**(倉庫裝「每次通關多送素材」的貨袋、獵寮裝「擊倒加成」的獵具、瞭望塔裝「撿取加成」的拾荒籃)。道具對該關每一次回放都生效, 不必重跑。
所以「先修哪一棟」= 決定這關要往哪種產線發展。道具來自建築房間裡的寶箱。另有獨立的**升級所**: 招募職業、花獸魂強化移速 / 血量 / 技能冷卻。
四種素材各有一種專屬用途: **木材**開路(解鎖關卡、招募職業)、**磚瓦**重建建築、**時晶**買回放加速器、**獸魂**(只有怪物會掉)強化角色; 終極目標「復興之城」四種都要。
驗證假設: H08、H11、H33、H46、H47、H56、H57、H59、H60、H73、H74、H75、H80、H81

## 核心循環
大地圖看四種素材缺哪種 → 選關卡 → 在關卡面板重建建築、往修好的建築裝道具、選職業 → 進關打怪、撿素材、鑽進修好的建築房間、開寶箱、衝終點 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放產出、素材飛進資訊列 → 用木材開新關 / 招募職業, 用磚瓦重建更多建築, 用時晶加速回放, 用獸魂強化角色 → 回到剛重建的關卡, 把新房間跑進回放。

## 規則

### 關卡與錄影
1. 每關是不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、素材與寶箱都不入帳), 跳出失敗面板。
4. 這趟拿到的素材與寶箱道具只在過關時才入帳(不論結算時留新或舊, 都入帳)。
5. 素材 4 種: **木材**、**磚瓦**、**時晶**、**獸魂**。地上的素材(木材 / 磚瓦 / 時晶, 地上沒有獸魂)碰到即得 1; 擊倒怪物立即得到該怪的掉落(見數值表), 不落地。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、職業、面向、動作)、每隻怪物(含獵寮裡的怪; 位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃)、所有飛行物(箭、炸彈、蜂彈)、爆炸、震波、已拿走的素材(以素材編號記)、裂岩牆血量、寶箱開關、擊倒煙。另記錄每次「基本得到素材」的時間點、位置、種類、數量與來源(地上撿 / 擊倒怪物), 每隻怪被擊倒的時間點與位置, 以及抵達終點的位置。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔); 怪物移動、攻擊、被擊飛、被擊倒都照錄影重現。每播到一個得到素材的時間點, 持有的該種素材 + 該數量(含道具加成, 見規則 25); 每播到抵達終點, 加上「每次通關」類道具的素材。
8. 回放在大地圖、關卡內、各面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。該關每種素材的每分鐘產量 = 一圈內該種素材總數(含目前裝的道具加成)÷ 錄影秒數 × 60 × 加速器倍率(小數 1 位)。
10. 開局: 素材全 0, 只開放第 1 關與劍士, 背包沒有道具, 所有建築都是破損的。

### 大地圖
11. 8 張關卡卡片依樹狀排列(版位見「大地圖版位」), 連線: 1→2、1→3、2→4、2→5、3→6、3→7、5→8、6→8。上分支(2、4、5)多高台與寬坑, 下分支(3、6、7)多怪物與裂岩牆。另有**升級所**卡片(第 1 關下方)與終極目標**復興之城**卡片(最右)。
12. 卡片狀態: **封鎖**(連到它的前一關都還沒過關; 畫鎖與花費, 不能買)、**可解鎖**(至少一個前一關已過關; `Z` 花木材解鎖)、**已開放**(未過關)、**已過關**(縮圖重演回放、下方顯示四種素材每分鐘產量)。第 8 關的前一關是 5 或 6, 任一過關即可解鎖。
13. **素材飛行**: 大地圖畫面(沒開任何面板)時, 回放每得到 1 個素材, 就從縮圖裡該素材被拿到的位置(錄影位置 × 縮圖倍率 + 縮圖左上角; 擊倒掉落從怪物倒下處、每次通關的道具素材從裝著該道具的建築處)飛出一顆該種素材, 0.7 秒沿弧線飛進資訊列該種素材圖示, **飛到時持有數才 +1**, 計數跳一下。一次得到 N 個就飛 N 顆(同時出發, 起點各自隨機錯開 ±6px; N > 5 時只飛 5 顆, 最後一顆帶剩下的數量)。開著面板或在關卡內時不飛, 直接 +。
14. **新區域標記**: 該關目前回放是在該關最近一次重建建築之前錄的 → 卡片縮圖角落標「新區域」, 直到存下一條在重建之後錄的回放才消失。
15. 游標: `←` `→` 換到左 / 右一欄中垂直位置最接近的卡片, `↑` `↓` 在同一欄內上下移(到頭不動)。欄由左到右: 第 1 關、升級所 / 第 2、3 關 / 第 4~7 關 / 第 8 關 / 復興之城。
16. 在卡片上按 `Z`: 封鎖 → 不反應; 可解鎖 → 木材夠就扣除並變成已開放, 不夠不反應; 已開放或已過關 → 打開**關卡面板**。升級所 → 打開**升級所頁面**。復興之城 → 四種都夠就買下(勝利), 不夠不反應。

### 關卡面板(先選關卡、再選職業)
17. 面板分三列, `↑` `↓` 換列, 打開時在第 1 列; `X` 關閉回大地圖。左邊是該關的靜態預覽(目前地形含建築狀態、素材、怪物出生位置、寶箱; **不畫任何路線線條**), 下方是道具背包與目前回放資訊。
    - **職業列**: `←` `→` 在劍士 / 獵人 / 炸彈工間選, 預設是這關上次用的職業(沒有就是劍士)。選到已招募的按 `Z` = 用這個職業進關; 未招募的格子畫鎖與「到升級所招募」, 按 `Z` 不反應。
    - **建築列**: `←` `→` 選這關的建築 1 / 建築 2, 預覽上框出該建築。
        - 破損的建築按 `Z` = 磚瓦夠就重建(扣除, 地形立即改變、多出一個道具格), 不夠不反應。
        - 已重建的建築按 `Z` = 換下一個**符合這棟類別**的道具, 依序「空 → 背包裡第 1 個符合的 → 第 2 個 → … → 空」循環; 換到正裝在別棟(別關)的道具時, 直接從原處搬過來(原處變空)。背包裡沒有符合類別的道具時不反應。
    - **加速器列**: `Z` = 時晶夠就買下一級(扣除), 已滿或不夠不反應。

### 升級所(獨立頁面)
18. 大地圖選升級所按 `Z` 打開; `X` 關閉回大地圖。分四列, `↑` `↓` 換列:
    - **招募列**: `←` `→` 選獵人 / 炸彈工; `Z` = 木材夠就招募(扣除, 之後所有關卡面板都能選), 已招募或不夠不反應。
    - **移速列** / **血量列** / **冷卻列**: `Z` = 獸魂夠就升一級(扣除), 已滿或不夠不反應。
19. 強化對三職業都有效, 只影響之後的跑關; 已存的回放照錄影重演, 不會變快(想讓回放變快要重跑)。

### 建築重建(本款特有)
20. 每關 2 棟建築(種類與位置見關卡構成)。每棟是一個由牆與屋頂圍起來的空間, 門口 1×2 格。**破損**時: 外觀殘破、門口被落石堵住(實心、打不壞也炸不壞, 外觀要和裂岩牆一眼分得出), 從破洞看得到裡面的素材與寶箱, 但進不去。**重建後**: 落石消失、外觀修好, 門口可進出; 門楣上出現該棟的**道具格**。
21. 三種建築的內部房間:
    - **倉庫**(約 6×4 格): 地上堆著素材 5~6 個(以木材、磚瓦為主)。進去再出來多花約 3~4 秒。
    - **獵寮**(約 8×4 格): 重建後每一趟開始時, 裡面有 2~3 隻怪物(種類見關卡構成), 照一般行為行動, 會從門口走出來到主路上。房間地上另有素材 1~2 個。清完再出來多花約 4~6 秒。破損時裡面沒有怪物。
    - **瞭望塔**(約 4×9 格, 高): 內部有 3~4 段平台一路爬到屋頂, 屋頂上有時晶 3~4 個。爬上去再下來多花約 4~6 秒。
22. 每關有 1 個寶箱, 放在其中一棟建築的房間裡(見關卡構成), 內含固定的道具。玩家碰到即打開, 畫面上方提示「獲得 <道具名>」, 過關時放進背包。拿過的寶箱之後的趟數都是打開的空箱。背包最多 8 個(全遊戲就 8 個寶箱)。
23. 重建在關卡面板做(規則 17), 重建後不會再壞。縮圖與預覽的地形一律畫**目前**的建築狀態; 回放照錄影重演: 錄影當時建築還沒修, 回放裡就沒有獵寮的怪; 錄影裡的角色可能穿過現在已修好的牆(屬預期)。新房間裡的素材, 這條錄影沒拿走的就一直畫在縮圖上; 寶箱照錄影: 錄影那趟打開過的, 打開瞬間之前畫關、之後畫開; 錄影沒碰過的照目前狀態畫(已被拿過 = 開、沒人拿過 = 關)。

### 建築道具格
24. 每棟重建好的建築有 1 個道具格, 只能裝**符合建築類別**的道具。道具效果作用在**整關**(不限建築附近), **依現在的配置**對該關每一圈回放與每一趟跑關生效, 改裝後下一個得到素材的時間點起就照新配置算, 卡片與面板上的每分鐘產量立即更新; 不必重跑。
25. 道具(同一關兩棟裝了同名道具時效果相加):
    - **貨袋類**(只能裝在倉庫): **木材袋** 每次通關 +4 木材; **磚瓦袋** 每次通關 +3 磚瓦; **時晶袋** 每次通關 +2 時晶; **魂袋** 每次通關 +2 獸魂。
    - **獵具類**(只能裝在獵寮): **獵人號角** 擊倒怪物的掉落 +100%(每種素材各自加倍); **魂鉤** 每擊倒 1 隻怪 +1 獸魂。
    - **採集類**(只能裝在瞭望塔): **拾荒籃** 每撿到 1 個地上素材, 額外 +1 同種。
26. 一個道具同時只裝在一格。

### 結算
27. 過關時該關沒有回放 → 直接存成回放。已有回放 → 結算面板並列「這一趟」與「目前回放」的秒數與四種素材的每分鐘產量(兩邊都用目前的道具配置計算), `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
28. 玩家血量 3(升級後 4 / 5); 碰到怪物(被擊飛中的除外)或蜂彈扣 1, 之後無敵 1 秒並被往反方向彈開 80px。每次進關回滿。
29. **怪物**(四種行為, 全部會主動移動, 都有血量; 被擊倒時冒擊倒煙。獵寮裡的怪行為相同):
    - **野豬**(衝撞): 以 80px/秒左右巡邏, 撞牆或到平台邊緣回頭。玩家與它上下相差 40px 內、在它面向那側 240px 內 → 停下預備 0.5 秒 → 以 420px/秒朝原方向衝撞, 撞牆或到平台邊緣才停, 停下後暈眩 1 秒, 再回到巡邏。
    - **盾兵**(正面擋): 玩家在水平 400px 內且上下相差 120px 內 → 以 40px/秒朝玩家走; 否則以 40px/秒巡邏(撞牆或邊緣回頭)。不離開所在平台(獵寮地板與門外主路地面相連時視為同一平台)。從它面向那側打來的揮砍、箭、衝刺斬被盾擋下(不扣血, 盾閃一下); 從背後、或攻擊判定中心高於它頭頂時照常受傷。爆炸、震波、被擊飛的怪撞上來都不受盾影響。
    - **射手蜂**(射擊): 在出生點左右 120px 內以 60px/秒來回巡飛(碰到地形回頭), 同時上下飄 ±16px(週期 2 秒)。玩家在 400px 內時每 2 秒射一發: 停下瞄準 0.4 秒 → 朝玩家當下位置射出蜂彈(220px/秒直線, 碰到地形消失)。
    - **跳蛙**(跳躍): 每 1.2 秒跳一次(水平 120px、最高 80px), 落地蹲著等下一跳。玩家在 300px 內時朝玩家跳; 否則朝面向跳, 起跳前若落點沒有地面或是牆就先轉向。
30. **職業**(攻擊 `Z`、技能 `X`; 三職業判定框都是 28×44; 移速與技能冷卻再乘升級所的倍率):
    - **劍士**(開局): 移速 260。攻擊 = 面前揮砍(面向側 50×40, 1 傷害, 冷卻 0.3 秒)。技能 = **衝刺斬**: 朝面向衝 160px(0.18 秒, 期間無敵、不受重力, 沿途怪物受 2 傷害), 冷卻 1.2 秒; 衝刺斬擊倒怪物時冷卻立刻歸零; 空中可用, 每次離地只能用 1 次(落地恢復)。擅長: 跳起再衝刺斬跨過 6 格寬坑。
    - **獵人**: 移速 260。攻擊 = **自動射擊**: 每 0.6 秒自動朝 260px 內最近的一隻怪物射一箭(箭速 700px/秒, 飛向目標當下位置, 1 傷害), 射程圈常駐顯示; 另外按 `Z` 可手動朝面向水平射一箭(冷卻 0.4 秒, 飛 600px, 可打裂岩牆)。技能 = **抓鉤**: 220px 內有鉤環時, 以 700px/秒被拉到鉤環, 到達瞬間獲得向上 500px/秒的速度, 冷卻 0.5 秒; 範圍內沒有鉤環則不反應。擅長: 一下上到 5 格高的高台。
    - **炸彈工**: 移速 230。攻擊 = **投彈**: 朝面向拋出炸彈(初速水平 300、向上 500px/秒, 重力同玩家), 碰到地形或怪物即爆炸, 半徑 60px(外緣)內怪物受 2 傷害、裂岩牆直接碎掉(門口落石不受影響); 冷卻 0.6 秒; 玩家不會被自己的爆炸傷到。技能 = **震波**: 以自己為中心半徑 130px(外緣)內的怪物受 1 傷害並被**擊飛**(規則 31), 範圍內的裂岩牆直接碎掉; 空中可用, 冷卻 1.5 秒。擅長: 破裂岩牆、打盾兵、把怪撞成一串。
31. **擊飛**(只有炸彈工的震波會造成): 被打中還活著的怪物朝「遠離炸彈工」的水平方向以 460px/秒飛出, 最多 0.6 秒或撞到地形為止, 期間不受重力、碰到玩家不傷人。
    - 擊飛中的怪碰到其他怪 → 對方受 2 傷害, 若還活著也被擊飛(方向相同)。同一次擊飛中每隻怪只會撞同一隻別的怪一次。
    - 擊飛中撞到地形 → 自己受 1 傷害, 擊飛結束。
    - 擊飛結束仍活著 → 落地(蜂回到飛行)後恢復原本行為。
32. **連鎖字**: 玩家的同一次攻擊(含它引發的擊飛碰撞)擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」。只是顯示, 不改掉落。
33. **裂岩牆**: 實心, 耐久 3。揮砍、箭、衝刺斬每次 -1; 炸彈爆炸或震波碰到直接碎掉。碎掉後消失(冒擊倒煙)。

### 物理(三職業共用)
34. 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格); 移速 260 全速跳躍水平約 156px(過得了 3 格寬的坑)。按住跳躍鍵短於 0.15 秒時初速減半(小跳)。地形為實心方塊(建築的牆、屋頂、內部平台也是), 沒有單向平台、移動平台。

### 擅長與替代路線(三職業都過得了每一關的每個已開放地方)
35. 三種「擅長地形」每種都有不需技能的替代做法, 只是比較慢:
    - **高台**(離下方地面 5 格): 下方掛鉤環 → 獵人一下上去; 其他職業走旁邊的 3~4 段階梯平台(多花約 2~3 秒)。
    - **寬坑**(6 格寬, 坑底是低一層的小路, 不是尖刺): 劍士跳起 + 衝刺斬直接跨過; 其他職業下到坑底小路走過去、再爬階梯上來(多花約 2~3 秒)。
    - **裂岩牆**: 炸彈工一炸就破; 其他職業打 3 下。
36. 只有小捷徑或多拿一點的地方才放擅長地形; 不做整片區域只有某職業進得去。建築對所有職業都一樣, 重建後所有職業都能進; 瞭望塔內的平台每段 2 格高, 不需技能就爬得上。

### 素材用途(每種一種專屬用途)
37. **木材** = 開路: 解鎖關卡、招募職業。**磚瓦** = 重建建築。**時晶** = 回放加速器(每關各自買)。**獸魂** = 升級所強化角色。**復興之城** = 四種都要, 買下即勝利。
