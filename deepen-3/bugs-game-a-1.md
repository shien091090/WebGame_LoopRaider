# Bug: game-a 射手蜂被擊倒後仍會射擊

使用者原話: 「A款還是有蜜蜂死掉 還會繼續攻擊的問題 這之前不是講過了嗎」(deepen-2 回饋已回報過同一個 bug, 這輪重做後仍在)

規格: spec.md 規則 34「被擊倒時冒擊倒煙, **立即消失並停止一切行動**——包括射手蜂瞄準中的那一發也取消」

已查到的原因: `game.js` 每幀 `R.mons.forEach(stepMon)` 對所有怪物都跑, `stepMon` 開頭沒檢查 `m.alive`, 被擊倒的射手蜂(看不見)仍在巡飛、倒數並射出蜂彈。

修法要求:
- 被擊倒的怪物不再跑任何行為(移動、瞄準、射擊、碰撞傷害), 含巢口湧出的怪與巢母
- 瞄準中被擊倒, 那一發取消
- 回放重演時同樣成立(錄影裡被擊倒後不再出現蜂彈)
- 自測: 讓射手蜂進入瞄準後擊倒, 之後數秒內場上不得出現新的蜂彈
