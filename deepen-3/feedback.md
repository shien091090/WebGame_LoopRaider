# 試玩回饋 deepen-3

日期: 2026-11-20
使用者選擇: next
打磨底版: game-a(連環工程; deepen-2 時使用者已說「如果你要用哪一個當底來做打磨版的話 我會覺得可以用A」, 本輪確認以 A 進打磨, 併入下列修改)

## 喜歡
- B 討伐榜: 「B款的討伐榜我覺得不錯 但以一款簡易demo來說 我打算先捨棄這個設計不做 先不要增加遊戲的複雜度」 → 喜歡但本次不做(見「範圍」)

## 不喜歡 / 要改

### 戰鬥與掉落(三款共通)
- 「我想改成怪物頭上顯示血條 且每次攻擊怪物時 怪物每損失1HP 都會掉落素材 如果攻擊力比較高 一次可以打掉很多HP 則會依據打掉的HP掉落素材」 → 改: 怪物頭上顯示血條; 掉落改為每損失 1 HP 掉一份素材(一擊打掉 N HP 就掉 N 份), 不是擊倒時一次掉
- 「攻擊力也可以升級」 → 升級所新增攻擊力強化
- 盾兵: 「盾兵現在劍士跟獵人完全打不死 因為盾兵永遠朝著玩家 普通攻擊根本不可能打到盾兵的背後 這是一個很糟糕的設計 應該改成盾可以被打掉 打掉之後就可以傷害到盾兵本體」; 使用者補充「之前就覺得有問題但忘記跟你回饋」
- 怪物巢穴: 「怪物巢穴我希望改成不要無限重生怪物」 → 巢穴怪物數量有限, 清完就沒有

### 職業
- 獵人攻擊鍵: 「獵人按攻擊鍵能夠射箭我覺得很奇怪 已經是自動攻擊會射箭的狀態了 z鍵應該就沒有反應就好」 → 獵人只有自動射擊, Z 無作用
- 獵人技能改潛行: 「獵人的技能我想改成潛行 把原本場地上的鉤爪圓環移除掉 潛行的效果為按下技能鍵後進入潛行狀態 此時不會被怪物攻擊 且可以穿過怪物 碰到怪物也不會受傷 潛行狀態不會自動攻擊 潛行效果會持續一段時間 接下來就會解除 解除後要等CD才能再次使用 CD時間會比其他角色的技能都還要長一點點」 → 移除鉤爪圓環; 潛行期間無敵、可穿怪、不自動攻擊; 持續一段時間後解除; 冷卻比其他職業技能略長
- 角色高度: 「所有角色改成1格高 可以穿過1格高的空間 現在會一直被卡住體驗很差」 → 所有職業判定框高 1 格, 能通過 1 格高的通道

### UI 與流程
- 道具格: 「現在道具格的選擇我很不滿意 應該改成點擊道具格時再另外打開背包 從中做選擇」 → 選道具格 → 開背包面板 → 從背包選道具裝上
- 終點: 「抵達旗幟時改成跳出按鍵提示(按下鍵完成關卡) 而不是碰到直接就結算」 → 碰到旗幟時顯示「按 ↓ 完成關卡」提示, 按下鍵才結算

### 工程修復(A)
- 這輪 A 是工程鏈(修好一處, 迷霧散開露出下一處): 「我想像起來的不是這樣 工程應該互不干涉 不要用這種逐步打開的方式 因為這代表假設順序是A->B->C 就要強迫玩家不能先修C 一定要照這個順序 我覺得應該要是三個不干涉的區域」 → 每關工程為互不干涉的區域, 修理順序自由; 修復一律疊加紅利(沿用 deepen-2 回饋)

### C 職業工事
- 「C款的關卡設計非常糟糕 首先有一些區域被戰爭迷霧遮住但卻可以跳下去 跳下去之後就上不來了 一定要整關重新」 → 迷霧下的區域在修好前不能進入(要有實體阻擋), 且任何可掉進去的地方都要能爬回來
- 「我也不喜歡根據不同職業解鎖專屬區域的設計」(見衝突段)

## 與已成立假設的衝突
- H04 / H22(職業限定地點 / 專屬機關, 限小捷徑、多拿一點的專屬路線): 使用者不喜歡 C「根據不同職業解鎖專屬區域」 → 使用者選「情境不同」, 原話: 「小捷徑只是讓不同角色從A點到B點的速度有差異 有些角色比較快有些比較慢 而不是整塊區域只給專屬角色 這對其他角色來說 這塊區域形同虛設 且目前也沒有哪個角色可以鑽小捷徑了 因為每個角色都等高 所以這一條基本上可以移除了」。條件更新: 職業差異只表現在同一段路誰比較快 / 比較容易; 不做任何只有某職業進得去的區域或捷徑(含小捷徑, 角色改為等高後也做不到)
- H34(四種怪物行為, 含正面持盾的盾兵 → 戰鬥有特色): 盾兵劍士與獵人打不死 → 使用者答「之前就覺得有問題但忘記跟你回饋」, 記為「情境不同」: 盾兵保留舉盾擋正面, 但盾可以被打壞, 打壞後可傷害本體
