# 連環工程 美術規格(deepen-3 / game-a)

RD 只需讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。以 `<script src="game/art/art.js">` 載入, 取用全域 `window.Art`, 不用 ES module。

## 1. 邏輯畫布

- `Art.canvas = { width: 1280, height: 720 }`(= interface.json 的 canvas, 固定寬, 沒有依裝置加寬)
- 美術一律照 1280×720 設計座標畫, 不自己乘縮放。高 DPI 由 RD 呼叫前整體 `ctx.scale(dpr)`; 美術判斷「是否被縮小」時已扣掉底圖倍率(`canvas.width / 1280`), 不會誤判

## 3. 形狀語言

扁平幾何 + 粗描邊; **玩家白描邊、怪物深描邊紅眼、巢穴系一律發光紫**; 打得破的是暖色平板, 打不破的是冷色圓石或厚石框; 人工修好的結構(木板橋、切石階)有明顯的接縫與釘頭, 和天然地面分得出。

## 4. 理念落實

- **P0 辨識度先於好看**: 每種物件至少用「形狀 + 顏色」兩種方式分開; 裂岩牆(暖色平板、有裂痕)vs 亂石(冷色圓石堆、無裂痕)vs 封印石門(厚框 + 紫爪痕)三種擋路物一眼分得出誰打得破
- **P1 視覺權重跟著決策迫切度走**: 背景與遠山是全畫面最暗最低彩的層; 危險物(尖刺紅尖、怪物紅眼、蜂彈紅橘)與目標(寶箱閃光、終點旗)最亮; 大地圖只有「可解鎖」卡片用金色虛線框、選中卡片用金色實框
- **P2 規則上存在的東西畫面上就必須存在**: 未修斷橋的缺口中段畫極淡的木板虛線(看得出橋要修在哪); 巢口用 5 個小點畫這趟還剩幾隻; 巢母血條常駐; 花費逐項比對, 不足那種變紅; 面板背包每格寫出裝在哪關哪格
- **P3 一個意義一種長相**: 四種素材在地上、資訊列、飛行素材、卡片產量、面板花費、結算都用同一組圖示(`matIcon`); 工程牌在關卡內與關卡面板同一個圖形; 加速器一律時晶青色、強化等級一律獸魂紫紅(花什麼就是什麼色); 巢穴記號在巢穴怪、巢母、巢口、巢穴門、巢母之心上都是同一種發光紫
- **P4 關鍵區分至少兩條通道**: 我方 vs 敵方 = 白描邊 vs 深描邊 + 紅眼; 一般怪 vs 巢穴怪 = 紅眼 vs 發光紫眼 + 紫紋; 三種工程牌 = 箭頭 / 寶箱 / 爪印 三種形狀 + 青 / 金 / 紫; 寶箱關 / 開 = 金色帶閃光 vs 灰褐無光 + 箱蓋位置; 震波 vs 爆炸 = 空心青白環 vs 實心橘火球
- **P7 每個元素都要掙得它的版面**: 卡片上的工程進度只寫一行小字「工程 n/3」; 怪物狀態不加文字標籤, 全靠姿勢(壓低、揚塵、暈星)
- **P9 以最混亂的那一刻驗收**: 縮圖倍率(<0.2)改畫剪影: 玩家 = 職業色圓角塊 + 白框, 怪物 = 本體色橢圓 + 深框(巢穴怪紫框), 迷霧在縮圖裡仍是不透明灰團
- **P13 事件要排隊**: 獲得提示固定一塊、淡入淡出, 由 RD 依序傳; 美術不讓兩塊提示同時留在畫面
- **P15 回饋強度與份量成正比**: 一般怪擊倒煙 48×48, 巢母擊倒煙 2 倍; 連鎖字比 +N 浮字大一號並彈 1.3 倍; 巢母之心的提示框與圖示用紫色外光, 比其他道具醒目
- **P17 進度類圖形與數字分工**: 技能冷卻只用職業圖示外的一圈環(環 = 這次冷卻走到哪, 滿圈變金 = 可用), 不另寫秒數; 巢母血條每格一刻度(格數 = 血量, 數字不重述)
- **P18 重要資訊不能只存在一瞬間**: 「獲得 道具」提示閃過後, 結算面板再列一次; 背包常駐在關卡面板
- **P19 資訊貼著物件**: 工程牌立在工程旁; 巢口剩餘隻數畫在巢口本體上; 巢母血條貼在巢母頭上; 花費畫在卡片自己的縮圖區
- **P21 示意圖要選對錯理解會分岔的例子**: 說明第 4 頁兩張圖用同一關、同一組物件, 只差路線(繞路多撿 vs 直衝), 讓「撿多」與「跑快」的取捨看得出來

## 5. 判讀約定(RD 請照這些傳值)

1. **擊飛方向**: state 沒有飛行方向欄位, 美術約定「飛行方向 = 面向的反方向」(被震波打中的怪多半面向炸彈工)。速度線畫在面向那一側框外 ≤ 36px, 身體傾斜。若 RD 想讓畫面完全正確, 擊飛期間把 `facing` 設成「飛行方向的反方向」即可(建議製作人之後補一個 `flingDir` 欄位)
2. **花費不足**: 凡收 `stock` 的函式逐項比 `cost` 與 `stock`, 只把不足的那一種數字畫紅; `stock` 為 null 時退回 `canAfford === false` → 全部畫紅
3. **縮圖剪影門檻**: 函式讀 `ctx.getTransform()` 的縮放(扣底圖倍率), 小於 **0.2** 改畫剪影 / 簡化色塊; 預覽 0.5、說明頁約 0.3~1 都畫細節版。假 ctx 沒有 `getTransform` 時當成 1
4. **世界物件函式內沒有 `fillText`**(地形、工程、巢口、怪物、特效…), 沉睡的 z、暈眩星、驚嘆都用路徑畫, 跟著縮圖一起縮; 帶字的只有浮字 / 連鎖字 / 提示 / UI 面板。浮字與連鎖字被縮小到 0.6 倍以下時字會反向放大(上限 4 倍)
5. **閒置值**: 所有 `xxT / xxDur` 照介面「閒置時 xxT = xxDur」判讀; 例如巢口 `spawnT < spawnDur` 才畫噴霧
6. **布林欄位只認 `true`**: `top / repaired / end / bottom / open / reached / invuln / hit / brood / lit / selected / newArea / anyAffordable / canAfford / owned / active`; 傳 1、"true" 都當 false(`drawSiteHighlight` 例外: 只有 `active === false` 才不畫)
7. **表外值的預設外觀**(看到這些代表傳錯值): 地形主題 → plain、工程 kind → rubble、素材 → wood、職業 → sword、pose → idle、怪物 state → 各自第一種(walk / fly / crouch)、道具 → bagWood、角色 role → shortcut、卡片 state → sealed、巢口 state → dormant
8. **面板與子區塊**: `drawLevelPanel` 的暗幕與面板底都在預覽框 (60,96,640,360) **挖空**, 預覽框內 RD 要自己鋪滿(畫 `drawBackground` 等); 照介面順序「面板 → 預覽 → 框選」即可, 先後顛倒也不會被蓋
9. **牆鐘動畫**(用 `performance.now()`, 不讀 state): 玩家無敵閃爍(12Hz)、巢口運作中呼吸光、寶箱閃光、終點旗飄動、蜂彈旋轉、框選脈動。位移都在框內
10. **箭的 size 24×6 是沿飛行方向的長寬**, 旋轉後外接框自然變大
11. **野豬 / 巢母預備(windup)**: 以底邊為軸壓扁 10% + 腳後揚塵 + 眼睛變亮; 衝撞(charge)以框內速度線表示; 暈眩頭上冒星(野豬框外上方 ≤ 20px、巢母 ≤ 24px 且不壓血條)

## 6. 畫面文字歸屬

- 每個面板 / 卡片 / 資訊列內的文字(含按鍵提示)由美術畫, 詳見物件表; 大地圖最下方 y=690~714 那行操作提示由 RD 畫
- 美術額外畫的字: `drawFailPanel` 多一行「這趟作廢, 素材不入帳」; `drawHud`(關卡)在冷卻環旁畫一個小 `X` 鍵帽; 關卡面板背包上方小標「背包」、回放資訊區小標「目前回放」
- **說明頁**: 美術只畫示意圖, 只畫在 `(x, y, w, h)` 框內; 頁標題、說明文字、頁碼、翻頁提示、按鍵說明由 RD 畫。圖內只有物件旁短標籤(你、終點旗、12 → 13、素材多 / 秒數長…)與貼在角色旁的鍵帽
