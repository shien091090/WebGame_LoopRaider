# 討伐令 美術風格(deepen-3 / game-b)

RD 只讀這份。函式名、參數、state 欄位照 `interface.json`, 一個不多一個不少(另加任務要求的 `drawGuidePage`)。
**index.html 必須宣告 `<meta charset="utf-8">`**, 否則 art.js 的中文字串在 file:// 下會變亂碼。

## 1. 邏輯畫布尺寸

`window.Art.canvas = { width: 1280, height: 720 }`(等於 interface.json 的 canvas, 固定寬, 不依裝置變寬)。
美術一律照 1280×720 設計座標畫, 不自己乘縮放; RD 呼叫端的 translate / scale(縮圖 0.125、面板預覽 0.5、devicePixelRatio)照用。

**色相驗算**(node 算): 木 32° / 石 213°(低彩度 0.12)/ 晶 188° / 魂 327°; 危險紅 4°。
- 四種素材主通道是**形狀**(圓木 / 六角石 / 菱晶 / 魂火), 色相是第二通道; 木—魂差 65°, 晶—石靠彩度(0.74 vs 0.12)分。
- **最差組合 1**: 獸魂粉(327°)與危險紅(4°)差 37°、灰階 170 vs 127。危險紅只出現在數字、刺尖、愛心、子彈, 從不填在素材圖示上; 驗收那一幀: 升級所獸魂不足時「粉色魂火 + 紅字數字」並排。
- **最差組合 2**: 炸彈工黃(43°)、射手蜂黃(45°)、金色(45°)同色名。靠類別層分: 玩家一律帶**白色外框**(縮圖剪影也是)、怪物一律**深色外框**, 蜂另有黑條紋與翅膀; 金色只用在 UI 與寶箱 / 旗。
- 劍士藍(217°)與盾兵灰藍(212°)、石料、迷霧同色名, 但後三者彩度都 ≤ 0.26, 劍士 0.67。

## 3. 形狀語言

扁平幾何 + 深色描邊; 角色與怪物用圓角 / 圓頭(**尖角三角只留給尖刺**, 草叢、柵欄、背甲都是圓頭); 玩家白框、怪物深框; 「可打破」= 淺色砌塊 + 裂痕, 「打不壞」= 堆疊圓石 / 圓木、沒有裂痕。

## 4. 理念落實

- **P0 辨識度先於好看**: 三種實心擋路物用材質分開——裂岩牆 = 淺褐砌塊 + 黑裂痕(越打越多、缺角)、堵塞隧道 = 灰圓石堆、坍方亂石 = 暗紫黑角石 + 紫爪痕、倒塌柵門 = 交錯圓木堆; 縮圖 0.125 倍改畫剪影(見判讀約定)。
- **P1 視覺權重跟著決策迫切度走**: 背景與遠山低對比; 危險紅只用在會痛的東西; 討伐完成 / 獲得提示放在畫面上方中央 (440,52), 不疊在資訊列與討伐榜上。
- **P2 規則上存在的東西畫面上就存在**: 巢口用 5 個小點畫「這趟還會湧幾隻」; 盾兵的盾畫在面向側且框內; 巢母暈眩時背上露出金色弱點(受傷 ×2 的破綻); 花費逐項比對持有數, 不足的那一種變紅 + 底線; 斷橋中間格畫極淡藍圖虛線, 讓「這裡缺一段橋」看得到。
- **P3 一個意義一種長相**: 素材圖示在地上、資訊列、飛行、花費、結算、面板全用同一個 `matIcon`; 怪物小頭像在討伐榜、面板、結算共用; 巢穴記號(暗紫紋 + 紫眼)在巢穴怪、巢母、亂石、巢口、號角、勳章共用; 說明頁直接呼叫遊戲內函式。
- **P4 關鍵區分走兩條通道**: 素材 = 形狀 + 色相; 敵彈(紅色圓彈)vs 箭(細長木桿 + 綠羽); 爆炸(實心橘火球)vs 震波(空心白青環 + 往外短紋); 寶箱關(金邊、閃光)vs 開(降彩、蓋子後仰、內部黑)。
- **P7 每個元素都要掙得版面**: 討伐榜每欄只放頭像、進度、條、獎勵、加成一行; 說明頁不放頁面文字已講的字。
- **P9 以最混亂的一刻驗收**: 巢穴怪在本體框內加紋與紫眼, 縮圖剪影也保留中央紫點; 被擊飛的怪有傾斜 + 白速度線, 混戰中看得出誰在飛。
- **P13 事件要排隊**: 獲得提示與討伐完成提示共用 (440,52) 一個位置, 由 RD 依序播(美術只畫一則)。
- **P15 回饋強度和份量成正比**: 撿素材 = 小浮字; 連鎖 = 金色大字彈 1.3 倍; 巢母倒下 = 2 倍擊倒煙; 討伐完成 = 金框兩行提示。
- **P17 進度圖形與數字分工**: 討伐令數字給 `prog/need`, 條給「離完成多遠」; 技能冷卻沒有數字, 圈畫總冷卻進度、好了整圈亮起。
- **P18 重要資訊不能只閃一下**: 獲得的獵具 / 勳章在結算面板列出, 勳章常駐在討伐榜底部; 永久加成常駐在每張討伐令的「永久 ...」一行。
- **P19 資訊貼著物件**: 巢口剩餘數畫在巢口下緣; 巢母血條貼在本體上方; 工程牌立在工程旁。
- **P21 示意圖選會分岔的例子**: 說明頁第 4 頁並排繞路 / 直衝兩條路線, 同一關、同樣素材, 只差路線; 第 6 頁前後對照只差「修好」那一項。

## 5. 物件表

`(x, y)` 未註明「左上」時一律為判定框中心。所有函式自己 save / restore。列舉值查不到時畫第一個(預設)值, 數字缺漏或 NaN 時用預設值、極大值會被夾住——看到不該出現的預設外觀時先查傳入值。

### 判讀約定(RD 照這個傳值)

- **擊飛方向**: state 沒有方向欄位, 美術採「飛行方向 = 面向的反方向」(被擊飛的怪多半正面朝炸彈工), 速度線畫在**面向那一側**。RD 想完全正確時, 擊飛期間把 facing 設成**飛行方向的反方向**即可(不必改介面); 若把 facing 設成飛行方向, 速度線會畫反。建議製作人日後補 `flungDir` 欄位。
- **花費**: 凡有 `cost` 的函式逐項比對 `stock`, 只把不足的那一種標紅 + 底線; `stock` 缺漏時才看 `canAfford`(false → 全部標紅)。關卡面板 / 升級所的各項花費都用 state 的 `stock` 比對。
- **一次性特效的閒置值**: 一律 `t = dur`(已播完)時不畫 / 不彈; `t = 0` 是開始第一幀。
- **關卡面板挖空**: 暗幕與面板底在預覽框 (60,96,640,360) **挖空**, 外框畫在框外 1px; RD 呼叫順序前後都不會被蓋, 但預覽內容要自己鋪滿底(`drawBackground` 縮 0.5 會鋪滿)。
- **縮圖剪影**: 物件函式讀 `ctx.getTransform()`, 扣掉底圖倍率(`canvas.width / 1280`)後縮放 < 0.2 時畫剪影: 玩家 = 職業色圓角方塊 + 白框; 怪物 = 本體色橢圓 + 深框, 巢穴怪中央加紫點; 巢母 = 紫黑橢圓 + 紫框 + 血條; 素材 = 填滿 24px 的素材色方塊; 迷霧 = 灰底白斜紋。剪影不出判定框。`getTransform` 不存在時當成 1 倍(細節版)。
- **帶字特效反向放大**: `drawPopup`、`drawChainText` 在縮放 < 0.6 時把字整組放大到相當於 0.6 倍(上限 4 倍), 位移量不放大。
- **世界物件函式內不用 fillText**(巢口的 z、驚嘆號都用路徑), 縮圖 / 預覽縮放不會出現糊字。
- **牆鐘動畫**(`performance.now()` 驅動, 和 state 無關): 無敵閃爍、巢口呼吸光、寶箱閃光、終點旗飄動、蜂翅膀、暈眩星、蜂瞄準紅光、巢母弱點脈動、蜂彈白芯、選取框 / 工程框選 / 升級所記號脈動、獵王殿可買外光。全部位移都在框內。
- **震波判定**: `radius` = 環的**外緣**, 環帶 = [外緣 − 12, 外緣]; 環的外緣在 t = dur 時剛好到 radius。爆炸的 radius 同為外緣。
- **工程框選**只在 active=true 時畫(false 直接返回)。
- **文字歸屬**: 每個面板 / 卡片內的字(含按鍵提示)由美術畫; 大地圖最下方 y=690~714 的操作提示由 RD 畫; 說明頁的頁標題、說明文字、頁碼、翻頁提示由 RD 畫(§8)。
