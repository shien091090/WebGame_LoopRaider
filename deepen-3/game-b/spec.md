# 討伐令(大地圖討伐榜: 回放裡的每一次擊倒都在推進討伐目標; 獵場與巢穴; 巢母掉巢母勳章)

## 概述
單畫面橫向平台動作, 8 個短關卡以樹狀連結在大地圖上。三職業(劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈 + 震波擊飛)各有擅長的地形; 四種怪物都有血量、都會主動移動。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖飛一顆素材進資訊列。
本款的新機制是**討伐令**: 大地圖左上角掛著一面**討伐榜**, 同時列 3 張討伐令(例: 「擊倒跳蛙 12 隻」)。**所有關卡回放裡重演的每一次擊倒、以及跑關過關時這趟的擊倒, 都算進進度**。討伐完成立刻拿一筆素材, 外加一條**永久加成**(例: 全部關卡的跳蛙多掉 1 木材), 然後換上下一張。所以「這關要派誰、走哪條路、打哪些怪」直接決定哪張討伐令跑得快; 回放越多、怪打得越多, 討伐完成越快, 加成又讓每一隻怪更值錢。
每關有 2 處修復: **捷徑工程**(修好通往終點的路變短)與**獵場工程**(修好開出一塊圍起來、怪物成群的獵場, 怪多、寶箱 1)。第 3、6、8 關的獵場是**巢穴**: 巢口每趟湧出怪物, 巢穴裡住著**巢母**; 每次擊倒巢母掉大量素材, **第一次**擊倒另得一枚**巢母勳章**(永久: 全部關卡每擊倒一隻怪多 1 獸魂)。還沒修好的區域蓋著戰爭迷霧。
獵場與巢穴的寶箱開出**獵具**, 裝在關卡的道具格上, 讓指定種類怪物的掉落加倍, 對該關每一次回放都生效, 不必重跑。另有獨立的**升級所**: 招募職業、花獸魂強化移速 / 血量 / 技能冷卻。
四種素材各有一種專屬用途: **木材**開路(解鎖關卡、招募職業)、**石料**修復工程、**時晶**買回放加速器、**獸魂**(只有怪物會掉)強化角色; 終極目標「獵王殿」四種都要。
驗證假設: H11、H33、H45、H56、H57、H59、H60、H75、H89、H90、H91、H92

## 核心循環
看討伐榜上三張討伐令缺哪種怪 → 選關卡 → 在關卡面板修捷徑 / 獵場、裝獵具、選職業 → 進關打怪、撿素材、決定進不進獵場清一群、衝終點 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放一邊產素材、一邊推進討伐令 → 討伐完成拿素材與永久加成 → 用石料修更多獵場, 用木材開新關 / 招募職業, 用時晶加速回放, 用獸魂強化角色 → 回到剛修好的關卡把獵場跑進回放。

## 規則

### 關卡與錄影
1. 每關是不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件只有兩個: 血量歸 0、掉出畫面下緣。失敗時這趟作廢(不存回放、素材、獵具、勳章與這趟的擊倒數都不入帳), 跳出失敗面板。
4. 這趟拿到的素材、獵具、勳章與擊倒數只在過關時才入帳(不論結算時留新或舊, 都入帳)。
5. 素材 4 種: **木材**、**石料**、**時晶**、**獸魂**。地上的素材(木材 / 石料 / 時晶, 地上沒有獸魂)碰到即得 1; 擊倒怪物立即得到該怪的掉落(見規則 33), 不落地。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、職業、面向、動作)、每隻怪物(含巢穴怪與巢母; 位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃、巢母血量)、巢口狀態、所有飛行物(箭、炸彈、蜂彈)、爆炸、震波、已拿走的素材(以素材編號記)、裂岩牆血量、寶箱開關、擊倒煙。另記錄每次地上撿取的時間點、位置、種類, 每次擊倒的時間點、位置與**怪物種類**(野豬 / 盾兵 / 射手蜂 / 跳蛙 / 巢母; 另記是否巢穴怪), 以及抵達終點的位置。**擊倒的掉落量不寫死在錄影裡**, 每次播到時依當下的加成計算(規則 33)。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔); 怪物湧出、移動、攻擊、被擊飛、被擊倒都照錄影重現。每播到一個撿取時間點, 該種素材 +1; 每播到一個擊倒時間點, 得到該怪當下的掉落, 並推進符合的討伐令(規則 22); 每播到抵達終點, 加上「每次通關」類獵具的素材。
8. 回放在大地圖、關卡內、各面板時都持續產出與推進討伐; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。該關每種素材的每分鐘產量 = 一圈內該種素材總數(擊倒掉落用當下的加成計算, 含目前裝的獵具)÷ 錄影秒數 × 60 × 加速器倍率(小數 1 位)。加成一變(討伐完成、拿到勳章、換獵具)卡片與面板上的產量立即更新。
10. 開局: 素材全 0, 只開放第 1 關與劍士, 背包沒有獵具, 所有工程未修, 討伐榜列第 1、2、3 張討伐令、進度 0。

### 大地圖
11. 8 張關卡卡片依樹狀排列(版位見「大地圖版位」), 連線: 1→2、1→3、2→4、2→5、3→6、3→7、5→8、6→8。上分支(2、4、5)多高台與寬坑, 下分支(3、6、7)多怪物與裂岩牆。另有**升級所**卡片(第 1 關下方)、**討伐榜**(第 1 關上方, 只顯示、不能選)與終極目標**獵王殿**卡片(最右)。
12. 卡片狀態: **封鎖**(連到它的前一關都還沒過關; 畫鎖與花費, 不能買)、**可解鎖**(至少一個前一關已過關; `Z` 花木材解鎖)、**已開放**(未過關)、**已過關**(縮圖重演回放、下方顯示四種素材每分鐘產量)。第 8 關的前一關是 5 或 6, 任一過關即可解鎖。
13. **素材飛行**: 大地圖畫面(沒開任何面板)時, 回放每得到 1 個素材, 就從縮圖裡該素材被拿到的位置(錄影位置 × 縮圖倍率 + 縮圖左上角; 擊倒掉落從怪物倒下處、每次通關的獵具素材從終點旗處)飛出一顆該種素材, 0.7 秒沿弧線飛進資訊列該種素材圖示, **飛到時持有數才 +1**, 計數跳一下。一次得到 N 個就飛 N 顆(同時出發, 起點各自隨機錯開 ±6px; N > 5 時只飛 5 顆, 最後一顆帶剩下的數量)。開著面板或在關卡內時不飛, 直接 +。討伐獎勵的素材不飛, 直接入帳並讓計數跳一下。
14. **新區域標記**: 該關目前回放是在該關最近一次修好工程之前錄的 → 卡片縮圖角落標「新區域」, 直到存下一條在修好之後錄的回放(結算採用新的那趟)才消失。
15. 游標: `←` `→` 換到左 / 右一欄中垂直位置最接近的卡片, `↑` `↓` 在同一欄內上下移(到頭不動)。欄由左到右: 第 1 關、升級所 / 第 2、3 關 / 第 4~7 關 / 第 8 關 / 獵王殿。討伐榜不在游標順序裡。
16. 在卡片上按 `Z`: 封鎖 → 不反應; 可解鎖 → 木材夠就扣除並變成已開放, 不夠不反應; 已開放或已過關 → 打開**關卡面板**。升級所 → 打開**升級所頁面**。獵王殿 → 四種都夠就買下(勝利), 不夠不反應。大地圖上按 `X` = 重開說明頁。

### 關卡面板(先選關卡、再選職業)
17. 面板分四列, `↑` `↓` 換列, 打開時在第 1 列; `X` 關閉回大地圖。左邊是該關的靜態預覽(目前地形含修復狀態與迷霧、素材、怪物出生位置、寶箱、工程位置; **不畫任何路線線條**), 下方是獵具背包與目前回放資訊(含這條回放一圈裡各種怪的擊倒數)。
    - **職業列**: `←` `→` 在劍士 / 獵人 / 炸彈工間選, 預設是這關上次用的職業(沒有就是劍士)。選到已招募的按 `Z` = 用這個職業進關; 未招募的格子畫鎖與「到升級所招募」, 按 `Z` 不反應。
    - **工程列**: `←` `→` 選捷徑工程 / 獵場工程(第 3、6、8 關顯示為巢穴), 預覽上框出位置。未修的按 `Z` = 石料夠就修好(扣除, 地形立即改變、該區迷霧散開), 不夠不反應; 已修好的顯示「已完工」。兩處可依任意順序修。
    - **道具格列**: `←` `→` 選 1、2 號格。按 `Z` = 換下一件獵具, 依序「空 → 背包第 1 件 → 第 2 件 → … → 空」循環; 換到正裝在別處(別格或別關)的獵具時, 直接從原處搬過來(原處變空)。背包沒有獵具時不反應。
    - **加速器列**: `Z` = 時晶夠就買下一級(扣除), 已滿或不夠不反應。

### 升級所(獨立頁面)
18. 大地圖選升級所按 `Z` 打開; `X` 關閉回大地圖。分四列, `↑` `↓` 換列:
    - **招募列**: `←` `→` 選獵人 / 炸彈工; `Z` = 木材夠就招募(扣除, 之後所有關卡面板都能選), 已招募或不夠不反應。
    - **移速列** / **血量列** / **冷卻列**: `Z` = 獸魂夠就升一級(扣除), 已滿或不夠不反應。
19. 強化對三職業都有效, 只影響之後的跑關; 已存的回放照錄影重演, 不會變快(想讓回放變快要重跑)。

### 討伐令(本款特有)
20. **討伐榜**: 大地圖左上角固定顯示 3 張討伐令(第 1~3 欄), 每張畫目標怪物、需求數、目前進度、獎勵素材與永久加成。討伐令依「討伐令清單」的順序上榜。
21. **計數**: 討伐令上榜後才開始計。每一次擊倒, 若符合該張的目標就 +1(一隻巢穴野豬同時符合「野豬」「巢穴怪」「任何怪物」)。計數來源: (a) 任何一關的回放播到擊倒時間點(大地圖、關卡內、面板中都算); (b) 跑關過關時, 這趟的擊倒在過關那一刻一次加進去(失敗不算)。
22. **完成**: 進度到需求數的那一刻, 立即得到獎勵素材(直接入帳)與永久加成(立即對所有關卡的回放與跑關生效), 該欄換上清單中下一張(進度從 0 開始); 清單用完後該欄顯示「全部完成」。在大地圖時當場跳出**討伐完成提示**(2.5 秒); 在關卡內或面板中完成的, 等回到大地圖畫面再依序跳出。同一時間完成多張就依序各跳一次。

### 獵場與巢穴(修復)
24. 每關 2 處工程: **捷徑工程**(斷橋 / 崩梯 / 堵塞隧道; 修好後通往終點的路變短, 本身不放素材與怪物)與**獵場工程**(第 1、2、4、5、7 關是**獵場柵門**, 第 3、6、8 關是**巢穴通道**)。位置見關卡構成。兩處修復互不影響、紅利疊加: 修好的實心格不落在任何原本可走的路上; 獵場 / 巢穴入口一定在捷徑起點之前的主路上(走捷徑也不會錯過)。RD 排完地形要逐關自查: 任何修復組合下, 修之前走得到的每個素材 / 寶箱 / 終點都仍走得到, 主路直衝時間不變長。
25. 捷徑結構:
    - **斷橋**: 未修 = 一段 8~12 格寬的缺口(下方是尖刺或深淵), 只剩兩端殘樁, 不是實心; 任何職業(含劍士跳起 + 衝刺斬, 最遠約 6 格)都跨不過。修好 = 整排實心橋面。
    - **崩梯**: 未修 = 地上一堆碎石(不是實心、可穿過), 上方平台離下方地面 7 格以上且 220px 內沒有鉤環, 任何職業都上不去。修好 = 一段每階 2 格高的實心階梯。
    - **堵塞隧道**: 未修 = 隧道口塞滿亂石(實心、打不壞也炸不壞, 外觀要和裂岩牆一眼分得出)。修好 = 亂石消失。
26. **獵場**(第 1、2、4、5、7 關): 一塊約 12×4 格、由矮牆圍起來的平坦場地, 入口是 2 格寬 × 2 格高的**獵場柵門**。未修 = 柵門倒塌堆成一堆實心木樁(打不壞也炸不壞), 進不去。修好 = 柵門立起、敞開(只剩門框, 不擋路)。獵場裡有 5 隻怪(種類見關卡構成, 開場就在, 每趟都重新出現)、地上素材 2、寶箱 1。**獵場裡的怪不會走出柵門**(把門框當成牆回頭; 跳蛙把門框當成牆先轉向), 玩家要進去打。5 隻怪的出生點彼此在 160px 內, 讓震波擊飛有東西可撞。
27. **巢穴**(第 3、6、8 關): 主路旁的地下通道被坍方亂石堵住(實心、打不壞也炸不壞), 通道後是巢穴室(約 12×4 格, 地面平坦), 最裡側有**巢口**, 巢穴室裡住著**巢母**, 另有寶箱 1。修好 = 亂石消失, 通道與主路相連且地面平順。
    - 巢口: 修好後每一趟開始後 1 秒湧出第 1 隻, 之後每 2.5 秒 1 隻, 一趟最多 5 隻(湧滿後變暗)。種類照該關「巢口怪物」清單依序輪流; 湧出的怪出現在巢口前方、面向通道, 照一般行為行動(野豬、盾兵、跳蛙會沿巢穴室走出通道進到主路; 射手蜂在出生點附近巡飛)。巢口打不壞。玩家沒進巢穴也照湧。
    - 巢穴怪: 基本掉落 = 同種怪的一般掉落 + 獸魂 1。
    - **巢母**(64×56): 血 12。在巢穴室內以 50px/秒巡邏(撞牆、到平台邊緣或到通道口就回頭, 不出巢穴)。玩家與它上下相差 80px 內、在它面向那側 320px 內 → 停下預備 0.8 秒 → 以 380px/秒衝撞, 撞牆或到邊緣 / 通道口才停, 停下後暈眩 1.5 秒; **暈眩中受到的傷害 ×2**。碰到玩家扣 1。不會被擊飛(震波只造成 1 傷害), 被擊飛的怪撞到它照常受 2 傷害。每次擊倒基本掉落 **獸魂 6 + 石料 4 + 時晶 3**。
    - **巢母勳章**: 該關**第一次**擊倒巢母時另得 1 枚(畫面上方提示「獲得 巢母勳章」, 過關時入帳)。每枚勳章永久讓**全部關卡**每擊倒一隻怪(含巢穴怪與巢母)多得獸魂 1; 3 枚可累加。
28. **戰爭迷霧**: 獵場、巢穴通道與巢穴室在修好前蓋著迷霧——關卡內、縮圖、面板預覽都蓋。迷霧不是實心, 但未修時那塊區域本來就進不去。工程結構(殘樁、碎石、亂石、倒塌柵門)與工程牌畫在迷霧之上、看得到。修好時迷霧在 0.8 秒內淡出散開(在面板預覽上就看得到散開)。

30. 工程在關卡裡看得到: 未修時旁邊立一面**工程牌**(畫捷徑 / 獵場 / 巢穴的標誌), 修好後工程牌消失。工程牌不是實心、不擋路。

### 道具格(獵具)
31. 每關 2 個道具格(1、2 號), 已開放的關卡就能裝。獵具效果**依現在的配置**對該關每一圈回放與每一趟跑關生效, 改裝後下一個得到素材的時間點起就照新配置算, 卡片與面板上的每分鐘產量立即更新; 不必重跑。
32. 獵具來源: 每關獵場或巢穴裡的寶箱 1 個(內含固定獵具, 見關卡構成; 碰到即打開, 畫面上方提示「獲得 <獵具名>」), 過關時放進背包; 拿過的寶箱之後的趟數都是打開的空箱。背包最多 8 件。一件獵具同時只裝在一格。獵具:
    - **捕蛙籠**: 跳蛙掉落 +100%。**野豬獵叉**: 野豬掉落 +100%。**捕蜂網**: 射手蜂掉落 +100%。**破盾錘**: 盾兵掉落 +100%。**巢獵號角**: 巢穴怪與巢母掉落 +100%。**魂燈**: 每次通關 +3 獸魂。

33. **擊倒掉落計算**(每種素材各自算, 取整): (該怪基本掉落 × 討伐令的巢母 ×2〔只對巢母〕 + 討伐令永久加成 + 勳章數〔獸魂〕) × (1 + 該關獵具加成)。

### 結算
34. 過關時該關沒有回放 → 直接存成回放。已有回放 → 結算面板並列「這一趟」與「目前回放」的秒數、四種素材的每分鐘產量與一圈擊倒數(兩邊都用目前的加成與獵具配置計算), `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
35. 玩家血量 3(升級後 4 / 5); 碰到怪物(被擊飛中的除外)或蜂彈扣 1, 之後無敵 1 秒並被往反方向彈開 80px。每次進關回滿。
36. **尖刺**: 碰到扣 1 血(不即死), 之後無敵 1 秒並被往上彈起(向上 520px/秒, 水平速度歸 0)。無敵中再碰尖刺不扣血。兩根刺中間一格寬的窄落腳點可以保留。
37. **怪物**(四種行為, 全部會主動移動, 都有血量; 被擊倒時冒擊倒煙, **立即消失並停止一切行動**——包括射手蜂瞄準中的那一發也取消):
    - **野豬**(衝撞): 以 80px/秒左右巡邏, 撞牆或到平台邊緣回頭。玩家與它上下相差 40px 內、在它面向那側 240px 內 → 停下預備 0.5 秒 → 以 420px/秒朝原方向衝撞, 撞牆或到平台邊緣才停, 停下後暈眩 1 秒, 再回到巡邏。
    - **盾兵**(正面擋): 玩家在水平 400px 內且上下相差 120px 內 → 以 40px/秒朝玩家走; 否則以 40px/秒巡邏(撞牆或邊緣回頭)。不離開所在平台(巢穴室與通道、主路地面相連時視為同一平台)。從它面向那側打來的揮砍、箭、衝刺斬被盾擋下(不扣血, 盾閃一下); 從背後、或攻擊判定中心高於它頭頂時照常受傷。爆炸、震波、被擊飛的怪撞上來都不受盾影響。
    - **射手蜂**(射擊): 在出生點左右 120px 內以 60px/秒來回巡飛(碰到地形回頭), 同時上下飄 ±16px(週期 2 秒)。玩家在 400px 內時每 2 秒射一發: 停下瞄準 0.4 秒 → 朝玩家當下位置射出蜂彈(220px/秒直線, 碰到地形消失)。
    - **跳蛙**(跳躍): 每 1.2 秒跳一次(水平 120px、最高 80px), 落地蹲著等下一跳。玩家在 300px 內時朝玩家跳; 否則朝面向跳, 起跳前若落點沒有地面或是牆就先轉向。
38. **職業**(攻擊 `Z`、技能 `X`; 三職業判定框都是 28×44; 移速與技能冷卻再乘升級所的倍率):
    - **劍士**(開局): 移速 260。攻擊 = 面前揮砍(面向側 50×40, 1 傷害, 冷卻 0.3 秒)。技能 = **衝刺斬**: 朝面向衝 160px(0.18 秒, 期間無敵、不受重力, 沿途怪物受 2 傷害), 冷卻 1.2 秒; 衝刺斬擊倒怪物時冷卻立刻歸零; 空中可用, 每次離地只能用 1 次(落地恢復)。擅長: 跳起再衝刺斬跨過 6 格寬坑。
    - **獵人**: 移速 260。攻擊 = **自動射擊**: 每 0.6 秒自動朝 260px 內最近的一隻怪物射一箭(箭速 700px/秒, 飛向目標當下位置, 1 傷害), 射程圈常駐顯示; 另外按 `Z` 可手動朝面向水平射一箭(冷卻 0.4 秒, 飛 600px, 可打裂岩牆)。技能 = **抓鉤**: 220px 內有鉤環時, 以 700px/秒被拉到鉤環, 到達瞬間獲得向上 500px/秒的速度, 冷卻 0.5 秒; 範圍內沒有鉤環則不反應。擅長: 一下上到 5 格高的高台。
    - **炸彈工**: 移速 230。攻擊 = **投彈**: 朝面向拋出炸彈(初速水平 300、向上 500px/秒, 重力同玩家), 碰到地形或怪物即爆炸, 半徑 60px(外緣)內怪物受 2 傷害、裂岩牆直接碎掉(亂石、倒塌柵門不受影響); 冷卻 0.6 秒; 玩家不會被自己的爆炸傷到。技能 = **震波**: 以自己為中心半徑 130px(外緣)內的怪物受 1 傷害並被**擊飛**(規則 39), 範圍內的裂岩牆直接碎掉; 空中可用, 冷卻 1.5 秒。擅長: 破裂岩牆、打盾兵、把怪撞成一串。
39. **擊飛**(只有炸彈工的震波會造成; 巢母不會被擊飛): 被打中還活著的怪物朝「遠離炸彈工」的水平方向以 460px/秒飛出, 最多 0.6 秒或撞到地形為止, 期間不受重力、碰到玩家不傷人。
    - 擊飛中的怪碰到其他怪(含巢母) → 對方受 2 傷害, 若還活著也被擊飛(方向相同; 巢母只受傷不飛)。同一次擊飛中每隻怪只會撞同一隻別的怪一次。
    - 擊飛中撞到地形 → 自己受 1 傷害, 擊飛結束。
    - 擊飛結束仍活著 → 落地(蜂回到飛行)後恢復原本行為。
40. **連鎖字**: 玩家的同一次攻擊(含它引發的擊飛碰撞)擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」。只是顯示, 不改掉落。
41. **裂岩牆**: 實心, 耐久 3。揮砍、箭、衝刺斬每次 -1; 炸彈爆炸或震波碰到直接碎掉。碎掉後消失(冒擊倒煙)。

### 物理與通道尺寸(三職業共用)
42. 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格); 移速 260 全速跳躍水平約 156px(過得了 3 格寬的坑)。按住 `↑` 短於 0.15 秒時初速減半(小跳)。地形為實心方塊, 沒有單向平台、移動平台。

### 擅長與替代路線(三職業都過得了每一關的每個已開放地方)

    - **裂岩牆**: 炸彈工一炸就破; 其他職業打 3 下。
