# 職業工事 — 美術規格(deepen-3 / game-c)

> RD 只讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。`art.js` 以一般 `<script src>` 載入, 全域 `window.Art`。

## 1. 邏輯畫布尺寸

- `Art.canvas = { width: 1280, height: 720 }`, 等於 interface.json 的 canvas, 固定寬度(沒有依裝置改寬)。
- 美術照 1280×720 設計座標畫, 不自己乘縮放。RD 若做整體縮放 / 高 DPI, 在呼叫前對 ctx 做, 美術函式讀 `ctx.getTransform()` 時會先除以「`ctx.canvas.width / 1280`」, 不會誤判成縮圖。

**張力(寫明讓製作人驗收)**:
- 炸彈工橘 `#ff8c1a` 與木材棕 `#b8743a` 色相同為約 30°。兩者類別不同(角色 / 工事 vs 素材圖示), 靠明度(亮橘 vs 暗棕)與形狀(人形、鐵箍 vs 圓木)分開; 最難分的一幀: 大地圖縮圖裡炸彈工剪影(圓角方塊)旁邊一顆木材(圓點)。
- 跳蛙黃綠 `#8cc63f` 與獵人綠 `#35c159` 色相差約 47°。怪物一律帶深色粗外框 + 怪物眼, 玩家是人形 + 膚色頭, 類別層先分開。
- 危險紅同時用在「會痛」與「花費不足」, 兩者都是「不行」; 不足只出現在面板 / 卡片的數字上, 不會出現在關卡世界裡。

## 3. 形狀語言

圓角、深色(`#1a1a24`)外描、扁平填色加一塊高光; **尖角只給會痛的東西**(尖刺、蜂彈發射端), 其他方向記號一律用圓頭箭頭; 職業 = 顏色, 三種工事各穿擅長職業的顏色。

類別層的區分:
- 地形(地面、裂岩牆、工事結構): 方格填滿 40×40、無外描或只有內部線。
- 會動的東西(玩家、怪物): 有外描的圓角剪影。玩家 = 人形 + 膚色頭 + 職業色身體; 怪物 = 深外框 + 怪物眼。
- 可撿的東西(素材、寶箱): 小圖示 + 輕微上下浮動 + 白色閃光星。
- UI(面板、卡片): 深藍底板 + 細框線。

## 4. 理念落實

- **P0 辨識度先於好看**: 三種「實心、擋路」的格(封坑木樁 / 坑底落石 / 裂岩牆)用三種材質分開: 直立圓木 + 橘鐵箍 / 深灰大圓石 / 淺米色磚 + 黑裂痕, 只有裂岩牆有裂痕(= 打得破), 裂痕隨 hp 3→1 變多並缺一角。
- **P1 視覺權重跟著決策迫切度走**: 關卡背景是低對比淡天空; 最亮、最飽和的顏色留給玩家、怪物、危險紅與可撿素材; 迷霧是灰紫低飽和; 射程圈是半透明虛線, 不搶圈內物件。
- **P2 規則上存在的東西畫面上就存在**: 巢口剩餘隻數用框內 5 點表示; 巢母暈眩時甲殼裂開露出橘色發光核心(受傷 ×2 的破綻); 盾兵的盾永遠畫在面向側; 修好的工事三點進度畫在卡片上; 花費逐項比對, 不夠的那種數字變紅。
- **P3 一個意義一種長相**: 素材圖示(地上、資訊列、飛行、浮字、面板、卡片、花費)全部共用同一組畫法; 工程牌標誌 = 關卡面板工事格的標誌 = 卡片上的三色點順序(鉤環架綠 / 跳崖台藍 / 爆破礦坑橘); 巢穴記號(紫紋 + 發光眼)在巢穴怪、巢母、巢口、面板巢母小頭像一致。
- **P4 關鍵區分至少兩條通道**: 敵方蜂彈 = 紅色圓球(顏色 + 圓形), 玩家箭 = 細長棕桿 + 白箭頭 + 綠羽(顏色 + 長條); 炸彈爆炸 = 實心火球(面), 震波 = 外擴白邊橘環 + 朝外方向記號(線 + 方向); 寶箱關 = 紅金 + 閃光 vs 開 = 灰褐 + 打開蓋子。
- **P7 每個元素都要掙得版面**: 說明頁示意圖只放 guide 要的東西(第 1、4 頁不畫工事、工程牌、迷霧; 第 5 頁不畫數字); 地圖背景不畫路線; 工程牌只有圖形不帶字。
- **P9 以最混亂的那一刻驗收**: 怪物一律帶深色粗外框, 擊飛中、巢穴怪成群疊在礦坑裡時仍分得開; 縮圖 0.125 倍改畫剪影(玩家 = 職業色圓角方塊 + 白框, 怪物 = 本體色橢圓 + 深框 / 巢穴怪紫框)。
- **P13 事件要排隊**: 獲得提示一次只畫一塊(採集器或寶庫); 同一趟兩件同時發生時, 請 RD 依序播(前一塊 1.5 秒播完再下一塊), 不要同時呼叫兩次。
- **P15 回饋強度和份量成正比**: 一般怪倒下 = 48px 煙; 巢母倒下 = 96px 煙(big); 連鎖字比 +N 浮字大一級且帶彈跳; 寶箱開 = 上方提示條(全關卡唯一的橫條提示)。
- **P17 進度類圖形與數字分工**: 技能冷卻只有圖形沒有數字, 依邊界畫總進度(灰扇形長滿 = 可用, 可用時換成職業色 + 白框); 加速器等級用兩格小方塊 + 倍率數字(數字給倍率, 格子給還剩幾級)。
- **P18 重要資訊不能只存在一瞬間**: 「獲得 <採集器名>」除了 1.5 秒提示, 結算面板與背包都會再列; 「寶庫將打開」在結算面板列為「寶庫已打開」。
- **P19 資訊貼著物件**: 工程牌立在工事旁; 巢口剩餘數畫在巢口本體上; 巢母血條貼在本體正上方; 「新區域」標在該卡縮圖左上角內側。
- **P21 示意圖選對錯理解會分岔的例子**: 第 4 頁兩張圖用同一關、同一組素材與怪物, 只差路線, 讓「多撿」與「跑快」只差一個變數; 第 5 頁左右兩格只差修好與否(結構、落石、工程牌、迷霧四項同時變)。

## 7. 判讀約定(RD 照這些傳值 / 算判定)

1. **擊飛方向**: state 沒有方向欄位。美術約定「被擊飛的怪飛向面向的反方向」(被震波打中的怪多半正面朝炸彈工), 速度線畫在**面向那一側**的框外。**請 RD 在怪物被擊飛時把 facing 設成「朝向炸彈工」**(= 飛行方向的反向), 畫面才對; 回報已請製作人補方向欄位。
2. **爆炸 / 震波 radius = 外緣**: 爆炸實心火球最大半徑 = radius; 震波環外緣在 t=dur 時 = radius, 環寬 12px 畫在外緣內側; 判定是整個圓內(規則「半徑內」), 環只是外緣的視覺, 不是只有環帶才算命中。
3. **射程圈 radius = 外緣**, 線寬往內畫。
4. **縮圖剪影門檻**: 呼叫端縮放(已扣除底圖倍率)< 0.2 時, 世界物件改畫剪影: 玩家 = 職業色圓角方塊 + 白框; 怪物 = 本體色橢圓 + 深框(巢穴怪 / 巢母紫框); 素材 = 該色圓點; 工事 = 職業色塊(鉤環架綠、跳崖台藍、坑底落石深灰 + 藍頂、封坑木樁棕 + 橘箍); 尖刺 = 紅帶; 巢母血條照畫。外框線寬以畫面 1px 換算。0.5 倍(面板預覽)仍畫細節版。
5. **縮圖內的字**: 世界物件函式(會被縮圖 / 預覽重用的那組)完全不用 `fillText`(巢口的 z 用路徑畫)。浮字 / 連鎖字被縮到 < 0.6 倍時, 字整組反向放大到畫面約 12px(倍率上限 6), 上移量不放大。
6. **關卡面板預覽框已挖空**: 暗幕與面板底都在 (60,96,640,360) 挖空(evenodd), 外框畫在框外 1px。預覽內容要自己鋪滿(drawBackground 等), 先畫或後畫面板結果相同。
7. **花費不足**: 凡有 cost + stock 的函式逐項比 `stock[k] < cost[k]` → 該項數字紅; stock 缺漏時退回 `canAfford === false` → 全部標紅。
8. **布林欄位只認 `=== true`**: open / reached / repaired / bottom / invuln / hit / brood / selected / newArea / owned / nest / lit / big 等, 缺漏一律當 false。
9. **閒置值**: 一次性特效 t ≥ dur 時函式自己不畫(爆炸、震波、擊倒煙、浮字、連鎖字、獲得提示); 巢口 spawnT ≥ spawnDur = 閒置。
10. **牆鐘動畫**(`performance.now()`): 無敵閃爍、巢口呼吸光、寶箱閃光、終點旗飄動、暈眩星旋轉、射手蜂 aim 閃爍、選取框 / 工事框選脈動。位移都在框內。
11. **說明頁示意圖的飛行素材**: drawFlyingMaterial 的拖尾以遊戲內資訊列座標為終點; 第 3 頁圖裡的資訊列不在 (36,20), 美術在說明頁內先平移再呼叫, RD 不必處理。
