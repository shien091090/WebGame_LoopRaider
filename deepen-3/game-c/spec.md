# 職業工事(每關 3 處工事各為一個職業量身打造; 採集器; 巢母寶庫)

## 概述
單畫面橫向平台動作, 8 個短關卡以樹狀連結在大地圖上。三職業(劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈 + 震波擊飛)各有擅長的地形; 四種怪物都有血量、都會主動移動。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖飛一顆素材進資訊列。
本款的新機制是**職業工事**: 每關有 3 處破損的工事, **各為一個職業量身打造**——**鉤環架**(獵人)、**跳崖台**(劍士)、**爆破礦坑**(炸彈工)。修好一處就開出一塊新區域, **擅長的職業進出又快又順, 其他職業也進得去但要多繞、多打**。三處裡有一處是**捷徑**(開出一條通往終點的近路), 另兩處是**採集區**(高處晶脈、崖對岸林場、礦坑石脈各藏一種主要素材)。哪一處是捷徑每關不同。所以「這關修了哪些工事 + 派哪個職業」= 這關變成誰的主場、主產什麼。修復紅利一律疊加, 修越多這關越好跑。
第 3、6、8 關的爆破礦坑深處是**巢穴**: 巢口每趟湧出怪物, 巢穴裡住著**巢母**; 每次擊倒巢母掉大量素材, **第一次**擊倒會打開巢穴後方的**巢母寶庫**——從此每一趟都能進寶庫撿一大堆素材。還沒修好的區域蓋著戰爭迷霧。
採集區的寶箱開出**採集器**, 裝在關卡的道具格上, 讓該關每撿到某種素材多 1 個, 對該關每一次回放都生效, 不必重跑。另有獨立的**升級所**: 招募職業、花獸魂強化移速 / 血量 / 技能冷卻。
四種素材各有一種專屬用途: **木材**開路(解鎖關卡、招募職業)、**石料**修復工事、**時晶**買回放加速器、**獸魂**(只有怪物會掉)強化角色; 終極目標「工匠之都」四種都要。
驗證假設: H11、H33、H56、H57、H59、H60、H75、H89、H93、H94、H95

## 核心循環
大地圖看四種素材缺哪種 → 選關卡 → 在關卡面板修工事(迷霧散開)、裝採集器、選擅長這關工事的職業 → 進關打怪、撿素材、鑽進修好的採集區或走捷徑、開寶箱、打巢母、衝終點 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放產出、素材飛進資訊列 → 用石料修更多工事, 用木材開新關 / 招募職業, 用時晶加速回放, 用獸魂強化角色 → 回到剛修好的關卡, 換上擅長的職業再跑。

## 規則

### 關卡與錄影
1. 每關是不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件只有兩個: 血量歸 0、掉出畫面下緣。失敗時這趟作廢(不存回放、素材與採集器都不入帳, 巢母寶庫不會打開), 跳出失敗面板。
4. 這趟拿到的素材與採集器只在過關時才入帳(不論結算時留新或舊, 都入帳)。巢母首殺也在過關時才生效(寶庫從下一趟起打開)。
5. 素材 4 種: **木材**、**石料**、**時晶**、**獸魂**。地上的素材(木材 / 石料 / 時晶, 地上沒有獸魂)碰到即得 1; 擊倒怪物立即得到該怪的掉落(見數值表), 不落地。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、職業、面向、動作)、每隻怪物(含巢穴怪與巢母; 位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃、巢母血量)、巢口狀態、所有飛行物(箭、炸彈、蜂彈)、爆炸、震波、已拿走的素材(以素材編號記)、裂岩牆血量、寶箱開關、擊倒煙。另記錄每次撿取的時間點、位置、種類, 每次擊倒的時間點、位置與掉落, 以及抵達終點的位置。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔); 怪物湧出、移動、攻擊、被擊飛、被擊倒都照錄影重現。每播到一個撿取時間點, 該種素材 +1(再加目前裝的採集器加成, 規則 30); 每播到一個擊倒時間點, 得到該怪的掉落(再加採集器加成)。
8. 回放在大地圖、關卡內、各面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。該關每種素材的每分鐘產量 = 一圈內該種素材總數(含目前裝的採集器加成)÷ 錄影秒數 × 60 × 加速器倍率(小數 1 位)。
10. 開局: 素材全 0, 只開放第 1 關與劍士, 背包沒有採集器, 所有工事未修。

### 大地圖
11. 8 張關卡卡片依樹狀排列(版位見「大地圖版位」), 連線: 1→2、1→3、2→4、2→5、3→6、3→7、5→8、6→8。上分支(2、4、5)多高台與寬坑, 下分支(3、6、7)多怪物與裂岩牆。另有**升級所**卡片(第 1 關下方)與終極目標**工匠之都**卡片(最右)。
12. 卡片狀態: **封鎖**(連到它的前一關都還沒過關; 畫鎖與花費, 不能買)、**可解鎖**(至少一個前一關已過關; `Z` 花木材解鎖)、**已開放**(未過關)、**已過關**(縮圖重演回放、下方顯示四種素材每分鐘產量)。第 8 關的前一關是 5 或 6, 任一過關即可解鎖。
13. **素材飛行**: 大地圖畫面(沒開任何面板)時, 回放每得到 1 個素材, 就從縮圖裡該素材被拿到的位置(錄影位置 × 縮圖倍率 + 縮圖左上角; 擊倒掉落從怪物倒下處)飛出一顆該種素材, 0.7 秒沿弧線飛進資訊列該種素材圖示, **飛到時持有數才 +1**, 計數跳一下。一次得到 N 個就飛 N 顆(同時出發, 起點各自隨機錯開 ±6px; N > 5 時只飛 5 顆, 最後一顆帶剩下的數量)。開著面板或在關卡內時不飛, 直接 +。
14. **新區域標記**: 該關目前回放是在該關最近一次修好工事(或巢母寶庫打開)之前錄的 → 卡片縮圖角落標「新區域」, 直到存下一條在那之後錄的回放(結算採用新的那趟)才消失。
15. 游標: `←` `→` 換到左 / 右一欄中垂直位置最接近的卡片, `↑` `↓` 在同一欄內上下移(到頭不動)。欄由左到右: 第 1 關、升級所 / 第 2、3 關 / 第 4~7 關 / 第 8 關 / 工匠之都。
16. 在卡片上按 `Z`: 封鎖 → 不反應; 可解鎖 → 木材夠就扣除並變成已開放, 不夠不反應; 已開放或已過關 → 打開**關卡面板**。升級所 → 打開**升級所頁面**。工匠之都 → 四種都夠就買下(勝利), 不夠不反應。大地圖上按 `X` = 重開說明頁。

### 關卡面板(先選關卡、再選職業)
17. 面板分四列, `↑` `↓` 換列, 打開時在第 1 列; `X` 關閉回大地圖。左邊是該關的靜態預覽(目前地形含修復狀態與迷霧、素材、怪物出生位置、寶箱、工事位置; **不畫任何路線線條**), 下方是採集器背包與目前回放資訊。
    - **職業列**: `←` `→` 在劍士 / 獵人 / 炸彈工間選, 預設是這關上次用的職業(沒有就是劍士)。每格下方標出「這關擅長的已修工事數」(例: 獵人『擅長 1 處』), 讓玩家看出修好的工事對誰有利。選到已招募的按 `Z` = 用這個職業進關; 未招募的格子畫鎖與「到升級所招募」, 按 `Z` 不反應。
    - **工事列**: `←` `→` 選鉤環架 / 跳崖台 / 爆破礦坑(固定這個順序), 預覽上框出位置。未修的按 `Z` = 石料夠就修好(扣除, 地形立即改變、該區迷霧散開), 不夠不反應; 已修好的顯示「已完工」。三處可依任意順序修。
    - **道具格列**: `←` `→` 選 1、2 號格。按 `Z` = 換下一個採集器, 依序「空 → 背包第 1 個 → 第 2 個 → … → 空」循環; 換到正裝在別處(別格或別關)的採集器時, 直接從原處搬過來(原處變空)。背包沒有採集器時不反應。
    - **加速器列**: `Z` = 時晶夠就買下一級(扣除), 已滿或不夠不反應。

### 升級所(獨立頁面)
18. 大地圖選升級所按 `Z` 打開; `X` 關閉回大地圖。分四列, `↑` `↓` 換列:
    - **招募列**: `←` `→` 選獵人 / 炸彈工; `Z` = 木材夠就招募(扣除, 之後所有關卡面板都能選), 已招募或不夠不反應。
    - **移速列** / **血量列** / **冷卻列**: `Z` = 獸魂夠就升一級(扣除), 已滿或不夠不反應。
19. 強化對三職業都有效, 只影響之後的跑關; 已存的回放照錄影重演, 不會變快(想讓回放變快要重跑)。

### 職業工事(本款特有)
20. 每關 3 處工事, 每處對應一個職業的擅長地形。每處的**角色**是**捷徑**(開出一條通往終點的近路, 本身不放素材)或**採集區**(開出一塊藏素材、怪物的區域; 寶箱放在其中一處)。每關恰好 1 處捷徑、2 處採集區(見關卡構成)。
21. 三種工事:
    - **鉤環架**(獵人擅長): 未修 = 一座倒塌的木架殘骸(不是實心), 上方 5 格高處是一塊**高台區**, 什麼都搆不到。修好 = 高台邊緣下方掛上 1 個**鉤環**(獵人抓鉤一下上去), 旁邊同時立起 3~4 段實心**階梯平台**(其他職業一段段跳上去, 多花約 2~3 秒)。
    - **跳崖台**(劍士擅長): 未修 = 一道 6 格寬的崖口, 對岸是一塊**崖岸區**, 這側的跳台崩塌、坑底小路也被落石填死(實心, 打不壞)。修好 = 這側立起實心跳台(劍士跳起 + 衝刺斬一下過去), 坑底落石消失、坑底小路與對岸的階梯打通(其他職業下坑走過去再爬上來, 多花約 2~3 秒)。坑底是小路, 不是尖刺。
    - **爆破礦坑**(炸彈工擅長): 未修 = 礦坑口被封坑木樁擋住(實心, 打不壞也炸不壞, 外觀要和裂岩牆一眼分得出)。修好 = 木樁消失; 礦坑裡有 2~3 道**裂岩牆**擋在路上(炸彈工一炸就破, 其他職業每道打 3 下, 每道多花約 1 秒)。裂岩牆每趟都重新出現。
22. 採集區的主要素材依工事種類固定(讓職業與產出種類綁在一起): 鉤環架高台區 → **時晶**為主; 跳崖台崖岸區 → **木材**為主、怪物較多; 爆破礦坑 → **石料**為主、怪物成群(3 隻以上在 160px 內, 讓震波擊飛有東西可撞)。
23. **修復紅利一律疊加**: 修好的實心格不得落在任何原本可走的路上; 任何修復組合下, 修之前走得到的每個素材 / 寶箱 / 終點都仍走得到, 主路直衝時間不變長。捷徑不會讓採集區入口變得走不到(採集區入口在捷徑起點之前, 或就在捷徑上)。RD 排完地形要逐關照這條自查。
24. **巢穴**(第 3、6、8 關的爆破礦坑深處): 礦坑最裡側連著巢穴室(約 10×4 格、地面平坦), 有**巢口**, 巢穴室裡住著**巢母**; 巢穴室後方是關著的**寶庫門**(2 格寬 × 3 格高, 實心), 門後是**巢母寶庫**(約 6×3 格)。巢穴與寶庫的迷霧隨礦坑修好一起散開(寶庫門關著時, 寶庫裡仍蓋著迷霧, 寶庫打開時才散開)。
    - 巢口: 礦坑修好後每一趟開始後 1 秒湧出第 1 隻, 之後每 2.5 秒 1 隻, 一趟最多 5 隻(湧滿後變暗)。種類照該關「巢口怪物」清單依序輪流; 湧出的怪出現在巢口前方、面向礦坑, 照一般行為行動(野豬、盾兵、跳蛙會沿礦坑走出去; 射手蜂在出生點附近巡飛)。巢口打不壞。玩家沒進巢穴也照湧。
    - 巢穴怪: 掉落 = 同種怪的一般掉落 + 獸魂 1。
    - **巢母**(64×56): 血 12。在巢穴室內以 50px/秒巡邏(撞牆、到平台邊緣或到巢穴室入口就回頭, 不出巢穴)。玩家與它上下相差 80px 內、在它面向那側 320px 內 → 停下預備 0.8 秒 → 以 380px/秒衝撞, 撞牆或到邊緣 / 入口才停, 停下後暈眩 1.5 秒; **暈眩中受到的傷害 ×2**。碰到玩家扣 1。不會被擊飛(震波只造成 1 傷害), 被擊飛的怪撞到它照常受 2 傷害。每次擊倒掉落 **獸魂 6 + 石料 4 + 時晶 3**。
    - **巢母寶庫**: 該關**第一次**擊倒巢母並過關後, 寶庫門永久打開(這趟畫面上方提示「寶庫將打開」)。之後每一趟寶庫裡都有地上素材 **木材 4、石料 4、時晶 4**(每趟重新出現)。
25. **戰爭迷霧**: 每處工事開出的區域在修好前蓋著迷霧——關卡內、縮圖、面板預覽都蓋。迷霧不是實心, 但未修時那塊區域本來就進不去。工事結構(殘骸、崩塌跳台、封坑木樁)與工程牌畫在迷霧之上、看得到。修好時迷霧在 0.8 秒內淡出散開(在面板預覽上就看得到散開)。
26. 縮圖與預覽的地形、迷霧一律畫**目前**的修復狀態; 回放裡的角色與怪物照錄影(錄影時礦坑沒修, 回放裡就沒有巢穴怪與巢母; 回放角色可能穿過新修好的跳台或階梯平台, 屬預期)。新區域裡的素材(含寶庫), 這條錄影沒拿走的就一直畫在縮圖上; 寶箱照錄影: 錄影那趟打開過的, 打開瞬間之前畫關、之後畫開; 錄影沒碰過的照目前狀態畫。
27. 工事在關卡裡看得到: 未修時旁邊立一面**工程牌**, 牌上畫該工事的職業標誌(獵人 / 劍士 / 炸彈工)與角色標誌(捷徑 / 採集), 修好後工程牌消失。工程牌不是實心、不擋路。

### 道具格(採集器)
28. 每關 2 個道具格(1、2 號), 已開放的關卡就能裝。採集器效果**依現在的配置**對該關每一圈回放與每一趟跑關生效, 改裝後下一個得到素材的時間點起就照新配置算, 卡片與面板上的每分鐘產量立即更新; 不必重跑。
29. 採集器來源: 每關其中一處採集區的寶箱 1 個(內含固定採集器, 見關卡構成; 碰到即打開, 畫面上方提示「獲得 <採集器名>」), 過關時放進背包; 拿過的寶箱之後的趟數都是打開的空箱。背包最多 8 個。一個採集器同時只裝在一格。
30. 採集器(同一關裝兩個同名時效果相加):
    - **伐木斧**: 每得到 1 個木材(撿到或擊倒掉落), 額外 +1 木材。
    - **碎石鎬**: 每得到 1 個石料, 額外 +1 石料。
    - **聚晶稜鏡**: 每得到 1 個時晶, 額外 +1 時晶。
    - **魂瓶**: 每擊倒 1 隻怪, 額外 +1 獸魂。

### 結算
31. 過關時該關沒有回放 → 直接存成回放。已有回放 → 結算面板並列「這一趟」與「目前回放」的秒數與四種素材的每分鐘產量(兩邊都用目前的採集器配置計算), `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
32. 玩家血量 3(升級後 4 / 5); 碰到怪物(被擊飛中的除外)或蜂彈扣 1, 之後無敵 1 秒並被往反方向彈開 80px。每次進關回滿。
33. **尖刺**: 碰到扣 1 血(不即死), 之後無敵 1 秒並被往上彈起(向上 520px/秒, 水平速度歸 0)。無敵中再碰尖刺不扣血。兩根刺中間一格寬的窄落腳點可以保留。
34. **怪物**(四種行為, 全部會主動移動, 都有血量; 被擊倒時冒擊倒煙, **立即消失並停止一切行動**——包括射手蜂瞄準中的那一發也取消):
    - **野豬**(衝撞): 以 80px/秒左右巡邏, 撞牆或到平台邊緣回頭。玩家與它上下相差 40px 內、在它面向那側 240px 內 → 停下預備 0.5 秒 → 以 420px/秒朝原方向衝撞, 撞牆或到平台邊緣才停, 停下後暈眩 1 秒, 再回到巡邏。
    - **盾兵**(正面擋): 玩家在水平 400px 內且上下相差 120px 內 → 以 40px/秒朝玩家走; 否則以 40px/秒巡邏(撞牆或邊緣回頭)。不離開所在平台(礦坑、巢穴室與主路地面相連時視為同一平台)。從它面向那側打來的揮砍、箭、衝刺斬被盾擋下(不扣血, 盾閃一下); 從背後、或攻擊判定中心高於它頭頂時照常受傷。爆炸、震波、被擊飛的怪撞上來都不受盾影響。
    - **射手蜂**(射擊): 在出生點左右 120px 內以 60px/秒來回巡飛(碰到地形回頭), 同時上下飄 ±16px(週期 2 秒)。玩家在 400px 內時每 2 秒射一發: 停下瞄準 0.4 秒 → 朝玩家當下位置射出蜂彈(220px/秒直線, 碰到地形消失)。
    - **跳蛙**(跳躍): 每 1.2 秒跳一次(水平 120px、最高 80px), 落地蹲著等下一跳。玩家在 300px 內時朝玩家跳; 否則朝面向跳, 起跳前若落點沒有地面或是牆就先轉向。
35. **職業**(攻擊 `Z`、技能 `X`; 三職業判定框都是 28×44; 移速與技能冷卻再乘升級所的倍率):
    - **劍士**(開局): 移速 260。攻擊 = 面前揮砍(面向側 50×40, 1 傷害, 冷卻 0.3 秒)。技能 = **衝刺斬**: 朝面向衝 160px(0.18 秒, 期間無敵、不受重力, 沿途怪物受 2 傷害), 冷卻 1.2 秒; 衝刺斬擊倒怪物時冷卻立刻歸零; 空中可用, 每次離地只能用 1 次(落地恢復)。擅長: 跳起再衝刺斬跨過 6 格寬坑(跳崖台)。
    - **獵人**: 移速 260。攻擊 = **自動射擊**: 每 0.6 秒自動朝 260px 內最近的一隻怪物射一箭(箭速 700px/秒, 飛向目標當下位置, 1 傷害), 射程圈常駐顯示; 另外按 `Z` 可手動朝面向水平射一箭(冷卻 0.4 秒, 飛 600px, 可打裂岩牆)。技能 = **抓鉤**: 220px 內有鉤環時, 以 700px/秒被拉到鉤環, 到達瞬間獲得向上 500px/秒的速度, 冷卻 0.5 秒; 範圍內沒有鉤環則不反應。擅長: 一下上到 5 格高的高台(鉤環架)。
    - **炸彈工**: 移速 230。攻擊 = **投彈**: 朝面向拋出炸彈(初速水平 300、向上 500px/秒, 重力同玩家), 碰到地形或怪物即爆炸, 半徑 60px(外緣)內怪物受 2 傷害、裂岩牆直接碎掉(封坑木樁、落石、寶庫門不受影響); 冷卻 0.6 秒; 玩家不會被自己的爆炸傷到。技能 = **震波**: 以自己為中心半徑 130px(外緣)內的怪物受 1 傷害並被**擊飛**(規則 36), 範圍內的裂岩牆直接碎掉; 空中可用, 冷卻 1.5 秒。擅長: 破裂岩牆(爆破礦坑)、打盾兵、把怪撞成一串。
36. **擊飛**(只有炸彈工的震波會造成; 巢母不會被擊飛): 被打中還活著的怪物朝「遠離炸彈工」的水平方向以 460px/秒飛出, 最多 0.6 秒或撞到地形為止, 期間不受重力、碰到玩家不傷人。
    - 擊飛中的怪碰到其他怪(含巢母) → 對方受 2 傷害, 若還活著也被擊飛(方向相同; 巢母只受傷不飛)。同一次擊飛中每隻怪只會撞同一隻別的怪一次。
    - 擊飛中撞到地形 → 自己受 1 傷害, 擊飛結束。
    - 擊飛結束仍活著 → 落地(蜂回到飛行)後恢復原本行為。
37. **連鎖字**: 玩家的同一次攻擊(含它引發的擊飛碰撞)擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」。只是顯示, 不改掉落。
38. **裂岩牆**: 實心, 耐久 3。揮砍、箭、衝刺斬每次 -1; 炸彈爆炸或震波碰到直接碎掉。碎掉後消失(冒擊倒煙)。

### 物理與通道尺寸(三職業共用)
39. 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格); 移速 260 全速跳躍水平約 156px(過得了 3 格寬的坑)。按住 `↑` 短於 0.15 秒時初速減半(小跳)。地形為實心方塊, 沒有單向平台、移動平台。
40. **通道尺寸**: 所有礦坑、門口、洞口、新區域入口至少 2 格寬、2 格高(80×80px), 容得下 28×44 的判定框; 角色要通過的垂直井至少 2 格寬。

### 擅長與替代路線(三職業都過得了每一關的每個已開放地方)
41. 主路上另有 1~2 處小規模的擅長地形(高台 / 寬坑 / 裂岩牆, 不需修), 每種都有不需技能的替代做法, 只是比較慢; 只有小捷徑或多拿一點的地方才放。不做整片區域只有某職業進得去: 每處工事修好後三職業都進得去, 只是擅長的職業比較快。

### 素材用途(每種一種專屬用途)
42. **木材** = 開路: 解鎖關卡、招募職業。**石料** = 修復工事。**時晶** = 回放加速器(每關各自買)。**獸魂** = 升級所強化角色。**工匠之都** = 四種都要, 買下即勝利。
