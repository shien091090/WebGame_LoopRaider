## game-a 疾影回放
- 「我喜歡打怪會掉素材的設計, 這讓玩家可以選擇是否要略過怪直接吃場地上的素材, 還是花一點時間打怪」 → 對應機制: 擊倒怪物掉素材(推論: H08 的「打它多賺 vs 跳過省時」有出現)
- 「我不喜歡上回合殘影, 殘影很干擾畫面」 → 對應機制: 殘影對手(H09)
- 「保留DPS高的設計我喜歡 但我打算不保留 因為我希望設計成多種素材」 → 對應機制: 自動保留效率較高的那趟(H10)。推論: 改成多種素材後「效率」不再是單一數字, 無法自動比高低
- 「各個職業有特殊技能可以觸發不同機關的設計我喜歡 但目前設計因為素材太單一 所以玩家其實沒有什麼策略性可言 如果做成多種素材 才有辦法讓玩家真正去規劃 我是要選弓箭手多賺一點素材A 還是要選法師多賺一點素材B」 → 對應機制: 職業專屬區 + 單一素材(H12)。推論: 職業差異要落在「產出種類」才有策略性, 只差在數量不夠

## game-b 三職工坊
- 「我喜歡多種素材的設計 玩家可以透過未來升級或解鎖的條件中 去發現自己目前缺什麼 從而有策略性的去規劃要怎麼過關」 → 對應機制: 多種素材 + 配方解鎖(H15、H17)
- 「多個角色過同一個關卡 讓一個關卡可以產出更多不同種類的素材且數量更多 這個設計我覺得有趣 但這樣玩法會變得完全不一樣 變成是一個關卡玩家要做的不是 用不同策略去客製化關卡產出及產出速度 而是每一種職業都進去拚speed run 這不是我想要的」 → 對應機制: 每關每職業各留一條回放(H16)。使用者想要的是「一關一條回放, 靠選職業與路線客製化該關的產出種類與速度」
- (自動攻擊, 使用者原本誤記在 C, 確認是 B)「角色自動攻擊我覺得不錯 但我更希望它變成是某個職業的特色 而不是每種職業都這樣 這樣也能對職業做出差異性」 → 對應機制: 全職業自動攻擊(H13/H14)。推論: 自動攻擊適合當某一職業的特性

## game-c 連斬回廊
- 「撿金幣連段比較沒感覺」 → 對應機制: 連段倍率(H20)
- 「回放加速器的設計我覺得不錯 又多一種素材可以使用到的地方」 → 對應機制: 回放加速器(H23)
- 「衝刺斬不錯 也可以包裝成是一個職業的技能」 → 對應機制: 衝刺斬(H19), 適合當某一職業的技能而非全員攻擊方式
- 「C款靠高度去區別職業能過的路這一點我覺得不錯 第一關刺客可以鑽小路多拿點錢 但其他職業不能鑽小路」 → 對應機制: 職業體型 / 移動能力不同 + 專屬路線(H22)

## 跨款比較
- 使用者沒有選出單一最好的款, 而是各款挑喜歡的部分: A 的打怪掉素材取捨、B 的多種素材、C 的體型分路線與回放加速器
- 重跑動機: 「如果覺得自己過關速度有點慢 打得有點卡的時候 會想再跑一次 主要是前幾次對關卡不熟 就會想再多打幾次」 → 推論: 速通重跑動機目前來自「對關卡不熟」, 熟了之後的動力未驗證
- 越賺越快: 問過 2、3 關後回大地圖是否感覺素材越賺越快, 答「有感覺」(H03)

## 不好的體驗
- 「殘影很干擾畫面」 → 可能來源: 殘影對手(A)
- 「目前怪物戰鬥很沒特色 怪物應該要有更多不一樣的行為 比較有趣」 → 可能來源: 三款怪物行為單一(推論)
- 「目前的操作有點怪, 應該要空白鍵=跳躍, z=攻擊,x=技能這樣才比較符合一般遊戲操作習慣」 → 可能來源: 按鍵配置(三款共通)
- 「回放時應該也要能看到怪物 打死怪物也要完整還原出來 簡單來說是整個關卡過關流程重新演一次 比較符合我心中的想像」 → 可能來源: 回放只重現玩家, 沒有重演怪物與擊殺(三款共通)

  - 回放要完整重演整個過關流程(含怪物與擊殺)
