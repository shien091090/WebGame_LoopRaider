## 1. 邏輯畫布尺寸

**1280 × 720**(`Art.canvas = { width: 1280, height: 720 }`)。照 `interface.json`, 固定寬度, 沒有依裝置變寬的程式。
任務範本預設寫 21:9 的 1680×720, 但介面明寫 1280×720 而且不能改, **以介面為準**。

## 3. 形狀語言

扁平幾何 + 深色 2px 外框, 實體物件一律有外框; **只有殘影沒有外框、單色、半透明**; 危險物有尖角或紅色; UI 用圓角卡片。

## 4. 理念落實

- **P0 辨識度先於好看**: 每種物件的色相各不相同(晶石是唯一的青色、怪物紅系、地形土褐、機關帶職業色), 背景壓成暗藍低對比。
- **P1 視覺權重跟著決策迫切度走**: 背景最暗; 關卡內最亮的是晶石、終點旗、玩家; 資訊列半透明深底、字級克制。結算面板沒有即時決策, 所以「效率」數字放到最大。
- **P2 規則上存在的東西要看得見**: 「裂岩牆只有劍士能打碎」「標靶 / 柵門只有弓手能處理」用職業色畫在機關本體上; 標靶射中後變灰並插著一支箭(已用掉); 史萊姆少 1 血會縮扁並出現裂痕; 結算面板寫明回放是存了、換了還是保留舊的。
- **P3 一個意義一種長相**: 晶石菱形在場上、資訊列、卡片花費、+1 浮字、結算面板都是同一個圖形; 職業徽章(藍劍 / 綠弓 / 紫三角)在資訊列、關卡卡片的回放職業、說明頁裡都一樣; 殘影的長相只代表回放(衝刺的身後效果用白色速度線, 不借殘影的長相)。
- **P4 關鍵區分走兩條感知通道**: 玩家與殘影的差別有三條: 透明度(殘影 50%)、色彩(殘影單色淡藍白、玩家有職業色)、外框(殘影沒有深色外框)。可以買 / 不足: 數字顏色(白 / 紅) + 「不足」兩個字 + 鎖頭亮度。
- **P7 每個元素都要掙得它的版面**: 資訊列不重複寫職業名(徽章就夠); 技能冷卻只畫一個環, 不另加秒數。
- **P9 以最混亂的那一刻驗收**: 所有實體物件都有深色外框, 疊在怪物、煙、殘影上仍然分得開; 縮圖是 0.3 倍, 晶石、旗子、殘影都靠色塊辨識, 不靠細節。
- **P13 事件要排隊**: 「+1」浮字各自長在它那張卡片的縮圖位置上, 0.8 秒內上升並淡出, 不集中到同一塊版位互相疊。
- **P15 回饋強度跟事件份量成正比**: 撿晶石 / 回放 +1 用小浮字; 怪物倒下用 48px 煙; 過關用整個面板; 新紀錄另外換成金色邊框。
- **P17 進度的圖形與數字分工**: 技能冷卻只用環表示這一次冷卻的進度, 轉滿就變成實心職業色 + 白框 +「技能 可用」(就緒當下有獨立回饋)。疾行靴等級用 3 格方塊, 數字 Lv 只是補充。
- **P18 重要資訊不能只存在一瞬間**: 回放效率常駐在關卡卡片上(`/分`), 資訊列常駐總產量; 結算面板寫明原紀錄 → 新紀錄。
- **P19 資訊貼著物件**: 花費寫在要買的那張卡片裡; +1 浮字冒在縮圖裡殘影撿到晶石的位置。
- **P21 示意圖選分岔例子**: 說明第 4 頁同一關並排兩條路線(繞路多撿 vs 直衝), 兩張都不打勾打叉; 第 1 頁的路線跳過史萊姆, 表示怪物可以不打。

### 角色姿勢(玩家 / 殘影共用)

- 職業長相: 劍士 = 藍衣 + 白頭盔 + 單手劍; 弓手 = 綠衣 + 綠兜帽 + 弓; 法師 = 紫袍 + 尖帽 + 紫寶珠法杖。
- `facing` 1 朝右 / -1 朝左(整隻鏡射)。
- `pose`: `idle` 站直 / `run` 雙腿前後跨、微前傾 / `rise` 縮腿、雙手上舉 / `fall` 雙腿垂下、手張開 / `dash` 大前傾 + 身後白色速度線(畫在判定框內) / `hurt` 後仰 + 眼睛變 X。
- 攻擊中(`attackT < attackDur`): 劍士在面向側框外畫白色新月刀光, 範圍就是揮砍判定 50×40(從身體邊緣 x±14 起, 垂直置中), 依進度展開並淡出; 弓手拉弓(弦往後拉); 法師把法杖往前推, 寶珠放大並加白圈。
- `invuln`: 照介面, RD 已經用閃爍控制呼叫頻率, 美術不另外畫(欄位不讀)。

### 大地圖卡片

- **關卡卡片** 400×290: 卡片頂端 (8,8) 起 384×216 是縮圖區, 美術只畫外框。
  - `locked`: 縮圖區塗黑 + 鎖頭 + 花費; 名稱與「未開放」用灰字。
  - `open`: 右下「未過關」灰字。
  - `cleared`: 邊框變晶石深青; 右下晶石圖示 + 效率 `rate`(青色大字)+「/分」, 下一行「回放」+ 回放職業徽章 `recordCls`。
  - 左下固定「第 N 關」+ 關卡名 `name`。
- **職業卡片** 240×140: 左側是 2 倍大的角色頭像。`locked`: 頭像變灰色剪影、鎖頭 + 花費; `owned`: 「已擁有」灰字; `active`: 外框與內框換成該職業色 + 職業色「使用中」標章。每張卡都寫技能一句(劍士「衝刺斬 · 碎裂岩牆」等), 讓玩家知道買了能打開哪種專屬區。
- **升級卡片** 420×140: 靴子圖示 + 3 格等級(已升級的格子塗金)+ Lv; 未滿級畫花費, `level = maxLevel` 或 `cost = null` 時畫金字「已滿級」。
- **終極目標卡片** 1220×90: 翅膀圖示 +「傳說之翼」+ 花費。`canAfford=true` 時金框、金字、翅膀亮白; 不足時灰翅膀。
- **花費與不足**: 晶石圖示 + 數字; 不足時數字變紅並加「不足」, 鎖頭變暗。
- **選取** `selected=true`: 卡片外 4px 黃色圓角框 + 四角加粗(最多畫到框外 6px)。

### 資訊列(0,0 起 1280×40, 深色半透明)

- 兩種模式都有(位置固定在右側): 晶石圖示 + 持有數 `stock`(x≈1000~1100)、「產量 +X.X /分」(靠右對齊到 x=1268)。
- `mode='level'` 再加, 由左到右: 職業徽章(x=24)→ 愛心 `hp/maxHp`(x=58 起每顆 26)→「時間 12.3s」(x=160)→「本趟 ◆ N」(x=290)→「紀錄 X.X/分」或「—」(x=410)→ 技能環(x=590)+「技能」/「技能 可用」。
- 技能環: 冷卻中 = 虛線外框 + 職業色扇形依 `skillCdT/skillCdDur` 長大; 可用 = 實心職業色 + 白框。

## 9. 繪製層級(RD 建議順序, 由下往上)

1. `drawBackground` / `drawMapBackground`
2. 地形: `drawGround`、`drawSpike`、`drawCrackWall`、`drawTarget`、`drawGate`
3. `drawCrystal`、`drawGoal`
4. `drawGhost`(在怪物與玩家之下, 不擋住玩家)
5. `drawSlime`、`drawBat`
6. `drawPlayer`
7. `drawArrow`、`drawMagicBolt`、`drawPoof`
8. `drawHud`
9. 面板: 結算 / 失敗 / 暫停 / 結束(暫停自帶暗幕)

大地圖: 背景 → 卡片(關卡卡片之後再畫縮圖)→ `drawPopup` → `drawHud` → 暫停面板。

## 10. 判讀約定

- **縮圖**: RD 以 `translate + scale(0.3)` 重用關卡函式; 美術沒有另做縮圖版。0.3 倍時晶石約 7px、殘影約 8×13px, 靠色塊辨識。
- **殘影透明度**由 `drawGhost` 內部乘上 0.5(沿用呼叫前的 globalAlpha), RD 不用自己調。
- **魔彈拖尾**需要方向, 介面沒給; 有傳 `dir` 才畫拖尾(已列為介面缺口, 回報製作人)。
- 面板函式固定在介面的版位; 結算、失敗面板若另外收到 `x, y` 會改用傳入值(左上角)。
