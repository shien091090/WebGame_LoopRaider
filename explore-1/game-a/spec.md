# 疾影回放(速通競速: 一直刷新自己的紀錄)

## 概述
橫向平台動作: 手動砍怪、撿晶石、衝到終點旗; 過關後那一趟在大地圖上不斷重播, 重播到撿晶石的瞬間就 +1。每關只留「效率最高的一趟」, 下次跑時那一趟會變成半透明殘影跟你同場比賽。
驗證假設: H01、H02、H03、H04、H05、H06、H07、H08、H09、H10、H11、H12

## 核心循環
進關(選一個職業) → 砍怪、撿晶石、衝終點 → 結算看到「每分鐘晶石」並自動存成該關回放 → 大地圖上所有已過關卡同時重播賺晶石 → 用晶石解鎖下一關 / 職業 / 移速升級 → 新職業或升級讓舊關能跑出更好的效率 → 回去追自己的殘影刷新紀錄。

## 規則

### 通用(使用者規定, 三款共通)
1. 每關是一個不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、這趟撿的晶石不入帳), 跳出失敗面板。
4. 這趟撿到的晶石只在過關時才入帳(加進持有數)。
5. 錄影: 從進關到過關, RD 每幀記錄玩家的 x、y、職業、面向、動作、攻擊計時; 並記錄每次「得到晶石」的時間點與位置(撿到地上晶石、擊倒怪物都算一次)。
6. 這趟效率 = 這趟晶石數 ÷ 這趟秒數 × 60, 單位「每分鐘晶石」, 顯示到小數 1 位。
7. 回放: 每個已過關卡在大地圖卡片的縮圖裡以原速無限循環播放它的回放(播完立刻從頭, 無間隔); 回放每播到一個「得到晶石」的時間點, 持有晶石 +1, 並在縮圖該位置冒出「+1」。
8. 回放在大地圖、關卡內、結算面板時都持續產出; 只有暫停與說明頁開著時停止。關卡內不畫縮圖, 只在資訊列顯示持有數與總產量。
9. 總產量(每分鐘) = 所有回放的效率加總, 顯示在資訊列。
10. 開局: 晶石 0, 只開放第 1 關與劍士。
11. 素材(晶石)用途: 解鎖第 2、3 關、解鎖弓手與法師、買疾行靴升級、買終極目標「傳說之翼」。

### 本款特有
12. **回放保留規則**: 每關只存一條回放。過關時若該關沒有回放, 直接存; 已有回放時, 這趟效率**高於**舊回放才取代, 否則保留舊的(玩家不用選)。
13. **殘影對手**: 進入有回放的關卡時, 該回放從第 0 秒起以半透明殘影同步播放(不能互動、不會撿東西); 殘影到終點後消失。
14. **手動戰鬥**: 怪物有血量, 被攻擊扣血, 歸 0 倒下; 擊倒一隻怪 = 立即得到 1 顆晶石(算一次得到晶石事件, 計入這趟)。
15. 玩家血量 3; 碰到怪物扣 1, 之後無敵 1 秒並被往反方向彈開 80px。
16. 職業(切換職業只能在大地圖):
    - **劍士**(開局): 攻擊=面前揮砍(判定 50×40, 1 傷害, 冷卻 0.3 秒)。技能=衝刺斬: 朝面向衝 160px(0.2 秒, 期間無敵、沿途怪物受 2 傷害), 可擊碎**裂岩牆**; 冷卻 1.5 秒。
    - **弓手**(解鎖 40): 攻擊=水平射箭(箭速 600px/秒, 飛 600px 消失, 1 傷害, 冷卻 0.4 秒)。箭射中**標靶**時, 同一關的**柵門**整排消失(這趟有效)。技能=疾風步: 2 秒內移速 +60%, 冷卻 5 秒。
    - **法師**(解鎖 90): 攻擊=魔彈(速度 400px/秒, 飛 400px, 穿透所有怪物, 1 傷害, 冷卻 0.5 秒)。技能=浮空術: 在空中按技能再跳一次(與地面跳同高), 每次落地前限一次。
17. 職業專屬區: 裂岩牆只有劍士的衝刺斬能打碎; 標靶只有箭能觸發(其他攻擊打到無反應); 法師區平台離最高可站處 4 格高, 只有浮空術上得去。專屬區裡放額外晶石。
18. **主路線**(起點到終點)不需任何職業技能, 三個職業都能過每一關。
19. 疾行靴升級: 每級移速 +10%(對三個職業都有效), 共 3 級; 只影響之後新跑的趟數, 不會改變已存的回放。
20. 買下「傳說之翼」即遊戲結束(勝利)。

### 物理(三職業共用)
21. 移速 260px/秒(套疾行靴、疾風步加成); 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格高的台階), 全速跳躍水平距離約 156px(可越過 3 格寬的坑)。按住跳躍鍵時間短於 0.15 秒時跳躍高度減半(可小跳)。
22. 地形為實心方塊, 沒有單向平台。

### 關卡構成(RD 依此排地形; 三關都是單畫面, 起點在左、終點在右)
| 關 | 名稱 | 主路線晶石 | 怪物 | 劍士區 | 弓手區 | 法師區 | 主路線直衝目標時間 |
|---|---|---|---|---|---|---|---|
| 1 | 草原 | 5 | 史萊姆 2 | 裂岩牆封住的小凹室, 3 晶石 | 柵門封住的凹室, 標靶在主路線可水平射到的牆上, 3 晶石 | 高台, 3 晶石 | 約 12 秒 |
| 2 | 洞窟 | 6 | 史萊姆 3、蝙蝠 1 | 4 晶石 | 4 晶石 | 4 晶石 | 約 16 秒 |
| 3 | 高塔 | 7 | 史萊姆 3、蝙蝠 2 | 5 晶石 | 5 晶石 | 5 晶石 | 約 20 秒(起點左下、終點右上, 以往上爬為主) |

- 每個專屬區繞進去再回到主路線約多花 3~5 秒; 主路線上也有 1~2 顆要稍微繞路才拿得到的晶石, 讓「撿 vs 不撿」在劍士開局就存在。
- 怪物放在主路線上或旁邊, 可以選擇跳過不打。
- 第 2、3 關各放 2~4 個尖刺。

## 操作(只用鍵盤)
| 玩家動作 | 按鍵 |
|---|---|
| 左右移動 | ← → |
| 跳躍(關卡內) | Z |
| 攻擊(關卡內) | X |
| 技能(關卡內; 法師在空中按 = 浮空術) | 空白鍵 |
| 大地圖: 換列(關卡列 / 職業與升級列 / 終極目標) | ↑ ↓ |
| 大地圖: 列內選擇 | ← → |
| 大地圖: 確定(進關 / 解鎖 / 換職業 / 買升級 / 買終極目標) | Z |
| 大地圖: 重開說明 | 空白鍵 |
| 說明頁: 翻頁 | ← → |
| 說明頁: 下一頁 / 最後一頁關閉 | Z |
| 結算面板: 回大地圖 / 再跑一次 | Z / X |
| 失敗面板: 重來 / 回大地圖 | Z / X |
| 暫停面板(關卡內): 重來 / 回大地圖 | Z / X |

通用鍵: `Esc` 暫停 / 繼續(關卡內與大地圖都可)。本探索版不做音效, 沒有 `M` 靜音鍵與聲音圖示。

大地圖 Z 的行為依游標所在卡片狀態決定: 已開放關卡 → 用目前職業進關; 未開放關卡 / 未解鎖職業 / 升級 / 終極目標 → 晶石夠就買, 不夠不反應(卡片顯示不足); 已擁有職業 → 設為目前職業。

## 勝負與結束
- 單關: 碰終點旗 = 過關(結算面板); 失敗條件見規則 3(失敗面板)。
- 整場: 買下「傳說之翼」→ 結束面板顯示總遊玩時間; 按 Z 全部重置(晶石、解鎖、回放清空)並回到說明頁第 1 頁。
- 沒有整場失敗。

## 範圍邊界
- 不做音效、不做存檔(重新整理即重來)、不做難度曲線與更多關卡
- 不做捲動關卡、不做單向平台、移動平台
- 不做怪物攻擊招式(只有碰撞傷害)、不做魔王
- 不做技能升級、裝備、商店以外的素材用途
- 大地圖縮圖裡不畫怪物(只有地形、晶石、終點、回放角色)
