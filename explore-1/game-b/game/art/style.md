**色相驗算**(node 算, HSV 色相 / 灰階): 三職業色兩兩差 82°(綠-黃)、119°(黃-洋紅)、159°(綠-洋紅)。危險紅對洋紅 74°、對綠 127°。
**張力**: 礦工黃與危險紅只差 45°(相鄰色名)。處理: 紅只出現在**點與線**(刺尖、眼睛、心、細血條、缺料底線與「缺」小牌), 從不填在物件本體大面積上; 黃只在礦工 / 礦石 / 礦工機關上; 兩者灰階差 60。最難分的一幀: 礦工站在尖刺旁 — 尖刺靠「銀色三角 + 紅尖」形狀辨識, 不靠顏色。
綠-洋紅灰階只差 4: 老闆明言 prototype 不考慮色弱, 色相差 159° 夠用; 職業另有剪影通道(下述)。

**字典詞**:
- **職業色 = 那個職業 + 它的素材**(獵人=獸牙=綠, 礦工=礦石=黃, 精靈=花露=洋紅)。卡片、HUD、浮字、結算一律同一套色。
- **職業色虛線 = 只有那個職業打得開的機關**: 繩結的綠虛線靶環、吊橋收起時的綠虛框、碎石牆的黃虛線框。
- **半透明 = 現在對你沒用 / 是回放**: 黯淡花(非精靈)、殘影。
- **白色雙線外框 = 大地圖游標**; 職業色粗框 + 「使用中」膠囊 = 目前職業(兩者可同時出現, 不互相取代)。
- **紅 = 會傷你 / 缺**。

## 3. 形狀語言

圓角扁平、深色描邊只用在小圖示與浮字; 地形是方塊, 角色與怪物是圓潤剪影, 危險物是「朝上的銀色尖三角 + 紅尖」(全畫面只有尖刺用一排朝上的尖)。

## 4. 理念落實

- **P0**: 三職業剪影不同(獵人=尖兜帽 + 弓、礦工=黃安全帽 + 頭燈 + 鎬、精靈=翅膀 + 三角裙), 0.3 倍縮圖只剩 8px 時再靠主色 + 殘影職業色外框分人。
- **P1**: 背景與遠山低對比、射程圈只 38% 細線 + 5% 淡染、畫在玩家下層; 最亮的是角色、怪物紅眼、終點旗。
- **P2**: 「規則上在但現在對你沒用」都畫出來: 黯淡花(非精靈)、收起的吊橋虛框、碎石牆 / 繩結的職業色虛線; 配方缺哪種在卡片上直接標紅 + 「缺」。
- **P3**: 素材色 = 職業色, 全畫面(HUD、卡片、產量面板、浮字、結算、說明頁)同一套圖示與顏色; 說明頁一律呼叫遊戲內畫家。
- **P4**: 礦脈 vs 碎石牆 vs 地面: 明暗(暗冷 / 亮灰 / 土棕)+ 紋理(寶晶 / 磚塊裂紋 / 斑點草頂)兩條通道; 狼 vs 甲蟲: 剪影(四腳長身 / 圓殼)+ 顏色; 可採花 vs 黯淡花: 顏色 + 光暈 + 透明度。
- **P7**: 卡片不寫重述字(職業卡只寫名稱與「採集 [圖示] 素材名」); 縮圖不畫怪物。
- **P9**: 浮字帶深色描邊, 疊在縮圖任何底色上都讀得到; 殘影外框用職業色, 3 個殘影擠在一起時仍分得出。
- **P13**: 浮字只在回放事件當下由 RD 逐個呼叫, 本身 0.8 秒上升淡出, 前 60% 不透明、後 40% 淡出, 不疊大型提示。
- **P15**: 回饋分級: 自動箭(細箭)< 揮鎬弧光 < 穿透箭(全畫面光束); 怪物受擊整隻閃白, 倒下才出煙。
- **P17**: HUD 技能鍵 X 上畫冷卻扇形(剩餘), 就緒時鍵帽亮起 + 職業色外框; 秒數只在結算面板與 HUD 數字給。
- **P18**: 結算面板留下這趟秒數、數量、效率與新舊紀錄; 每條回放的效率常駐在關卡卡片底列。
- **P19**: 怪物血條貼在怪物頭上; 回放得到素材的「+N」浮在殘影位置; 缺料標記貼在那個數字上。
- **P21**: 說明頁第 3 頁用「圈內狼被箭追 vs 圈外狼沒有箭」對照; 第 5 頁兩格同一關、只差停留與否。

### 玩家細節

- `pose`: idle 雙腳站 / run 雙腳交替(牆鐘)/ rise 縮腿 / fall 張腿 / glide(只精靈, 翅膀往兩側上方張開; 非精靈傳 glide 畫成 fall)/ hurt 身體後仰 + 紅白閃(牆鐘)。
- `skillT < skillDur`: 獵人拉滿弓 + 發光搭箭; 礦工鎬子往前劈下。
- `autoT < autoDur`: 獵人弓轉向 `autoAngle`(夾 ±75°)並半拉; 礦工鎬子轉向 `autoAngle`, **另在世界座標畫揮鎬弧光**(半徑 34~66 的黃白月牙, 朝 autoAngle 掃過, 框外, 不超過 70); 精靈手伸向 autoAngle + 白色星光。
- `invuln`: 收 `true` 或大於 0 的數字, 皆以每秒 12 次的頻率在 35% / 100% 透明度間閃。
- 礦工閒置時鎬子背在背後。

### 資訊列(0,0)~(1280,40)

- 中段(兩種模式同一位置, 不移動): 獸牙 x≈380、礦石 x≈555、花露 x≈730, 各為「圖示 + 持有數(粗 20px)+ `+x.x/分`(職業色 13px)」。
- mode='level' 再畫左段: 職業小頭像(職業色框)、血量心 ×maxHp(紅實心 = 剩)、技能鍵帽 `X` + 冷卻扇形(剩餘部分深色)+ 技能名(穿透箭 / 鎬擊 / 滑翔); 就緒時鍵帽全亮 + 職業色外框。右段: `time 秒`(右齊 x=960)、「本趟 [runType 圖示] ×runCount」、「紀錄 x.x/分」(null 畫「—」, 右齊 x=1270)。
- mode='map' 只畫中段。

### 畫面文字歸屬

照介面: 每個面板 / 卡片自己的字(含按鍵提示)都由美術畫, **RD 不要再畫**; 大地圖最下方 y=660~710 的操作提示由 RD 畫。說明頁的標題、說明文字、頁碼、翻頁提示由 RD 畫, 美術只畫示意圖(第 7 節)。

## 9. 判讀約定

- 所有「xxT / xxDur」: `xxT ≥ xxDur` 或 dur ≤ 0 視為閒置。一次性特效(穿透箭、煙、浮字)在 t ≥ dur 時自己不畫。
- **牆鐘動畫**(用 `performance.now()`, 不讀 state): 跑步腳步、狼 / 甲蟲腳步、終點旗飄動、礦脈閃光、無敵閃爍、受傷閃色、精靈空中拍翅。都在框內動, 自測掃過 10 個相位。
- 關卡卡片 open 時縮圖區先填深底並畫外框, RD 之後畫縮圖蓋上去。
- 自測紀錄: 假 ctx(追蹤變換、依角度取樣弧線、矩形剪裁)跑全部匯出函式 × 所有狀態組合 × 10 個時間相位 + 5 組壞狀態, 共 2170 次, 拋錯 0、save/restore 不成對 0、超出 `size` 0(放行: 介面明文允許的框外部分 — 血條、揮鎬弧光、繩子、花光暈、光球拖尾、浮字上升、選取框、暫停暗幕; 箭只在 angle=0 時比 24×6)。介面每個 state 欄位在 art.js 都有讀到。
