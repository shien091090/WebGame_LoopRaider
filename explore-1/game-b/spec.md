# 三職工坊(職業分工: 同一關派不同職業跑出不同產線)

## 概述
橫向平台動作: 角色會**自動攻擊**射程內的怪物, 玩家只管走位、跳躍與職業技能; 三個職業各自只能採集一種素材(獵人剝獸牙、礦工挖礦石、精靈摘花露)。每關**每個職業各留一條回放**, 在大地圖上同時重播, 解鎖需要多種素材的配方。
驗證假設: H01、H02、H03、H04、H05、H06、H07、H13、H14、H15、H16、H17、H18

## 核心循環
選職業進關 → 走位讓自動攻擊打怪、用技能採集該職業的素材、衝終點 → 這一關多了一條「這個職業」的回放 → 大地圖上所有關卡 × 所有職業的回放同時產出三種素材 → 湊配方解鎖下一關 / 職業 → 新職業回到舊關又能多開一條產線, 缺哪種素材就派哪個職業去跑。

## 規則

### 通用(使用者規定, 三款共通)
1. 每關是一個不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、這趟採到的素材不入帳), 跳出失敗面板。
4. 這趟採到的素材只在過關時才入帳。
5. 錄影: 從進關到過關, RD 每幀記錄玩家的 x、y、職業、面向、動作; 並記錄每次「得到素材」的時間點、位置、種類與數量。
6. 這趟效率 = 這趟素材數 ÷ 這趟秒數 × 60, 單位「每分鐘」, 小數 1 位。每個職業只採一種素材, 所以效率就是該種素材的每分鐘產量。
7. 回放: 每條回放在大地圖該關卡片的縮圖裡以原速無限循環播放(播完立刻從頭, 無間隔); 每播到一個「得到素材」的時間點, 持有的該種素材 + 該數量, 並在縮圖該位置冒出「+N」與素材圖示。
8. 回放在大地圖、關卡內、結算面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 資訊列顯示三種素材的持有數與每分鐘總產量(各種素材分開加總)。
10. 開局: 素材全 0, 只開放第 1 關與獵人。
11. 素材用途: 解鎖第 2、3 關、解鎖礦工與精靈、買終極目標「飛空艇」。

### 本款特有
12. **每關每職業一條回放**: 一關最多同時存 3 條回放(每職業一條), 全部同時重播。同職業再過同一關時, 這趟效率高於該職業舊回放才取代, 否則保留舊的(玩家不用選)。
13. **自動攻擊**: 沒有攻擊鍵。角色每隔固定時間自動攻擊**射程內最近的一隻怪物**(以兩者中心距離判定); 射程外不攻擊。射程以圓圈常駐顯示在角色周圍。
14. 怪物有血量, 歸 0 倒下。玩家血量 3; 碰到怪物扣 1, 之後無敵 1 秒並被往反方向彈開 80px。
15. **採集專長**(每個職業只能拿自己的素材):
    - **獸牙**: 只有獵人擊倒怪物時得到(狼 +1、甲蟲 +2); 其他職業擊倒怪物沒有素材。
    - **礦石**: 只有礦工用鎬擊打碎**礦脈**時得到(每塊 +1)。礦脈是實心方塊, 其他職業打不碎、當牆。
    - **花露**: 只有精靈碰到**發光花**時得到(每朵 +1)。其他職業看得到花(畫成黯淡)但碰到沒反應。
16. 職業(切換職業只能在大地圖):
    - **獵人**(開局): 自動射箭(射程 240px, 每 0.5 秒, 箭速 700px/秒飛向目標當下位置, 1 傷害)。技能=穿透箭: 朝面向水平射出貫穿全畫面的一箭, 路徑上所有怪物 2 傷害, 冷卻 3 秒; 穿透箭射中**繩結**會放下該關的**吊橋**(這趟有效)。
    - **礦工**(解鎖: 獸牙 20): 自動揮鎬(射程 70px, 每 0.6 秒, 2 傷害, 立即命中)。技能=鎬擊: 敲面前一格(面向側、與身體中心同高的那格), 打碎礦脈(+1 礦石)或**碎石牆**; 面前 50×40 內的怪物也受 2 傷害; 冷卻 0.4 秒。
    - **精靈**(解鎖: 獸牙 15 + 礦石 20): 自動發射追蹤光球(射程 180px, 每 0.8 秒, 光球 350px/秒追著目標, 1 傷害)。可二段跳(空中再按一次跳, 落地前限一次)。技能=滑翔: 空中按住技能鍵時下落速度上限 70px/秒。
17. 職業專屬區: 吊橋後方是只有獵人過得去的怪物平台(多 2 隻狼); 碎石牆後方是只有礦工進得去的礦坑(多 2 塊礦脈); 浮空小島離最高可站處 4 格高或隔 5 格寬的坑, 只有精靈的二段跳 / 滑翔到得了(放花)。
18. **主路線**(起點到終點)不需任何職業技能, 三個職業都能過每一關。
19. 買下「飛空艇」即遊戲結束(勝利)。

### 物理(三職業共用)
20. 移速 260px/秒; 跳躍初速 720px/秒、重力 2400px/秒² → 最高約 108px(可爬上 2 格高), 全速跳躍水平約 156px(可越過 3 格寬的坑)。按住跳躍鍵短於 0.15 秒時初速減半。
21. 地形為實心方塊, 沒有單向平台。

### 關卡構成(RD 依此排地形; 單畫面, 起點在左、終點在右)
| 關 | 名稱 | 怪物(主路線) | 礦脈(主路線旁) | 發光花 | 獵人區(吊橋後) | 礦工區(碎石牆後) | 主路線直衝目標時間 |
|---|---|---|---|---|---|---|---|
| 1 | 森林 | 狼 4、甲蟲 1 | 4 | 低處 2 + 浮空島 4 | 狼 2 | 礦脈 2 | 約 14 秒 |
| 2 | 礦谷 | 狼 4、甲蟲 2 | 5 | 低處 2 + 浮空島 5 | 狼 2 | 礦脈 3 | 約 18 秒 |
| 3 | 花崖 | 狼 5、甲蟲 2 | 5 | 低處 3 + 浮空島 6 | 狼 2、甲蟲 1 | 礦脈 3 | 約 22 秒 |

- 怪物分布在主路線上與兩側: 把怪全清乾淨要在射程內停留, 比直衝多花時間(獵人「多賺 vs 跑快」的取捨)。
- 主路線旁的礦脈嵌在路邊牆面或小凹處, 要停下來敲(礦工的取捨); 浮空島要繞上去(精靈的取捨)。
- 第 2、3 關各放 2~4 個尖刺。
- 繩結放在獵人站在主路線某處時, 水平穿透箭打得到的高度。

## 操作(只用鍵盤)
| 玩家動作 | 按鍵 |
|---|---|
| 左右移動 | ← → |
| 跳躍(精靈在空中再按 = 二段跳) | Z |
| 技能(獵人穿透箭 / 礦工鎬擊 / 精靈按住滑翔) | X |
| 攻擊 | 自動, 無按鍵 |
| 大地圖: 換列(關卡列 / 職業列 / 終極目標) | ↑ ↓ |
| 大地圖: 列內選擇 | ← → |
| 大地圖: 確定(進關 / 解鎖 / 換職業 / 買終極目標) | Z |
| 大地圖: 重開說明 | 空白鍵 |
| 說明頁: 翻頁 | ← → |
| 說明頁: 下一頁 / 最後一頁關閉 | Z |
| 結算面板: 回大地圖 / 再跑一次 | Z / X |
| 失敗面板: 重來 / 回大地圖 | Z / X |
| 暫停面板(關卡內): 重來 / 回大地圖 | Z / X |

通用鍵: `Esc` 暫停 / 繼續(關卡內與大地圖都可)。本探索版不做音效, 沒有 `M` 靜音鍵與聲音圖示。

大地圖 Z 的行為依游標所在卡片狀態決定: 已開放關卡 → 用目前職業進關; 未開放關卡 / 未解鎖職業 / 終極目標 → 素材全部夠就買(扣除配方上每一種), 不夠不反應(卡片標出缺的那種); 已擁有職業 → 設為目前職業。

## 勝負與結束
- 單關: 碰終點旗 = 過關(結算面板); 失敗見規則 3(失敗面板)。
- 整場: 買下「飛空艇」→ 結束面板顯示總遊玩時間; 按 Z 全部重置並回到說明頁第 1 頁。
- 沒有整場失敗。

## 範圍邊界
- 不做音效、不做存檔、不做難度曲線與更多關卡
- 不做手動攻擊鍵、不做怪物招式(只有碰撞傷害)
- 不做素材加工、合成樹(配方只用在解鎖與終極目標)
- 不做捲動關卡、單向平台、移動平台
- 大地圖縮圖裡不畫怪物
