## 3. 形狀語言

扁平幾何、角色與可互動物件一律 2px 深色外描(殘影改淡白外描)、地形無外描; **職業色 = 該職業專屬機關的顏色**, 紅色只留給會傷人的東西。

## 4. 理念落實(經驗文件「成立」理念)

- **P0 辨識度先於好看**: 三類東西用三種手法分開 — 地形(無外描、暗暖灰)、危險(紅 + 尖角)、可互動(外描 + 職業色或金色); 背景柱刻意低對比。
- **P1 視覺權重跟決策迫切度**: 資訊列裡最大最亮的是連段數字與它的價值階段(決定下一枚金幣值多少); 背景、地形最低調; 結算面板裡新舊效率比較是最大的兩塊。
- **P2 規則上存在的就要畫**: 空中衝刺剩餘(菱形格)、技能冷卻、連段計時、價值階段、這趟秒數全在資訊列; 判定框 = 畫面邊界(見尺寸表, 已用假 ctx 掃描確認)。
- **P3 一個意義一種長相**: ▼ 重量記號只出現在重騎機關(鐵箱 / 踏板 / 閘門)與重騎技能圖示; 金色只代表金幣與「錢 / 效率」; 價值階段色(tier1~3)在資訊列徽章與「+N」浮字共用; 說明頁示意圖全部呼叫遊戲內畫家。
- **P4 關鍵區分兩條通道**: 三職業 = 顏色 + 剪影(兜帽矮個 / 方盔寬肩 / 尖帽長袍); 風車停 / 轉 = 灰 + 靜止 vs 綠 + 旋轉弧; 踏板未壓 / 已壓 = 高度 + 亮度; 價值階段 = 顏色 + 數字 ×N(浮字另加字級)。
- **P7 每個元素掙版面**: 窄道不另畫記號(地形本身就是窄道); 卡片不寫職業能力說明; 說明頁圖裡不放與該頁無關的物件。
- **P9 最混亂的一刻驗收**: 衝刺拖影只畫在衝刺反方向; 煙霧 0.3 秒內淡掉; 浮字有深色描邊, 疊在任何縮圖上都讀得到。
- **P13 事件排隊**: 本作事件回饋都是物件尺寸級、時長 ≤0.8 秒的小特效(煙、浮字), 不出現全畫面事件卡, 沒有需要排隊的大事件。
- **P15 回饋強度 ∝ 份量**: 擊倒煙(單隻)< 震地波(範圍); 「+1 / +2 / +3」字級 13 / 16 / 18 + 顏色逐級升, +3 再加橘色光暈。
- **P17 進度圖形與數字分工**: 連段數字給「幾段」, 計量條只給「這段還能撐多久」(1.5 秒), 並附「再 N → ×下一階」; 技能冷卻扇形 + 剩餘秒數。
- **P18 重要資訊不能只閃一下**: 回放產出除了浮字, 資訊列常駐持有金幣與每分鐘總產量; 卡片常駐該關效率。
- **P19 資訊貼著物件**: 金幣浮字冒在縮圖裡撿到的位置; 加速等級與「X 加速」寫在那張關卡卡片上。
- **P21 示意圖選分岔例**: 第 2 頁斜衝格讓衝刺方向(右上)與面向(右)不同, 才看得出「跟著方向鍵」而不是「跟著面向」; 第 5 頁兩圖同一張地圖, 只差路線。

### 玩家姿勢(drawPlayer / drawGhost)

- 三職業剪影: 刺客 = 紫色兜帽矮個 + 粉色圍巾; 重騎 = 藍色方盔(紅纓)寬肩甲; 風術士 = 綠色尖帽長袍。全部畫在各自判定框內(28×36 / 32×44 / 28×44), 中心對齊 x, y, 腳底貼框底。
- `idle` 站; `run` 跨步 + 手前後擺; `rise` 收腿舉手; `fall` 張腿舉手; `dash` 身體前傾、框內前緣一道白色月牙刀光, 框外沿 dashAngle 反方向畫 3 條速度線(最長超出框 56px)+ 一個後方 22px 的淡色殘影; `slam`(僅重騎)雙腳併攏舉手 + 框內兩側白色下墜線; `glide`(僅風術士)雙臂平伸 + 淡綠披風張開; `hurt` 全身轉粉白、紅外描、X 眼。
- 非重騎傳 `slam`、非風術士傳 `glide` → 畫成 `fall`。
- `invuln===true`: 每 80ms 在 35% / 100% 不透明之間閃(美術內用 `performance.now()` 計時, 不需 RD 傳時間)。殘影不閃。
- facing: 只鏡像身體; 速度線與刀光照 dashAngle 的絕對方向畫(0 朝右、順時針為正)。

### 卡片

- 關卡卡片(左上 x, y, 400×290): 縮圖區外框畫在 (8,8) 384×216 的外緣。
  - `locked`: 縮圖區畫暗底斜紋 + 鎖 + 花費(可負擔金字 / 不足紅字)+「Z 解鎖」或「金幣不足」; 卡底較暗, 標號與名稱灰字。
  - `open`: 外框 + 名稱 + 右側「未過關」灰字(縮圖由 RD 畫進來)。
  - `cleared`: 卡邊轉暗金; 文字區: 回放職業小頭像 + 效率(金色, 「/分」)、加速 2 格(已買格填金)+ 倍率 ×1 / ×1.25 / ×1.5、右下「[X] 加速 ●花費」(不足時字變灰、花費紅); `speedLv>=2` 或 speedCost 為 null →「加速已滿」。
  - `selected===true`: 卡外 4px 白框 + 四角白三角(最遠到框外 6px)。
- 職業卡片(左上 x, y, 240×140): 左側頭像台 + 名稱。`locked` 頭像為深色剪影 + 鎖 + 花費 +「Z 解鎖 / 金幣不足」; `owned`「已擁有」+「Z 換上」; `active` 卡邊 4px 職業色 + 職業色「使用中」膠囊。選取框同上。

### 資訊列(0,0 起 1280×40)

- 兩種模式共用: 右端 1110~1274 持有金幣(金幣圖 + 大金字)+ 每分鐘總產量「+X.X/分」。**位置固定, 模式切換不移動。**
- `level` 另畫(由左至右): 職業小頭像(22)/ 血量心 ×maxHp(52 起)/「空衝」+ maxAirDash 個菱形(剩餘白填職業色邊, 用掉暗格)/ 技能圓(就緒: 職業色邊 + 亮圖示 +「技能」; 冷卻: 暗扇形 + 剩餘秒數)/ 連段區(x 440 起: 「連段」+ 數字 + 價值徽章 ×1/×2/×3 + 計時條 150px + 「再 N→×下一階」)/ 時間(806 起)/ 本趟金幣(902 起)/ 回放效率(1004 起, null 畫「—」)。
- 連段 = 0: 數字與徽章轉暗灰, 不畫計時條。計時條剩不到 30% 轉紅。
- 技能圖示: 刺客 = 紫色飛刃、重騎 = 藍 ▼ 落地、風術士 = 綠色翼弧。風術士滑翔傳 1/1 → 恆為就緒。

## 7. 判讀約定

- **震地波**: radius 指外緣; 環寬 7 往內畫。請 RD 判定用「與落點距離 ≤ radius」。
- **一次性特效的 t**: `drawPoof` / `drawSlamWave` / `drawPopup` 都以 t 從 0 走到 dur; 播完 RD 不再呼叫(美術不處理閒置值)。
- **大地圖縮圖**: RD 以 `translate + scale(0.3)` 重用關卡畫家; 所有關卡畫家都只用相對座標, 可直接縮放。`drawBackground` 自帶 1280×720 剪裁。殘影在縮圖裡約 9×13px, 靠淡白外描撐輪廓。
- **畫面文字歸屬**: 每張卡片 / 面板內的文字與按鍵提示(Z 解鎖、Z 換上、X 加速、Z 採用這一趟 等)都已由美術畫, **RD 不要再畫**; 大地圖最下方 y=660~710 那行操作提示由 RD 畫。說明頁的頁標題、說明文字、頁碼、翻頁提示、按鍵說明由 RD 畫, 美術只畫示意圖。
- **字型**: 只用系統字(微軟正黑體 → 蘋方 → Noto Sans TC → sans-serif), 不載外部字型。
- 本作沒有音效, 不畫聲音圖示。
