## game-a 岔路遠征
- 「A的戰鬥設計比較好 不管是職業或怪物行為的設計都比其他兩款好」 → 對應機制: 劍士衝刺斬 / 獵人自動射擊 / 炸彈工投彈的職業差異, 與野豬衝撞、盾兵正面擋、射手蜂射擊、跳蛙跳躍四種怪物行為(推論)
- 三層岔路: 「不是很喜歡 我希望關卡各有特色 而不是統一都分三層」 → 對應機制: 每關固定上 / 中 / 下三層、每層一種素材
- 「重跑時在結算畫面留新的還是舊的這個設計我覺得不錯」 → 對應機制: 結算並列新舊兩趟各素材產量, 玩家選留哪趟(H25)

## game-b 森林獸徑
- 「B的踩頭不是很喜歡 我希望怪是有血量的 以及要花一點心力去策略性的與之戰鬥 單純踩頭踩一下就死掉 不是我想要的戰鬥體驗」 → 對應機制: 踩頭戰鬥、怪物低血量
- 「時間內過關拿到金章 反而會讓玩家為了拚金章什麼都不做直接衝終點 但如果金章效益不大 又失去了它的意義 所以我覺得這個設計不好」 → 對應機制: 標準時間 / 金章 ×1.5(推論: 與「多撿 vs 跑快」的取捨衝突, 把天平壓向純衝刺)
- 「現場加成的設計應該是鼓勵玩家一直進關卡遊玩 但原本就已經是這樣設計了 因為玩家能做的事情只有進關卡玩 所以這個設計意義不大」 → 對應機制: 跑關時全場回放 ×2
- 「我不太喜歡B款穿山甲挖地的設計 因為他直接限制某個區域只有他可以進去 其他動物不能進去 我覺得好的設計是 不同角色(動物或職業) 會因為擅長某些事情所以比較能簡單達到某些目標 但不要是其他角色完全無法做到的 好的設計是 例如有些角色可以跳比較高 或是快速到高處 其他角色則同樣可以到高處 但要花比較多時間跳平台」 → 對應機制: 整片區域(地下層)只有單一物種進得去

## game-c 機兵工坊
- 「打出去的怪會撞傷別隻的設計我覺得不錯 這可以設計成是某個職業的技能 該技能會有擊退效果 擊退會造成連鎖」 → 對應機制: 擊飛連鎖; 使用者要它限定為某一職業的技能
- 「每個關卡有幾個格子可以蓋設施的設計我覺得很棒 我覺得可以改成在關卡中加入寶箱 可以開到道具 這些道具可以安裝在關卡的附魔格(可以換不同名字)上 會有不同效果 可以把道具拔下來裝在其他格子上 而關卡的格子可以擴充(需要花費素材) 這樣就可以讓玩家在關卡探索中更有目標」 → 對應機制: 關卡改造樁; 使用者提的改版: 關卡內寶箱 → 道具 → 裝到關卡附魔格(可拔下改裝)→ 花素材擴充格數

## 跨款比較
- 戰鬥以 A 最好(見 A 段原話)
- 素材差異: 「目前素材還沒有什麼差異性 感覺就是三種不同錢幣而已 沒有那種"某一種素材就是拿來某種事情"的感覺」 → 推論: 三款的素材用途都是「混在同一張解鎖價目表」, 每種素材沒有專屬用途

## 不好的體驗
- 「單純踩頭踩一下就死掉 不是我想要的戰鬥體驗」 → 可能來源: 踩頭秒殺(B)
- 「為了拚金章什麼都不做直接衝終點」 → 可能來源: 標準時間金章(B)
- 「這個設計意義不大」 → 可能來源: 現場加成(B)
- 「直接限制某個區域只有他可以進去」 → 可能來源: 整區物種鎖(B 地下層; 推論 A 的上 / 下層同性質)
- 「我希望關卡各有特色 而不是統一都分三層」 → 可能來源: 統一三層關卡結構(A)
- 「感覺就是三種不同錢幣而已」 → 可能來源: 素材沒有專屬用途(三款)

## 與已成立假設的衝突
- H04(3 職業技能不同 + 職業限定地點 / 機關 → 選職業成為策略決定)與 H22(職業移動能力不同 + 專屬機關 → 換職業 = 換一條路線): explore-1 成立依據含「第一關刺客可以鑽小路多拿點錢 但其他職業不能鑽小路」; 這輪說「直接限制某個區域只有他可以進去 其他動物不能進去」不好 → 使用者選「情境不同」。條件: 小捷徑、多拿一點的專屬路線可以; 整片區域只有某角色進得去不行。好的方向是「擅長的角色比較容易 / 比較快做到, 其他角色也做得到但要花更多時間」
