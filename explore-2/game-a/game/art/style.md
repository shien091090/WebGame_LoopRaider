# 岔路遠征 — 美術風格(explore-2 / game-a)

> RD 注意: `index.html` 必須宣告 `<meta charset="utf-8">`, 否則 art.js 裡的中文字串會變亂碼。
> 全部函式掛在 `window.Art`(非 ES module), 每個函式自己 `save()` / `restore()`。

## 邏輯畫布尺寸

`1280 × 720`(= interface.json 的 canvas, 固定寬度, 不依裝置變寬)。`Art.canvas = { width: 1280, height: 720 }`。

素材三色驗算(色相 / 灰階): 木材 28° / 104、魔晶 285° / 155、鐵礦 205° / 193。色相兩兩差 ≥ 80°, 灰階三階分開; 另有形狀(圓木 / 六角塊 / 菱形)當第二通道。
已知張力: 炸彈工黃(41°)與木材(28°)色相相近, 但一個是角色(白外框、人形)、一個是撿取物(小圖示), 類別層先分開, 明度也差很多(炸彈工亮、木材暗)。獵人綠與跳蛙綠同色名, 靠「白外框 vs 深框 + 紅眼」與人形 / 蛙形分開。

## 形狀語言

扁平幾何、圓角; **玩家 = 白外框人形, 怪物 = 深色外框 + 紅眼**; 危險只用「並排朝上的尖角 + 危險紅」, 其他機關與特效都不用尖角。

## 理念落實

- P0 辨識度先於好看: 三種素材同時換色相與形狀; 兩種可破壞地形換材質(冷灰整塊石 vs 沙黃碎片 + 黑縫), 和一般地面(褐土綠頂)三者一眼不同。
- P1 視覺權重跟著決策迫切度: 背景與遠山壓低對比; 會傷人的東西(尖刺、蜂彈、預備中的野豬、瞄準中的蜂)用全畫面唯一的危險紅; 射程圈只是 40% 細虛線。
- P2 規則上存在的東西畫面上就要存在: 盾兵的盾畫在面向側、又大又亮(規則上正面擋); 野豬「預備」與「暈眩」各有獨立外觀; 技能冷卻在 HUD 畫扇形; 結算 rates 為 0 也畫 0.0。
- P3 一個意義一種長相: 素材小圖示在地上、浮字、HUD、卡片、結算全部共用同一個畫法; 職業頭像在 HUD、卡片、結算共用; 說明頁示意圖全部呼叫遊戲內畫法。
- P4 關鍵區分走兩條通道: 玩家 vs 怪物 = 外框明暗 + 眼睛顏色 + 外形; 蜂彈 vs 箭 = 紅色圓球 vs 細長箭身 + 綠羽; 裂岩牆 vs 脆地板 = 色溫 + 整塊 / 碎片。
- P7 每個元素要掙得版面: 卡片只放決策要的字(名稱、產量、花費、可否購買); 地形不畫層名稱(層由地形自然分出, 說明頁才標)。
- P9 以最混亂的一刻驗收: 怪物與玩家各自帶外框, 擠在一起、疊在爆炸與煙上仍分得開; 浮字帶深色描邊。
- P13 事件排隊: 本作沒有美術自訂的事件提示層; 浮字與擊倒煙由 RD 依規則時點呼叫, 浮字上移、煙原地擴散, 不疊在同一帶。
- P15 回饋強度與份量成正比: 擊倒煙(48 框)< 爆炸(120 框); 揮砍刀光只在 0.15 秒內出現, 衝刺斬多一組速度線。
- P17 進度圖形與數字分工: 技能冷卻沒有數字, 只用扇形畫總進度(依邊界「沒有數字時圖形畫總進度」); 訓練等級用 3 格, 不另寫 3/3。
- P18 重要資訊不能只存在一瞬間: 「+N」浮字的結果留在 HUD(這趟素材、持有數)與卡片的每分鐘產量。
- P19 資訊貼著物件: 暈眩星星在野豬頭上、盾的擋下閃光長在盾上、浮字從撿到的位置冒出。
- P21 示意圖選分岔的例子: 說明第 4 頁同一關兩條路線, 一條繞進凹槽、停在野豬旁, 一條跳過凹槽與野豬直衝, 對照「撿多 vs 跑快」。

## 判讀約定

- 列舉欄位遇到表外值: `kind` 未知 → 灰色小圓(不是任何素材); `cls` 未知 → 灰色無帽人形; `pose` 未知 → 當 `idle`; 野豬 `state` 未知 → `walk`; 盾兵非 `block` → `walk`; 射手蜂非 `aim` → `hover`; 跳蛙非 `jump` → `crouch`; 卡片 `state` 未知 → `locked`。看到灰色物件請查傳入值。
- 布林欄位只認 `=== true`(`hit`、`invuln`、`reached`、`top`、`selected`、`canAfford`)。
- `invuln` 的閃爍用牆鐘(`performance.now()`, 每 90ms 切換), RD 不用另外處理。
- `drawExplosion` 的 `radius` = 判定**外緣**, 外框描邊畫在外緣內側; radius 夾在 0~60。`t >= dur` 時不畫。`drawPoof`、`drawPopup` 同樣 `t >= dur` 不畫。
- `drawRangeRing` 的 `radius` = 外緣, 虛線畫在外緣內側 1px。
- `drawHookRing` 的吊繩固定往上畫 20px(框外); 請在**地面之前**呼叫, 讓平台蓋住多出的繩。
- `drawPopup` 縮圖補償: 偵測到目前變換相對邏輯畫布小於 0.6 倍(扣掉 `canvas.width / 1280` 的底圖倍率)時, 浮字以起點為錨放大(上限 2.2 倍), 讓縮圖裡的「+N」約 12px 可讀。只影響縮圖, 關卡內原尺寸。縮圖本來就被 RD 裁切在縮圖區內。
- `drawLevelCard` 的縮圖區(卡片左上 (8,8) 起 384×216)美術先鋪深底與外框, RD 之後把縮圖畫進去; locked 時美術在此區畫鎖頭與花費。
- `drawPausePanel` 自己畫全畫面暗幕。其他面板(結算、失敗、結束)只畫面板本身, 若要暗幕請 RD 自行在呼叫前畫。
