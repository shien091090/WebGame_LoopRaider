## 形狀語言

扁平幾何 + 圓角, 地形與物件無描邊或深色描邊、**玩家獨有白色外輪廓**; **尖角(並排三角)只給危險**(尖刺、刺蝟背刺), 其餘一律圓頭(樹冠用圓葉、草叢用圓叢、方向箭頭用圓頭)。

| P1 視覺權重跟決策迫切度 | 危險(紅刺、背刺、追擊紅眼)與玩家白輪廓最顯眼; 背景遠樹最低調; HUD 的時間 / 標準時間用最大字 |
| P2 規則上存在就要畫出來 | 軟土鑽地中仍保留虛線內框(看得到範圍); 熊搖晃全程畫判定外緣虛線圈; 藏著的蛇在草叢露一對眼; 空蜂巢灰化加裂痕(拿不到了) |
| P3 一個意義一種長相 | 金 = 達標準時間(金章、HUD 秒數、終點旗)、綠 = 現在按 Z 可做、紫 = 現場加成、紅 = 危險; 素材圖示在地上、浮字、HUD、卡片、結算共用同一個畫法 |

## 物件表

所有 x, y 都是**螢幕座標**、物件判定框中心(除註明「左上角」); 時間單位秒。表外值的預設: 未知 `sp` → 松鼠、未知 `kind` → 橡實、未知怪物 `state` → 閒置 / 藏著、未知卡片 `state` → locked(上鎖)、NaN → 0。布林欄位一律只認 `=== true`。

| 物件 | 函式 | state 欄位 | 各狀態視覺 |
|---|---|---|---|
| 關卡背景 | `drawBackground(ctx)` | — | 暗綠漸層 + 遠樹剪影, 畫滿 1280×720, 不隨鏡頭 |
| 大地圖背景 | `drawMapBackground(ctx)` | — | 深綠漸層 + 淡葉影; y 664 以下壓暗一條給 RD 的操作提示列 |

### 卡片版面(關卡卡片 400×290)

- 縮圖區 (8,8) 384×216: open / cleared 只畫深底 + 外框(RD 之後蓋縮圖); locked 畫鎖頭 + 花費(置中)+ 「Z 解鎖」(綠, 買得起)或「素材不足」(灰)

### HUD 版面(0,0 起 1280×40, 82% 深底)

- map: x 440 起三組「圖示 持有數 +x.x/分」, 左側小字「持有素材 / 每分鐘產量」
- level(由左到右): 物種頭像 → 血量愛心 maxHp 顆 → 技能圈(X 字; 可用 = 綠實心圓, 冷卻中 = 深底 + 已恢復部分的綠扇形 + 虛線外圈)→ 小章(標準內金 / 超過灰)+ 秒數(標準內金字 / 超過灰字)+「/ 標準 N 秒」+ 下方細條(長度 = time/parTime, 超過時整條灰並寫「超過」)→ x 488「這趟」三種素材 → x 720「持有」三種素材 + 每分鐘產量(liveBoost 時產量字變紫)→ 右端 x 1112~1272 紫色「現場加成 ×2」徽章(只在 liveBoost=true)
- hp > maxHp 時夾到 maxHp; maxHp 上限 10

## 判讀約定

- **縮圖內的浮字放大**: `drawPopup` 會讀 `ctx.getTransform()` 的縮放; 縮放小於 0.5(大地圖縮圖的 0.3)時, 浮字整組放大 `min(3, 0.75 / 縮放)` 倍(0.3 → 2.5 倍, 畫面上約 13px 字), 讓縮圖裡的「+N」讀得到。上移 30px 不放大。RD 若在整張畫布再乘一層高 DPI 縮放, 判斷會跟著變, 請用 CSS 放大而不是 ctx 縮放。
- `drawPausePanel` 自己畫全畫面暗幕; `drawFailPanel` 不畫暗幕(介面沒寫, 由 RD 決定要不要壓暗)。
- 大地圖最下方 y 670~710 的操作提示由 RD 畫, 美術各卡片不畫那一行; 卡片內的「Z 解鎖 / Z 換成這隻 / Z 舉辦祭典」按鍵字由美術畫(介面文字歸屬: 每個函式畫自己卡片內的按鍵提示)。
- `drawLevelCard` 的 open / cleared 縮圖區請在本函式**之後**畫縮圖並裁切在 (x+8, y+8, 384, 216) 內; 外框畫在縮圖區外 1px, 不會被縮圖蓋掉。
- 蛇: x, y 是草叢中心; 判定框由 RD 算, 美術的蛇頭中心 = x + facing × e, e 依 state / stateT 算(見物件表)。
- `drawSoil` open=true 時請在玩家之前畫軟土(玩家畫在土上, 看得到土裡的穿山甲)。

## 繪製層級(由下到上)

背景 → 軟土 / 地面 / 尖刺 → 蜂巢 → 素材、終點旗 → 怪物 → 玩家 → 橡實彈 → 搖晃波 → 擊倒煙 → 浮字 → HUD → 面板(結算 / 失敗 / 暫停 / 結束)。大地圖: 地圖背景 → 卡片(關卡卡片之後畫縮圖)→ RD 操作提示 → HUD → 暫停面板。
