# 機兵工坊 美術規格(explore-2 / game-c)

> RD 只讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`, 否則 art.js 的中文字在 file:// 下會變亂碼。

## 邏輯畫布尺寸

`1280 × 720`(= interface.json 的 canvas, 固定寬度, 沒有依裝置變寬)。所有座標以此為準, 美術不自己乘縮放。

**三種素材色驗算**(node 算, HSV 色相 / 灰階): 礦石 224° / 108、電池 131° / 158、齒輪 46° / 206。色相兩兩差 93° / 85° / 178°, 灰階分三階(差 50 / 48)。形狀也各不同(多面晶體 / 直立電池 / 八齒輪), 縮圖 0.3 倍時靠顏色 + 明度。

**色彩張力(請製作人驗收)**: 鑽頭號橘 `#ff8a1e`(29°)離危險紅 0° 只差 29°、離齒輪黃 46° 只差 17°, 色輪已排滿(三素材 + 三機兵 + 危險)。處理: 橘只出現在**白機身玩家**的部件上(類別層先分: 白身深描邊的玩家 vs 地上的素材 / 暗身紅眼的怪物), 不填在任何素材或危險物上; 「素材不足」一律用壓暗灰, 不用紅。最差那一幀: 鑽頭號站在齒輪旁、身後有尖刺。軟岩沙色與鑽頭號橘同色相(29°), 是刻意的「鑽頭能處理的東西是暖色」, 明度與飽和度差很多(軟岩是暗沙)。

## 形狀語言

工業機械風: 平塗 + 深色描邊(玩家、怪物、素材都描邊), 地形方正無圓角、物件圓角; 玩家是白色方塊機身, 怪物是暗色有機圓形 + 紅眼, 危險 = 朝上尖角 + 紅, 其他元素不用並排朝上的尖角。

## 理念落實

| 理念 | 本作怎麼落實 |
|---|---|
| P0 辨識度先於好看 | 三類物件先用類別層分開: 白機身玩家 / 暗身紅眼怪物 / 描邊小圖示素材; 背景只用低對比剪影 |
| P1 視覺權重跟著決策迫切度 | 全畫面最亮的是玩家與危險紅; 背景、地形壓在低明度; 連鎖字最強一級才加底牌, 而且畫在倒下位置而非 HUD 上 |
| P2 規則上存在的東西畫面上要有 | 爆炸紅環外緣 = 判定半徑 90; 盾甲蟹硬殼只畫在面向側; 空改造樁畫虛線框 + 加號; 擊飛中的怪物有翻滾 + 速度線(它此刻會撞傷別隻); 卡片上畫出回放秒數與每分鐘產量 |
| P3 一個意義一種長相 | 磁力 = 紫(磁力號、磁門、磁吸波紋); 螺旋號青 = 氣旋彈; 素材圖示在地上、浮字、HUD、卡片、面板花費都用同一個畫法; 鍵帽在所有面板同一個長相 |
| P4 關鍵區分走兩條通道 | 素材: 色相 + 明度 + 形狀; 盾甲蟹硬殼: 亮度 + 厚度鉚釘; 炸彈蟲引爆: 紅白閃 + 閃爍頻率漸快 + 體積微脹; 終點旗: 未到 = 半桿暗頂珠 / 已到 = 升頂亮環 |
| P7 每個元素要掙得版面 | 卡片不畫「回放中」字樣(縮圖本身在動); HUD 技能只畫 X 鍵圓盤不寫「技能」; 資訊列不寫「持有」 |
| P9 以最混亂的一刻驗收 | 怪物群擠在 160px 內時, 每隻靠剪影(圓球 / 炸彈 + 引信 / 橫寬蟹 + 白殼 / 鳥)分, 不靠顏色 |
| P13 事件排隊 | 浮字與連鎖字由規則決定時間點; 連鎖字畫在最後倒下處、+N 浮字畫在取得處, 兩者都自己上移 30px 並淡出, 不疊在 HUD |
| P15 回饋強度和事件份量成正比 | 連鎖字 2 / 3 / ≥4 三級: 22px / 26px 粗描邊 / 30px + 深底牌 + 放射線; 擊倒煙(單隻)< 爆炸(範圍) |
| P17 進度圖形與數字分工 | 技能冷卻只用圓盤扇形(無數字); 螺旋號燃料只用機身背後的小量表; 加速等級用 2 格 + 倍率字 |
| P18 重要資訊不能只閃一下 | +N 浮字閃過, 但 HUD 的持有數與「這趟 +N」常駐; 結算面板留下這趟素材與每分鐘產量 |
| P19 資訊貼著物件 | 改造面板的樁標籤對齊各樁 x 並以三角尖指向預覽; 卡片的改造樁 3 格就在卡片內 |
| P21 示意圖選分岔例子 | 說明第 4 頁兩張同一關並排, 只差路線(繞路撿素材 vs 直衝), 讓「撿多 vs 跑快」是一個選擇 |

### 玩家姿勢(`drawPlayer`)

三台共用白色方塊機身(頭 + 護目鏡 + 身體 + 雙腳), 機兵色畫在眼、腰帶與專屬部件上; facing=-1 整隻鏡像。

| pose | 鑽頭號 drill | 螺旋號 heli | 磁力號 magnet |
|---|---|---|---|
| idle / run | 手上小鑽頭; run 雙腳前後擺 | 頭頂旋翼慢轉、手上炮管 | U 型磁鐵手 |
| rise / fall | rise 收腳 / fall 腳伸直 | 同左, rise 旋翼轉快 | 同左 |
| attack | **大鑽錐伸到面向側框外 50×40 內**, 轉動紋 + 兩道速度線(0.15 秒內 poseT 驅動) | 炮口小旋渦(框內; 子彈由 drawCycloneShot 畫) | **磁力拳伸到面向側框外 60×44 內**: 長臂 + 紫拳 + 速度線 |
| drill | 鑽頭伸進面前一格(框外約 24px)+ 沙色碎屑 | 不適用 → 畫 idle | 不適用 → 畫 idle |
| hover | 不適用 → 畫 rise | 旋翼畫成青色模糊圓盤 + 腳下青色氣流 | 不適用 → 畫 rise |
| magnet | 不適用 → 畫 idle | 不適用 → 畫 idle | 3 道紫色波紋由 18px 往外擴到 **至多 120px(外緣)** 並淡出, 磁鐵手發光 |
| hurt | 全身後仰 + 縮 0.82 + 紅色罩 + 眼變 × | 同左 | 同左 |

- fuel(只有螺旋號): 機身背後 4×18 的直立量表, 青色由下往上 = 剩餘; 其他機兵傳 null 不畫。
- invuln=true: 以牆鐘 12Hz 在 100% / 35% 不透明間閃。

### 改造面板版位(`drawBuildPanel`, 面板左上 (40,60), 下列為畫布絕對座標)

- 全畫面暗幕 66% → 面板 1200×600 → 標題 (60, 98)。
- 預覽外框: 畫在 (60,130) 640×360 的外側 1px(RD 之後畫進去的預覽會蓋住內部)。
- 樁標籤列 (60,500) 起: 三個 80×32 標籤, 中心 x = `slotPos[i].x`(也接受 `[x, y]`; 夾在預覽範圍內), 上方小三角指向預覽; 選中(col=i)整塊白底黑字。標籤右側畫該樁目前設施的小圖示。

## 判讀約定

- **爆炸 radius = 判定外緣**: 紅環的外緣剛好在 radius(環寬 3px 往內畫), 請 RD 以「怪物 / 玩家判定框與圓心距離 ≤ radius」判定。
- **一次性特效**(爆炸、擊倒煙、連鎖字、+N 浮字)t ≥ dur 時函式自己不畫; 播完 RD 可以停止呼叫。
- **時長常數**: 全部由 state 傳入, 美術沒寫死規格秒數。缺值時的預設: springDur 0.25、fuseDur 0.3、爆炸 / 擊倒煙 dur 0.3、連鎖字 / 浮字 dur 0.8(與規格一致)。
- **牆鐘動畫**(`performance.now()`): 玩家無敵閃爍、炸彈蟲引信火花、擊飛中的炸彈蟲 / 盾甲蟹翻滾。位移都在框內, 回放縮圖裡照樣會動。
- **縮圖裡的字**: `drawPopup` 與 `drawChainText` 會讀 `ctx.getTransform()`, 扣掉底圖倍率(`ctx.canvas.width / 1280`)後, 若相對邏輯畫布的縮放 < 0.6(大地圖縮圖的 0.3、改造預覽的 0.5 都算), 以 `min(2.2, 0.66 / 縮放)` 在自身中心放大, 畫面上約 12~15px。這時字會超出縮放後的 `size`, 屬預期(浮字不參與判定)。RD 用 `ctx.scale(devicePixelRatio)` 做高解析度時不受影響; 不需要 RD 配合。
- **磁吸波紋**由 poseT 驅動, 每 0.45 秒一圈; 外緣固定不超過 120px。
- 機兵不支援的 pose(例: 鑽頭號 hover)畫成最接近的合法姿勢(見玩家姿勢表), 不拋錯。
- `slotPos` 各項接受 `{x, y}` 或 `[x, y]`; 缺值時三個標籤平均分在預覽寬度。
- 卡片 `builds` 長度不足時, 缺的那格畫空框(none)。
