# 機兵工坊 — 玩家說明

翻頁: `←` `→`; `Z` 下一頁, 最後一頁按 `Z` 開始。大地圖上按空白鍵可再打開。

## 第 1 頁: 衝到終點
- 文字: 碰到旗子就過關
- 圖要示意什麼: 一個關卡畫面的縮小版, 鑽頭號在左邊起點, 中間有礦石素材、一群擠在一起的滾石蟲與炸彈蟲, 右邊是終點旗; 一條虛線箭頭從鑽頭號經過礦石連到終點旗。
- 示意圖框最小寬高: 480×270

## 第 2 頁: 操作
- 文字: 空白鍵 跳、Z 攻擊、X 技能
- 圖要示意什麼: 四格小圖: `←` `→` 配鑽頭號跑步; 空白鍵配鑽頭號跳起; `Z` 配鑽頭號鑽擊一隻滾石蟲、滾石蟲往後飛出去(帶速度線); `X` 配鑽頭號鑽碎面前一格軟岩(碎屑飛散)。角落小字標 `Esc` 暫停。
- 示意圖框最小寬高: 600×220

## 第 3 頁: 過關後一直重播
- 文字: 過關的關卡會不停重播賺素材
- 圖要示意什麼: 大地圖上一張已過關的關卡卡片, 縮圖裡重演著剛才那趟: 鑽頭號鑽擊一隻滾石蟲, 滾石蟲被擊飛撞上牆化成煙, 該處冒出「+1」與礦石小圖示; 頂端資訊列的礦石數變大(前後兩個數字或箭頭)。
- 示意圖框最小寬高: 480×300

## 第 4 頁: 撿多還是跑快
- 文字: 撿越多、跑越快, 重播賺越快
- 圖要示意什麼: 同一個關卡並排兩張小圖: 左圖路線繞去打怪、多撿素材, 下方標「素材多 / 秒數長」; 右圖路線直衝終點, 下方標「素材少 / 秒數短」。不打勾打叉, 不畫改造樁上的設施。
- 示意圖框最小寬高: 560×240

## 自查
- 操作章節逐條對照: 移動、跳、攻擊、技能、暫停(第 2 頁); 翻頁、關閉、重開說明(本檔開頭說明列); 大地圖選擇與確定、`X` 開改造面板(卡片上畫『X 改造』、下方提示列也有)、改造面板內的選欄 / 選項 / 蓋下去 / 關閉(面板最下方一行提示)、結算 / 失敗 / 暫停面板按鍵都由畫面當場提示, 不另寫。
- 狀態驗算: 第 2 頁鑽擊 1 傷害、滾石蟲血 2 → 打一下還活著, 進入擊飛 ✓(不能畫成一下打死)。第 3 頁滾石蟲先被鑽擊 -1 剩 1 血, 擊飛撞牆再 -1 → 倒下, 掉礦石 1 → 「+1」礦石 ✓; 縮圖照規則 6、7 會重演擊飛與擊殺 ✓。第 2 頁軟岩在面前一格、鑽頭號可鑽穿 ✓; 四個動作鑽頭號都有(開局機兵) ✓。第 1 頁第 1 關有滾石蟲 2、炸彈蟲 2, 依關卡構成「至少 2 群 3 隻以上」可擠在一起 ✓。
- 刻意不寫: 擊飛的怪撞倒其他怪、炸彈蟲連爆、連鎖字(要驗玩家會不會自己想到把怪排成一串打; 第一次打到就看得到)、其他機兵與專屬區、關卡改造與加速器(過關後卡片上出現『X 改造』, 面板當場說明效果與「下一趟才出現」)。
