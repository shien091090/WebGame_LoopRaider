# 機兵工坊(再投資: 把素材蓋回關卡裡, 重跑收割, 越賺越快)

## 概述
單畫面橫向平台動作, 角色包裝成三台機兵(鑽頭號、螺旋號、磁力號), 各自開得了不同的素材區; 戰鬥是**擊飛連鎖**: 打中的怪物會被擊飛, 撞到別的怪物一起受傷, 炸彈蟲倒下還會爆炸連鎖。過關後的回放完整重演; 素材除了解鎖, 還能**改造已過關的關卡**(在 3 個改造樁上蓋素材堆 / 怪物巢 / 彈跳板)和買**回放加速器**。改造只出現在之後新跑的趟數, 舊回放照舊, 要重跑才收得到。
驗證假設: H01、H06、H07、H18、H33、H43、H45、H46、H47、H48

## 核心循環
選機兵進關 → 擊飛怪物撞成一串、開機兵專屬區、撿素材衝終點 → 回放在大地圖重演產出 → 解鎖下一關 / 機兵, 或把素材投資回舊關(蓋素材堆、怪物巢、彈跳板, 買加速器) → 重跑舊關把新蓋的東西收進回放 → 產量更高 → 再投資。

## 規則

### 通用(使用者規定 + 第 1 輪回饋, 本輪三款共通)
1. 每關是一個不捲動的單一畫面(32×18 格, 每格 40px), 第 0 列被頂端資訊列蓋住, 不放任何物件。
2. 玩家從起點出發, 判定框碰到終點旗即過關; 沒有其他過關條件。
3. 失敗條件: 血量歸 0、碰到尖刺、掉出畫面下緣。失敗時這趟作廢(不存回放、素材不入帳), 跳出失敗面板。
4. 這趟拿到的素材只在過關時才入帳。
5. 素材共 3 種: **礦石**、**電池**、**齒輪**。地上的素材碰到即得 1; 擊倒怪物立即得到該怪的掉落。
6. **錄影 = 整關重演**: 從進關到過關, RD 每幀記錄整關狀態: 玩家(位置、機兵、面向、動作)、每隻怪物(位置、面向、行為狀態、是否存活、是否被擊飛、受擊閃)、飛行物(氣旋彈)、爆炸、已拿走的素材、已鑽碎的軟岩、已打開的磁門、彈跳板彈起、擊倒煙、連鎖字與「+N」浮字; 這趟進關時的改造內容一併記下。並記錄每次得到素材的時間點、位置、種類與數量。
7. **回放**: 每個已過關卡在大地圖卡片的縮圖裡以原速(乘加速器倍率)無限循環重演錄影(播完立刻從頭, 無間隔), 畫的是錄影當時的關卡(含當時的改造); 每播到一個得到素材的時間點, 持有的該種素材 + 該數量, 並在縮圖該位置冒出「+N」。
8. 回放在大地圖、關卡內、結算面板、改造面板時都持續產出; 只有暫停與說明頁開著時停止。
9. 每關只留一條回放。資訊列顯示三種素材的持有數與每分鐘總產量(各種素材分開加總, 已含加速器倍率)。
10. 開局: 素材全 0, 只開放第 1 關與鑽頭號。
11. 玩家血量 3; 碰到怪物或在爆炸範圍內扣 1, 之後無敵 1 秒並被往反方向彈開 80px。

### 本款特有
12. **碰旗即取代**: 過關時這一趟一律成為該關回放(取代舊的)。不想取代的話, 在關卡內按 `Esc` 暫停 → `X` 回大地圖, 這趟作廢、舊回放保留。
13. **擊飛**: 玩家的攻擊打中怪物 → 怪物扣 1 血; 若還活著, 進入「擊飛」: 朝遠離玩家的水平方向以 420px/秒飛出(磁力號 520px/秒), 最多 0.6 秒或撞到地形為止, 期間不受重力、不傷玩家。
    - 擊飛中的怪物碰到其他怪物 → 被碰到的怪物扣 2 血, 若還活著也進入擊飛(方向同撞它的那隻)。
    - 擊飛中撞到地形 → 自己扣 1 血。
    - 擊飛結束仍活著 → 落地恢復原本行為。
14. **連鎖字**: 同一次攻擊(含它引發的擊飛碰撞與爆炸)擊倒 2 隻以上怪物時, 在最後一隻倒下的位置冒出「N 連鎖」(N = 擊倒數)。連鎖只是顯示, 不改變掉落數量。
15. **怪物**(四種行為, 各掉一種素材; 被擊倒時冒擊倒煙):
    - **滾石蟲**(滾動): 以 150px/秒沿地面滾, 撞牆或到平台邊緣回頭。血 2。
    - **炸彈蟲**(連爆): 以 40px/秒慢走, 撞牆或到邊緣回頭。被擊倒時原地閃 0.3 秒後爆炸, 半徑 90px(外緣)內的怪物受 2 傷害(可再引爆其他炸彈蟲)、玩家在範圍內扣 1。血 1。
    - **盾甲蟹**(正面硬): 以 50px/秒橫走, 撞牆或到邊緣回頭。玩家的攻擊從它面向那側打來時被擋下(不扣血、不擊飛, 殼閃一下); 背後的攻擊、擊飛中的怪物、爆炸都照常傷它。血 2。
    - **俯衝鷹**(俯衝): 在空中定點上下飄。玩家在它下方、水平距離 120px 內 → 朝玩家當下位置以 450px/秒俯衝(最多 0.6 秒或碰到地形)→ 以 150px/秒飛回原位 → 冷卻 1.5 秒。血 1。
16. **機兵**(切換只能在大地圖); 攻擊鍵 `Z`、技能鍵 `X`:
    - **鑽頭號**(開局): 移速 260、跳躍初速 720。攻擊=鑽擊: 面向側 50×40, 冷卻 0.35 秒。技能=鑽穿: 鑽碎面前一格(面向側、與身體中心同高的那格)的**軟岩**, 冷卻 0.4 秒。能去: 主路線、礦坑(軟岩後方, 放礦石)。
    - **螺旋號**: 移速 260、跳躍初速 720。攻擊=氣旋彈: 朝面向水平射出, 500px/秒、飛 300px, 碰到第一隻怪物即算命中(同樣扣 1 並擊飛), 冷卻 0.5 秒。技能=懸停: 按住時以 220px/秒上升, 燃料 1.2 秒, 落地補滿。能去: 主路線、高台(離主路線地面 5 格高, 放電池)。
    - **磁力號**: 移速 230、跳躍初速 700。攻擊=磁力拳: 面向側 60×44, 擊飛速度 520px/秒, 冷卻 0.45 秒。技能=磁吸: 120px 內的**磁門**整扇打開(這趟有效), 冷卻 1 秒。能去: 主路線、倉庫(磁門後方, 放齒輪)。
17. **主路線**(起點到終點)不需任何機兵技能, 三台機兵都能過每一關。礦坑、高台、倉庫的出口都以「往下跳 3 格以上的落差」接回主路線, 不能從出口倒走進去。
18. **關卡改造**: 每關有 3 個**改造樁**(固定位置, 都在主路線上, 第 1~3 號由左到右)。關卡過關後, 可在大地圖開該關的改造面板, 花素材在每個樁上蓋 1 種設施(蓋了不能拆、不能換):
    - **礦石堆 / 電池堆 / 齒輪堆**: 進關時在樁上方排出 4 個該種素材。
    - **怪物巢**: 進關時在樁旁放出 炸彈蟲 2 + 滾石蟲 2(擠在 120px 內)。
    - **彈跳板**: 站上去以 1000px/秒向上彈起(最高約 208px)。每個樁正上方 5 格處都有一段捷徑平台通往終點方向, 只有彈跳板(或螺旋號懸停)上得去, 走捷徑比走主路線快約 3 秒。
    - 設施只出現在**之後新跑的趟數**; 已存的回放照錄影當時的關卡播放, 產量不變。
19. **回放加速器**: 也在改造面板買, 每關 2 級, Lv1 回放速度 ×1.25、Lv2 ×1.5(同一條回放每分鐘產出同比例增加); 立即生效, 換了新回放也保留等級。
20. 素材用途: 解鎖第 2、3 關、解鎖螺旋號與磁力號、改造、回放加速器、買終極目標「巨神機」。買下巨神機即遊戲結束(勝利)。

### 物理(共用部分)
21. 重力 2400px/秒²; 按住跳躍鍵短於 0.15 秒時初速減半(小跳)。跳躍初速 720 時最高約 108px(可爬上 2 格)。地形為實心方塊, 沒有單向平台、移動平台。三台機兵判定框都是 32×44。

## 勝負與結束
- 單關: 碰終點旗 = 過關(結算面板); 失敗見規則 3(失敗面板)。
- 整場: 買下巨神機 → 結束面板顯示總遊玩時間; 按 `Z` 全部重置並回到說明頁第 1 頁。
- 沒有整場失敗。

## 範圍邊界
- 不做音效、不做存檔、不做難度曲線與更多關卡
- 不做捲動關卡、單向平台、移動平台
- 不做新舊回放比較或保留選擇(碰旗即取代)
- 不做設施拆除、升級、自由擺放位置(只有固定的 3 個樁)
- 不做連鎖倍率(連鎖字只是顯示)
- 不做怪物魔王、掉落機率(掉落固定)
