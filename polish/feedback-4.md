## 不喜歡 / 要改

### 新手教學全面重做
「現在的新手教學太沒存在感了」→ **現有新手教學(規格「新手教學」表、drawTutorial 的各階段與觸發)全部移除**, 改成以下流程。教學只出現一次(第一關第一次過關後不再播放, 重玩第一關也不重播, 不提供重看)。大箭頭、提示文字框、按鍵外觀、操作方式面板、修復點強調、重生落下的畫法照 visual/direction.md 對應元素。

1. **大地圖**: 第一次進大地圖時, 有明顯的提示: 大箭頭指著第一關卡片 + 文字「選擇這一關」
2. **關卡準備頁**: 大箭頭指著「開始挑戰」 + 文字「直接按Z開始關卡吧!」; 其中「Z」用按鍵外觀(keycap)畫, 不是純文字。**全遊戲有按鍵提示的地方一律比照, 用按鍵外觀**(例: 商店「Z購買」、各面板按鍵說明)
3. **進入第一關**: 遊戲先暫停, 自動播放教學演出, 全程不需要玩家操作。依序逐一出現大箭頭指著目標 + 提示文字, 文字以小動畫逐字顯示:
   1. 角色: 「這是你」
   2. 從角色身上淡入「操作方式」面板: ←/→、↑、Z、X, 每個按鍵旁有功能小字說明(按鍵用 keycap 外觀); 面板淡入後移到畫面左上角, **這一關結束前一直固定在左上角**供玩家查看
   3. 素材(同時有箭頭指著石頭與木頭): 「這是素材,多多收集,不同素材有不同用途」
   4. 怪物: 「打怪也會掉落素材」
   5. 終點: 「終點,抵達後就可以結算關卡了」
   6. 3 個待修復點(工程牌 + 結構格 + 迷霧)顯示輪廓邊緣光, 其餘場景稍微壓暗, 同時出現三個大箭頭指著三個修復點, 文字「收集素材後可以修復通道, 解鎖更多可以去的地方」
4. 演出結束後暫停解除, 玩家自由移動; 畫面上只剩左上角的操作方式面板
5. **第一關(教學關)過關條件**: 要撿完場景上所有素材(修復點裡的除外)並打死所有怪物, 才能觸發終點。未達成就在終點按↓時跳出提示: 還有素材 → 大箭頭指著(最近的)素材 +「先撿素材再結算關卡吧!」; 素材撿完但還有怪 → 大箭頭指著怪物 +「先打死怪物再結算關卡吧!」。**只套用第一關, 其他關卡維持現狀**
6. **第一關被打死**: 不跳失敗彈窗, 死亡動畫播完停頓片刻, 角色從起點上空掉下來重新開始(重生落下演出)。**只套用第一關, 其他關卡維持現行失敗彈窗**
   - 第一關的教學關若需要改關卡內容(素材 / 怪物位置), 寫在規格請使用者用編輯器擺, 不自行改 levels.js
7. **第一關過關、回到大地圖後**(接續教學, 期間鎖住玩家操作, 直到總結板關閉):
   1. 大箭頭指著第一關卡片 + 逐字文字「接著會不斷重演剛剛的通關歷程」
   2. 若在這句逐字顯示完之前, 或顯示完後 3 秒內, 第一關回放有獲得素材(出現素材飛行特效), 文字直接往後逐字接上「, 源源不絕累積素材」
   3. 若顯示完 3 秒內都沒獲得素材: 原文字消失, 大箭頭改指該卡片的通關秒數, 逐字文字「但這次通關花比較多時間, 素材累積的比較慢, 可以考慮重刷一次關卡」
   4. 大箭頭指升級所 + 「升級所可以解鎖新職業、提升角色能力」。**從這一步起每個提示要按 Z 才推進**(前面幾步自動推進); 提示上要有「按 Z 繼續」的按鍵外觀提示
   5. 按 Z 後: 大箭頭指商店 + 「商店可以購買裝置,裝置可以安裝在關卡中,提升素材產量」
   6. 按 Z 後: 畫面中央出現大板子, 標題「新手教學總結」, 下面 4 個圖文區塊依序以小動畫出現, 每個區塊盡量附對應的遊戲畫面:
      - 區塊 1: 刷關卡
      - 區塊 2: 刷越快,素材累積越快
      - 區塊 3: 素材可解鎖修復工程、解鎖新關卡
      - 區塊 4: 有空也多去升級所和商店看看吧!
      - 最下方提示「按 Z 關閉」(按鍵外觀); 按 Z 關閉後解除鎖定, 新手教學結束

### 按鍵提示
- 關卡內工程牌附近的提示「按 Z 修復工程, 開出新區域 [Z]」: 右邊另外畫的 Z 按鍵是多餘的, 拿掉; 改成句中的「Z」直接用按鍵外觀(keycap)。全遊戲同類提示一律這樣: 按鍵嵌在句中用按鍵外觀, 不在句尾另外重複畫一顆
