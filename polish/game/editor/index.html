關卡編輯器 使用說明

這個編輯器直接讀寫遊戲用的 game/levels.js。畫面上每一格 = 遊戲裡的一格(40px), 整關 32 欄 × 18 列。滑鼠移到格子上, 下方會顯示「欄、列」。

基本操作

  • 上方 1~8 切換關卡(或按 [ ])。關卡按鈕右上的紅點 = 這關有嚴重問題的數量。
  • 左邊選工具, 在畫面上左鍵放置 / 畫, 右鍵刪除(地形工具右鍵 = 擦掉)。
  • 地形工具可以按住拖曳連續畫; 勾「矩形填滿」或按住 Shift 拖曳 = 拉一個矩形一次填滿。
  • 選取移動: 點物件選起來, 按住拖曳搬家; Delete 刪除。同一格疊了好幾樣東西時, 再點一次會換選下一樣。選起來後右邊可以改種類(例如素材換成水晶、怪物換種類、寶箱換裝置)。
  • Ctrl+Z 復原、Ctrl+Y 重做、Ctrl+S 存檔、Esc 取消選取、H 開關說明。

物件要點在哪一格

  • 起點、終點、寶箱、工程牌、地面怪物: 點它們身體所在的那一格, 腳下那格要是地面。
  • 飛行怪(射手蜂、俯衝鷹、蝙蝠群)、素材、尖刺: 點它所在的格子。尖刺放在地面上方那一格。
  • 落石蜥: 點天花板正下方那一格(牠倒掛在天花板上)。
  • 巢母: 只能放在巢穴門工程的巢穴室裡, 放之前先在選項選主題(翠林 / 高崖 / 礦坑)。巢穴迷霧裡的怪會自動變成巢穴怪。

工程(每關 3 處)

  • 右邊「工程」先選 工程 1 / 2 / 3(也可按 1 2 3), 設定結構(斷橋 / 崩梯 / 堵塞隧道 / 巢穴門)與角色(捷徑 / 寶區 / 巢穴)。
  • 結構格: 拖曳畫出這處工程的格子。斷橋、崩梯 = 修好後變實心; 堵塞隧道 = 修好前是實心(亂石), 修好後打通。
  • 迷霧: 拖曳拉矩形, 蓋住修好後才開放的區域(可以有好幾個); 右鍵刪掉。迷霧區在修好前必須被牆、亂石或巢穴門完全擋住。
  • 巢穴門: 點門的左上格(門 2×2 格); 巢穴室: 拖曳拉出巢穴範圍。只有結構選「巢穴門」時能用。
  • 工程牌: 點牌子要站的格子(工程旁的地面上)。
  • 「預覽修好」打勾可以看修好後的樣子; 試玩時也會照這裡的勾選決定哪些工程已修好。

檢查

  • 每次修改後自動檢查, 點一則問題, 畫面上會用紅框標出位置。
  • 可走範圍是照遊戲的跳躍物理(最高約 2 格、不用技能、用最慢的炸彈工速度)模擬的; 勾「可走範圍」可以看到綠色 = 走得到的地方。
  • 會檢查: 少起點終點、東西卡在牆裡、地面怪腳下沒地、終點走不到(每種修復組合)、掉進去就爬不出來的地方、迷霧區修好前就進得去、修好後反而擋路、素材 / 寶箱拿不到、巢穴門與巢母的設定。

存檔與試玩

  • 存檔: 第一次會跳出存檔視窗, 請找到 polish\game\game\levels.js 選它並覆蓋; 之後按存檔就直接寫回同一個檔(瀏覽器可能會再問一次權限, 按允許)。
  • 瀏覽器不支援直接存檔時, 會改成下載 levels.js, 請把下載的檔案搬到 polish\game\game\ 取代舊檔。
  • 還沒存檔的修改會自動暫存在瀏覽器裡; 下次打開若發現沒存的草稿, 上方會問要不要載入。
  • 試玩這關: 先存檔, 再開新分頁直接進這一關(可選職業)。改了關卡之後要重新按一次試玩(或重新整理遊戲分頁)。
