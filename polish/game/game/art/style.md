# 連環工程 美術規格(polish 第 2 輪)

本輪沿用上一版的色票、形狀語言與所有世界物件畫法; 只改規格變動牽涉的物件: 大地圖背景(營地 + 河 + 橋)、關卡卡片(修復灰幕 + 裝置格)、升級所卡 / 商店卡、裝置圖示(嵌牆圓盤機關)、裝置倉庫(取代背包)、準備頁(拿掉商店列)、升級所(解鎖職業 + 特效)、結算(對決外框發光)、新增死亡碎裂與過關光圈、終點旗與角色的過關慶祝、暫停面板(拿掉下載紀錄)、教學階段 6 完成特效。

RD 只需讀這份。`index.html` 必須宣告 `<meta charset="utf-8">`(art.js 內有中文字串)。以 `<script src="game/art/art.js">` 載入, 取用全域 `window.Art`, 不用 ES module。函式名與 state 欄位與 `interface.json` 一一對應, 一個不多一個不少。

## 1. 邏輯畫布

- `Art.canvas = { width: 1280, height: 720 }`(= interface.json 的 canvas; 上一版沒有依裝置加寬, 本版照舊匯出固定寬)
- 美術一律照 1280×720 設計座標畫, 不自己乘縮放。高 DPI 由 RD 呼叫前整體 `ctx.scale(dpr)`; 美術判斷「是否被縮小」時已扣掉底圖倍率(`canvas.width / 1280`)
- 額外匯出(非繪圖函式, RD 不必接): `Art.palette`、`Art.themes`、`Art.icons.mat / item / cls / key`(字典級小圖示, 之後若有說明頁或方案頁要重用就呼叫這裡, 不要另抄)

## 3. 形狀語言

一句話: **世界物件扁平幾何、怪物圓潤 Q 版無黑描邊(上亮下暗 + 白眼紅瞳)、玩家幾何剪影白描邊; 介面是釘角釘的深色木板 + 羊皮紙牌 + 有厚度的石鍵帽; 地形整塊連成一片、只在外露邊描深邊, 外角依主題 圓(翠林)/ 尖(高崖)/ 方(礦坑); 裝置一律是「方石座 + 色環 + 中心大符號」的嵌牆圓盤。**

## 4. 理念落實

- **P0 辨識度先於好看**: 三種擋路物 裂岩牆(暖色平板 + 裂痕)/ 亂石(冷色圓石堆、無裂痕)/ 封印石門(厚框 + 紫爪痕)用「材質 + 顏色」兩通道分出誰打得破; 三職業縮到 1/8 只剩盾形 / 三角 / 圓; 八種裝置縮到卡片裝置格的 17px 時拿掉鉚釘與細節, 只剩「色環 + 中心符號」。
- **P1 視覺權重跟著決策迫切度走**: 背景與地圖紙紋最低調(營地石板紋、河波紋都是極淡的線); 最亮的是危險投影(紅)、破綻(黃)與教學箭頭(金); 素材飛行投幣時只讓那一格資訊列壓扁、噴火花; 結算時「這一趟」(按 Z 會採用的)是全面板唯一有金色外光的欄, 「目前回放」只有淡虛線框。
- **P2 規則上存在的東西畫面上必須存在**: 未修的斷橋 / 崩梯每一格畫角色色施工藍圖; 盾兵的盾值接在血條前段; 花費逐項比對, 只有不足的那一種變紅 + 「缺 N」; 卡片縮圖上每處工程的區域都框出來(未修虛線 / 已修實線), 修好幾處一眼看得出; 卡片裝置格空著也畫空格(虛線 + 「+」), 看得出「這裡還能裝」; 倉庫清單每種標 ×N 座數; 冷卻環每 1 秒一刻。
- **P3 一個意義一種長相**: 四種素材全部呼叫同一個 `matIcon`, 聚X機關的中心符號也是它; 裝置在卡片格、準備頁、倉庫、商店、獲得提示、結算、商店卡招牌全部呼叫同一個 `itemIcon`; 號碼釘在工程牌與準備頁工程卡同款; 巢穴記號一律「發光紫紋」; 黃 = 破綻、紅 = 敵方預備、金 = 介面選中 / 可按 / 會被採用; 營地兩張建築卡的「!」與大標籤共用同一支小工具。
- **P4 關鍵區分至少兩條通道**: 我方 vs 敵方 = 白描邊幾何 vs 無描邊圓潤 + 紅瞳; 一般怪 vs 巢穴怪 = 紅瞳 vs 紫瞳 + 背上發光紫紋; 卡片修好 vs 沒修 = 原色 vs 灰階 + 實線框 vs 虛線框; 這一趟 vs 目前回放 = 金外光 + 吊牌 + 亮底 vs 虛線框 + 淡底 + 淡字; 職業已解鎖 vs 未解鎖 = 彩色 + 綠章 vs 灰色剪影 + 鎖; 全解鎖 vs 已售完 = 羊皮紙金邊 vs 灰紅底深字。
- **P7 每個元素都要掙得它的版面**: 資訊列素材格只剩圖示、持有數、每分鐘產量; 卡片拿掉「工程 N/3」字, 改由縮圖本身與木框彩度表達; 商店卡 / 升級所卡只放簡單圖示與名牌, 不列價格、剩餘、等級; 死亡與過關動畫沒有任何文字。
- **P9 以最混亂的那一刻驗收**: 縮圖倍率(<0.2)一律改畫剪影色塊; 自測對世界物件以 1 / 0.5 / 0.125 三種倍率跑過; 解鎖特效以「角色跳到最高、放射光最大」那一幀驗頭頂 ≥ y 64; 死亡碎片以「命中點在各方向 + 掉出畫面」驗不超過 160px。
- **P13 事件要排隊**: 「獲得 裝置」提示固定一塊、淡入淡出, 由 RD 依序傳; 教學一次只畫一個階段; 解鎖特效畫在職業卡上、教學完成特效畫在橫幅上, 位置不重疊。
- **P15 回饋強度與份量成正比**: 擊倒煙 小 48 / 巢母 96 / 巨像 320; 巢心機關的圖示與提示框是紫色外光; 過關(光圈收合 1.4 秒)與死亡(碎裂 1.3 秒)是全遊戲最大的兩個演出, 解鎖職業(光柱 + 躍出)次之, 教學完成(打勾章 + 6 星)最小。
- **P17 進度類圖形與數字分工**: 技能冷卻只用腳下地面環(不寫秒數); 巨像血條刻度不另寫數字; 工程修復進度只用縮圖上色(不再寫 N/3)。
- **P18 重要資訊不能只存在一瞬間**: 「獲得 裝置」閃過後, 結算面板再列一次; 「新區域」標記常駐卡片角落直到重跑; 裝置裝上後常駐在卡片裝置格。
- **P19 資訊貼著物件**: 冷卻環在角色腳下; 號碼釘在工程牌頂; 花費畫在卡片自己的縮圖區; 裝置格貼在卡片右下(就在它加成的那關上); 結算的勝負箭頭在兩欄之間的脊上, 指向較好的那一格。
- **P21 示意圖要選對錯理解會分岔的例子**: 本輪沒有說明頁(嵌入式教學), 不適用。

## 5. 判讀約定(RD 請照這些傳值)

1. **座標**: 除註明「左上角」外, x, y 都是判定框中心。工程牌 / 寶箱 / 終點旗 / 巢穴門 / 刺藤花 / 巢母底邊貼地 = y + 高/2。
2. **布林只認 `true`**(`open` 的四邊、`repaired`(含 `regions[i].repaired`)、`end`、`bottom`、`hit`、`brood`、`reached`、`first`、`invuln`、`stealth`、`big`、`weak`、`lit`、`selected`、`newArea`、`anyAffordable`、`allDone`、`soldOut`、`owned`、`touch`); 例外: `drawSoundIcon.on` 與 `drawSiteHighlight.active` 只有 `=== false` 才算關、`drawShieldman.hasShield` 只有 `=== false` 才算盾已破。
3. **表外值的預設外觀**(看到這些代表傳錯值): 主題 → forest、工程 kind → rubble、角色 role → shortcut、素材 → wood、職業 → sword、pose → idle、怪物 state → 各自第一種、裝置 type → bagWood(聚木機關)、卡片 state → sealed、預備投影 kind → ring。卡片裝置格裡的表外值畫成空格; `drawDevicePanel.current` 表外值當成空格。
4. **閒置值**: 所有 `xxT / xxDur` 照介面「閒置時 xxT = xxDur」判讀; xxT < xxDur 才播。
5. **縮圖剪影門檻**: 函式讀 `ctx.getTransform()` 的縮放(扣底圖倍率), 小於 0.2 改畫剪影; 準備頁預覽 0.5 畫細節版。假 ctx 沒有 `getTransform` 時當成 1。縮圖中的**主角記號**刻意畫成畫面上約 9px(會大於判定框), 否則只剩 3px 看不出職業。
6. **工程牌號碼**: 0.5 倍預覽下號碼自動放大到畫面上至少 10px, 號碼釘會比 36×48 框頂多出至多 12 單位(只在預覽發生)。
7. **施工動畫時間軸**: 介面寫「buildT/buildDur ≥ order×0.7 後開始自己的 0.3 秒」, 但 order = 1 時 0.42 + 0.3 = 0.72 > 0.6, 會在 buildT 到 buildDur 時還沒播完。美術採「每格施工長 = min(0.3, buildDur − 起點)」, 保證 buildT = buildDur 那一刻全部到位(最後鋪的格子施工較快); buildT 還沒到那格的起點時照未修畫(含藍圖)。
8. **落石蜥的血條**: 介面把血條固定在框上緣上方(top−13~top−8), 落石蜥倒掛時那裡是天花板岩頂。`drawHpBar` 的 y 是血條底邊, **建議 RD 對落石蜥改傳 y = 框下緣 + 13**(血條畫在身體下方開闊處); 照介面傳也能畫, 只是會壓在岩頂上。
9. **巨像拳頭超出 size**: 介面 `drawColossus` 外接框是 y 20~580, 但規格的巨拳卡在地面(地面 600、埋 10px)時拳中心約 y 560, 拳底到 610。美術照拳的判定 110×100 畫在 (x, y), 超出外接框屬規格位置使然; 換階段噴飛的肩甲在落地前淡出, 落地後**不留在場上**(避免被看成可站的地形)。
10. **教學階段 6**(本輪照介面改): 平常不呼叫; 在旗子上按 ↓ 後的 0.6 秒, RD 照介面傳 stage '6'、橫幅框 = 「按 ↓」泡泡的位置(200×48)、tip null, 美術照一般階段畫(羊皮紙橫幅 +「按 ↓ 完成關卡」+ ↓ 鍵帽, 轉金 + 右端打勾章 + 6 金星), 蓋在泡泡上。上一版「用 tip 傳泡泡中心」的用法已不支援。
11. **系統時鐘動畫**(state 沒給時間的): 玩家無敵閃爍 12Hz、寶箱閃光、終點旗飄動(非慶祝時)、蜂彈旋轉、準備頁框選脈動、結局 t 停在 14 之後的提示字呼吸。暫停時這幾個會繼續動, 屬預期。其餘動畫一律吃 state 的 t / xxT。
12. **全畫面暗幕**由面板函式自己畫: `drawLevelPanel`(在預覽框 (60,96,640,360) **挖空**, 預覽框內請 RD 自己鋪滿)、`drawDevicePanel`、`drawShopPanel`、`drawClassSelect`、`drawUpgradePage`、`drawPausePanel`、`drawDeathFx`(它本身就是暗幕 + 角色)。`drawResultPanel` 不畫暗幕(底 = `drawClearIris` t=dur 的全木板)、`drawFailPanel` 不畫暗幕(底 = `drawDeathFx` t=dur 的暗下世界)。
13. **字歸屬**: 每個面板 / 卡片 / 提示 / 資訊列內的字(含鍵帽)美術已畫; RD 只畫大地圖最下方 y=690~714 那行操作提示。美術額外畫的字: 失敗面板「這趟作廢, 素材不入帳」; 卡片「可解鎖 · Z」「前一關未過」「7 關全過才開放」; 準備頁紀錄區小標「目前回放」; 裝置倉庫標題列右側「目前裝著 <裝置名 / 空>」、空格選「拆下」時資訊牌第二行「選它 = 不變」; 職業卡「擅長: …」; 結算「目前回放」欄頂小字與脊上的列名「職業 / 通關時間 / 素材名」。死亡動畫、過關光圈沒有任何字。世界物件函式內唯一的字是工程牌號碼。

## 6. 繪製順序補充

照 interface notes 的順序即可。`drawSkillRing` 一次畫完整個環(沒有前後分層), 請在 `drawPlayer` 之前呼叫。`drawTutorial` 的箭頭會畫在橫幅外(依 tip), 請保持在 `drawHud` 之後、`drawSoundIcon` 之前。

- **死亡動畫**: 定格世界(不畫 drawPlayer / drawSkillRing / drawRangeRing / drawGoalPrompt / drawTutorial)→ `drawDeathFx` → `drawHud` →(1.3 秒後)`drawFailPanel` → `drawSoundIcon`。
- **過關動畫**: RD 放大畫定格世界(drawPlayer 用 'cheer'、drawGoal 用 cheerT)→ 還原變換 → `drawClearIris`(畫布座標)→ `drawHud` →(1.4 秒後)`drawResultPanel` → `drawSoundIcon`。
- **大地圖**: `drawMapBackground` → `drawMapLink` × 10 → 每張關卡卡片(`drawLevelCard` → 縮圖 → `drawCardOverlay`)→ `drawWorkshopCard`、`drawShopCard` → `drawFlyingMaterial` → `drawHud` → `drawTutorial` → 面板(`drawShopPanel` / `drawUpgradePage` / `drawLevelPanel` …)→ `drawSoundIcon`。營地兩張卡沒有上層函式, 選取框由卡片本身畫。
