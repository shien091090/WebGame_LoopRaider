## 概述
單畫面橫向平台動作 × 放置。8 個短關卡以樹狀連在大地圖上, 分三個主題(翠林谷地 / 風蝕高崖 / 地底礦坑)與一個最終 Boss 關。三職業(劍士衝刺 / 獵人自動射擊 + 潛行 / 炸彈工投彈 + 爆風擊退)各有擅長的地形; 10 種怪物依主題分布, 每打掉 1 HP 就噴 1 份素材。過關後該關在大地圖卡片裡不停重演整趟, 每得到素材就從縮圖彈出一顆素材投進資訊列。
每關有 3 處互不干涉的工程(斷橋 / 崩梯 / 堵塞隧道 / 巢穴門), 花石頭修好就開出新區域, 修越多越好跑、越好賺。第 3、5、7 關各有一處巢穴, 住著該主題的巢母, 首殺掉巢心機關。裝置裝在關卡的裝置格上, 對該關每一次回放生效; 裝置來自寶箱、巢母與大地圖上的商店。7 關全過後挑戰第 8 關的守門巨像, 打倒後播結局。
四種素材各一種專屬用途: **木材**開路(解鎖關卡、解鎖職業)、**石頭**修復工程、**水晶**在商店買裝置、**魔核**(只有怪物會掉)強化角色。

## 核心循環
大地圖看缺哪種素材 → (營地: 商店買裝置、升級所解鎖職業 / 強化)→ 選關卡 → 準備頁修復工程、裝裝置 → 開始挑戰、選職業 → 進關打怪(每下都噴素材)、撿素材、走新修好的路、開寶箱、打巢母、碰旗按 ↓ → 過關動畫 → 結算比較新舊兩趟, 決定留哪一趟 → 回大地圖看各關回放產出、素材投進資訊列、卡片隨修復越來越完整 → 用木材開新關 / 解鎖職業, 石頭修復工程, 水晶買裝置, 魔核強化 → 回到剛修好的關卡重新規劃路線再跑 → 7 關全過 → 挑戰守門巨像 → 結局。

## 新手教學
教學嵌在遊戲流程裡, 每個新操作在第一次需要的地方教。共用規則:
- 一次只顯示一個階段; 同時有兩個階段的出現條件成立時, 編號小的先, 另一個等前一個完成特效播完再出現。
- 提示 = 一條羊皮紙**橫幅**(文字 + 鍵帽, 位置依畫面固定, 見下)+ 一支會上下彈跳的**指示箭頭**(尖端貼著要操作的物件; 沒有物件可指時不畫)。由 `drawTutorial` 畫。

### 工程(互不干涉)
22. 每關(第 1~7 關)3 處工程, 編號 1、2、3(位置、結構與角色見「關卡」)。**一開始 3 處全部看得到、順序自由、互不影響**: 每處工程的入口都在主路上(或主路旁一步可達), 開出的區域只靠它自己就走得到。工程的**角色**: **捷徑**(修好後通往終點的路變短, 本身不放素材)、**藏寶處**(修好後開出一塊有素材、怪物、寶箱的繞路區域)、**巢穴**(只在第 3、5、7 關; 見規則 26)。
23. **戰爭迷霧**: 每處工程開出的區域(以 1~2 個矩形定義)在修好前蓋著迷霧——關卡內、縮圖、準備頁預覽都蓋。未修時那塊區域**有實體阻擋、進不去**(被斷橋缺口 / 碎石台階 / 亂石 / 巢穴門擋住; 迷霧矩形邊上不得有能跳進去的開口)。工程結構與工程牌不在迷霧裡、永遠看得到。
    - 未修的結構外圍畫**施工藍圖**: 修好後會變成實心的格子畫成工程角色色的虛線輪廓(捷徑 / 藏寶處 / 巢穴各一色)。
    - 修好時: 結構先**施工** 0.6 秒(崩梯石階一欄欄落下 / 斷橋木板由兩端往中間鋪 / 亂石炸開 / 巢穴門封印石板沉入地面), 接著迷霧**從工程結構中心畫圓往外推開** 0.8 秒(圓的半徑由 0 長到蓋滿該區所有矩形, 圓邊是一圈亮霧), 圓圈掃過的素材、寶箱、怪物依序彈出一下。準備頁預覽上同樣播放。
24. 四種結構:
    - **斷橋**: 未修 = 一段 8~12 格寬的缺口(下方是尖刺或深淵), 只剩兩端殘樁, 不是實心; 任何職業(含劍士跳起 + 衝刺, 最遠約 6 格)都跨不過。修好 = 整排實心橋面。
    - **崩梯**: 未修 = 地上一堆碎石(不是實心、可穿過), 上方平台離下方地面 7 格以上, 任何職業都上不去。修好 = 一段每階 2 格高的實心階梯。
    - **堵塞隧道**: 未修 = 隧道口塞滿亂石(實心、打不壞也炸不壞, 外觀和裂岩牆一眼分得出)。修好 = 亂石消失。
    - **巢穴門**: 未修 = 一扇 2 格寬 × 2 格高的封印石門(實心、打不壞, 看得出門後是魔物巢穴)。修好 = 石門沉入地面, 只剩門框。

### 結算
- 過關動畫(規則 2)播完, 結算面板疊在全木板上出現(固定左上 (280, 150)、720×420)。

- 已有回放 → 照 result-panel B「對決外框發光」: **兩欄同大、左右對稱**——左欄「這一趟」、右欄「目前回放」, 列名放在兩欄中間的**脊**上。列由上到下: 職業、通關時間、木材 / 石頭 / 水晶 / 魔核 各一列(每列兩邊寫「這趟得到數 · 每分鐘產量」, 每分鐘產量兩邊都用目前的裝置配置計算)。
    - 「這一趟」整欄**金色外光** + 頂端吊一張金色標籤「這一趟」(金 = 按 `Z` 會採用的那一趟); 「目前回放」只有淡色虛線框、字色較淡。
    - 脊上每列(職業列除外)畫一個綠色箭頭指向較好的一邊: 通關時間短的較好、每分鐘產量高的較好; 一樣時畫灰色「=」。

    - 底部「Z 採用這一趟  X 保留舊的」; `Z` 採用這一趟(取代)、`X` 保留舊的, 之後回大地圖。

### 戰鬥
32. **掉落按傷害算**: 怪物(含巢穴怪、巢母、守門巨像)**每損失 1 HP 立即得到 1 份**該怪的素材(種類見「怪物數值」), 一擊打掉 N HP 就得 N 份(傷害超過剩餘血量時只算剩餘血量); **擊倒時另得魔核**(一般怪 1、巢穴怪 2、巢母 6 + 主題素材 4、巨像 10)。不論傷害來源(玩家攻擊、擊飛碰撞、甲蟲爆炸)都算; 唯一例外: 爆炸甲蟲**自爆**時自己剩下的血不掉、也不給擊倒魔核。打盾兵的盾也掉素材(每損失 1 盾值 = 1 石頭)。
    - 得到的瞬間就計入這趟所得與錄影; 畫面上同時從怪物身上**噴出**對應顆數的素材粒(拋物線彈出 → 落地彈一下 → 0.6 秒後被吸回玩家, 吸到時冒「+N」浮字, 同種 0.2 秒內合併成一個浮字), 素材粒只是表現。
    - 一擊造成 2 以上傷害時畫面震一下(0.12 秒, ±3px)。
33. 玩家血量 3(升級後 4 / 5 / 6); 碰到怪物本體(被擊飛中的除外)或敵方飛行物、預備後的攻擊判定扣 1, 之後無敵 1 秒並被往反方向彈開 80px(岩角羊頂撞例外, 見數值)。每次進關回滿。
34. **尖刺**: 碰到扣 1 血(不即死), 之後無敵 1 秒並被往上彈起(向上 520px/秒, 水平速度歸 0)。無敵中再碰尖刺不扣血。兩根刺中間一格寬的窄落腳點可以保留。潛行不防尖刺。
35. **怪物**: 10 種一般怪依主題分布(行為與數值見「怪物數值」), 全部有血量、頭上常駐血條(長度跟最大血量成正比; 盾兵的盾值接在血條前段、另一色)。出手前都有看得見的預備動作, 並**投影在地上**(衝撞道、瞄準線、俯衝軌跡、落石柱、爆炸圈、藤鞭掃區)。被擊倒時冒擊倒煙, **立即消失並停止一切行動**——包括瞄準中的那一發、預備中的那一招、已點燃的甲蟲引信都取消(唯一例外是已經射出 / 丟出的飛行物照常飛完)。**血條跟著消失**: 怪物(含巢母)被擊倒那一幀起不再呼叫 `drawHpBar`; 守門巨像血量歸 0 那一幀起(崩解演出期間也算)不再呼叫 `drawBossHpBar`——不得留下空的或全黑的血條(polish 第 1 輪 bug)。回放重演時同樣照錄影: 擊倒之後的幀不畫血條。
    - **盾值段跟著盾的方向**(polish 第 2 輪 bug, 使用者已先修): 盾兵的盾值段畫在盾牌那一側——盾兵面向右時 RD 傳 `drawHpBar` 的 `shieldSide = 1`(盾值段在右), 面向左傳 −1(在左, 預設); 其他怪沒有盾, 傳 −1。
35a. **預告與攻擊都被地形擋住**(polish 第 2 輪 bug): 所有怪物的預告投影只畫到攻擊**實際打得到**的範圍, 由 RD 算好端點再傳給 `drawTelegraph`(美術照給的端點畫, 不自行延伸):
    - 地面衝撞道(野豬、岩角羊、翠林巢母): 從怪物前緣往前, 終點取「預備開始時算出的最遠距離」「前方第一面牆(和怪物身體同高的實心格)」「腳下平台邊緣(前方下一格沒有地面)」三者最近的一個; 實際衝撞也照同一條規則停下(撞牆或到平台邊緣就停), 預告長度 = 實際衝撞會走的距離。
    - 瞄準線(射手蜂)、俯衝軌跡(俯衝鷹)、石彈軌跡(高崖巢母): 沿線碰到第一個實心格就截斷(蜂彈、俯衝、石彈本來就碰地形停下, 預告與實際一致)。
    - 落石柱、巨拳落柱、碎岩落點: 從上往下到第一個實心頂面為止(現行)。
    - 藤鞭掃區(刺藤花): 前方 140×40, 碰到牆那一側截在牆面; 實際判定同樣截斷。
    - 光束路線(巨像): 每個 x 打到該 x 的第一個實心頂面(現行)。
    - **爆炸圈**(爆炸甲蟲 70、炸彈 60、巨像無): 判定改成被牆擋住——爆心到目標判定框中心的連線穿過實心格(不含裂岩牆本身被炸的那格)就不受傷; 預告圈與爆炸特效由 RD 在呼叫前設 `ctx.clip`(畫面矩形扣掉所有實心格, evenodd), 牆裡面不畫出紅圈 / 火光。
    - 落點圈(跳蛙)、裂縫(礦坑巢母): 畫在落點的地面頂面上, 不跨進牆裡(同樣以 RD 的 clip 保護)。

## 最終 Boss「守門巨像」(第 8 關)
- 懸在斷門缺口正上方、左右對稱的砂岩古代機關(final-boss 方案 B): 一顆頭(中心平時在 (640, 230), 判定 200×160)、兩隻分離的巨拳(平時在 (420, 300) 與 (860, 300), 每隻判定 110×100)。動作一格一格喀喀移動再精準停頓。敵我通道: 符文與眼睛一律紅, 只有破綻時轉黃。
- **血 45**, 三階段: 第 1 階段 45~31、第 2 階段 30~16、第 3 階段 15~1(血量降到 30 / 15 時換階段)。頭上長血條(寬 360, 兩道白粗刻度標出換階段門檻), 破綻時轉黃。
- **只有破綻期間打得動**: 平時頭與拳都打不動(攻擊打上去「叮」一聲、閃灰, 不扣血也不掉素材, 炸彈照常爆炸); 破綻(持續 **3.0 秒**)中打在發黃光的部位上照常扣血(不加倍)。碰到巨像的頭與拳**本體不傷人**, 只有招式判定傷人(每次扣 1)。
- 掉落: 每損失 1 HP 依序輪流給 木材 → 石頭 → 水晶 → 魔核(第 1 下木材, 第 2 下石頭……); 擊倒另得魔核 10。
- **招式**(每招都有看得見的預備動作, 投影在地上):

- `Esc`: 關卡內、大地圖、關卡準備頁(含裝置倉庫、職業選擇)、商店面板、升級所都能暫停 / 繼續; 暫停時遊戲、回放、教學計時全部停止, 音樂壓低一半音量。開始畫面、結局、死亡動畫(1.3 秒)、過關動畫(1.4 秒)期間不能暫停(`Esc` 無作用)。暫停面板只有「繼續」(大地圖與各面板)或「繼續 / 重來 / 回大地圖」(關卡內), **沒有下載遊玩紀錄**。

## 回歸自測
上一輪(polish 第 3 輪)與更早各輪回報的 bug 中本款仍有對應機制的, RD 收工前逐條跑過, 回報列出每條結果(第 3、4 條的地形以 levels.js 為準, 發現問題只回報、不改關卡; 第 4 條另用劍士、獵人的高跳再測一次, 見第 15 條):
1. **射手蜂擊倒後仍射擊**(deepen-2 回報、deepen-3 重寫後再犯, bugs-game-a-1.md): 讓射手蜂進入瞄準(點線出現)後把它擊倒 → 之後 3 秒內場上不得出現新的蜂彈; 存成回放後在縮圖回放裡同樣不得出現。
2. 同一原則擴到所有會預備的怪(規則 35): 分別在 落石蜥預備落石柱、俯衝鷹盤旋預備、刺藤花拉鞭、爆炸甲蟲閃爍、岩角羊 / 野豬預備、三種巢母預備 時把它擊倒 → 那一招不得發生(沒有落石、俯衝、鞭掃、爆炸、衝撞、石彈、竄出); 擊倒守門巨像後不得再出現光束、碎岩或巨拳。
3. **新區域入口容不下角色**(deepen-2 C 回報): 用 28×36 判定框走過每一關每一條通道、門口、修好後的工程入口與巢穴門框 → 全部進得去、出得來, 不會卡住。
4. **掉進迷霧區爬不回來**(deepen-3 C 回報): 每關在 3 處工程都未修時, 沿每塊迷霧矩形的邊跳躍 / 衝刺 / 擊退嘗試進入 → 都進不去; 每個掉得進去的坑都能自己爬回主路。
5. **盾兵打不死**(deepen-3 回報): 只用劍士、只用獵人各打一隻盾兵 → 都能打破盾(3 下)再擊倒本體。
6. **獵人按 Z 還會射箭**(deepen-3 回報): 用獵人按 `Z` → 沒有任何箭射出、沒有動作。
7. **碰到旗子就結算**(deepen-3 回報): 走進終點旗 → 只出現「按 ↓ 完成關卡」, 不結算; 走開提示消失; 回到旗子按 `↓` 才結算。
8. **巢穴無限湧怪**(deepen-3 回報): 修好第 3 關巢穴後進關, 清光巢穴裡的巢母與 3 隻巢穴怪, 在巢穴裡停留 20 秒 → 不得出現任何新怪。
9. **工程只能照順序修**(deepen-3 回報): 新開局進第 1 關準備頁, 先修復工程 3 → 可以修, 工程 1、2 仍可修, 三處修好的順序不影響彼此的區域。
10. **空白鍵跳躍**(deepen-2 回報): 關卡內按空白鍵 → 不跳、沒有任何作用。
