底版: deepen-3/game-a

## title — 開始畫面
類型: 動態
內容: 進遊戲第一個畫面。以主視覺呈現的大而顯眼小動畫, 不演玩法: 要傳達「一張由小關卡串成的冒險地圖, 打過的關會一直自己重演、源源不絕產出素材」的感覺(中央主體是一棟倉庫建築物, 不放角色; 素材在畫面裡流動進倉庫等, 不放遊戲名稱或任何標題文字)。動畫為循環播放, 一圈約 3~5 秒。底下一行「按任意按鍵開始遊戲」。
為什麼是核心: 玩家第一眼看到的畫面, 決定整款遊戲的第一印象與氣氛

## hero — 主角(三職業)
類型: 靜態
內容: 玩家操作的三個職業, 關卡內是主角, 大地圖縮圖裡回放時也一直看得到。劍士(近戰揮砍 + 衝刺斬, 開局唯一可用)、獵人(只會自動射箭, 技能是潛行)、炸彈工(拋炸彈 + 震波把怪擊飛)。三人**判定框一律 1 格高(約 28×40, 同高同寬)**, 只靠外型、配色、手持武器分辨, 不能用體型高矮區分。要表達三人個性與戰鬥方式完全不同, 且在大地圖縮小到約 1/8 時仍認得出是哪個職業。
為什麼是核心: 玩家整場都在看、都在操作的角色; 選職業 = 選路線與產出, 職業要一眼記得住才有「派誰去跑這關」的策略感

## ui — 介面風格(HUD、面板、按鈕、字)
類型: 靜態
內容: 頂端資訊列(四種素材持有數與每分鐘產量, 不標用途文字; 關卡內加上血量、計時; 不顯示這趟所得區塊)、大地圖的關卡卡片(封鎖 / 可解鎖 / 已開放 / 已過關, 已過關卡片內嵌回放縮圖與產量)、關卡面板(選職業、修工程、道具格、加速器)、背包面板(點道具格時另外打開)、升級所頁面、結算面板(新舊兩趟並排比較)、暫停 / 失敗面板、終點旗旁的「按 ↓ 完成關卡」提示、按鍵鍵帽、聲音開關圖示(右上角, 跟 `M` 鍵同步)。全部只用鍵盤操作, 選中狀態要很清楚。要表達的是一套統一的介面語言: 數字多但好讀、選中與「錢不夠」一眼看得出。
為什麼是核心: 這款一半時間在大地圖與面板裡做規劃決定, 介面就是玩法本身的一半

## materials — 四種素材
類型: 靜態
內容: 木材(開路、解鎖關卡與招募)、石頭(修工程)、水晶(回放加速器)、魔核(只有怪物會掉, 強化角色)。同一組圖示出現在關卡地上可撿的素材、打怪掉出的素材、大地圖飛行素材、資訊列、卡片產量、面板花費、結算, 全遊戲一個長相。要表達「每種素材各有專屬用途」, 四種之間形狀與顏色都分得開, 縮小到 18px 仍認得出。
為什麼是核心: 整個遊戲的循環就是在賺這四種東西、規劃缺哪種; 玩家視線最常停留的圖示

## monsters — 怪物設計(依主題分組)與血條
類型: 靜態
內容: 每個主題有自己的怪物陣容(主題見 themes), 共 10 種一般怪 + 每主題一種巢母(Boss), 全部有血量、會主動移動, **頭上常駐血條**。要表達每種怪行為不同、要換不同打法; 預備動作(蓄力、瞄準、俯衝前的盤旋、自爆前的閃爍)要讓玩家看得到再反應; 同主題的怪配色與畫風呼應該主題。
- 翠林谷地: **野豬**(巡邏, 發現玩家後蓄力衝撞)、**跳蛙**(不停跳向玩家)、**射手蜂**(巡飛, 停下瞄準後射彈)、**刺藤花**(扎根不動, 玩家靠近時伸藤鞭橫掃前方)
- 風蝕高崖: **岩角羊**(低頭頂撞, 把玩家撞退一大段、可能撞下平台)、**俯衝鷹**(在高處盤旋, 鎖定後斜線俯衝再飛回)、**落石蜥**(趴在牆面或天花板, 朝下方丟石塊)
- 地底礦坑: **盾兵**(正面舉盾擋攻擊, 盾可被打壞, 打壞後露出本體; 有盾 / 盾已破兩種外觀要明顯不同)、**爆炸甲蟲**(爬向玩家, 貼近後閃爍再自爆; 可被擊飛去炸別的怪)、**蝙蝠群**(3 隻一群繞圈飛, 一隻一隻打)
- 巢穴怪(部分關卡的巢穴內)需與一般怪分得出; 三種巢母各對應一個主題, 體型大、血條長
為什麼是核心: 打怪是「多賺 vs 跑快」取捨的一半, 怪物是關卡裡最主要的互動對象; 主題換怪讓每個主題的戰鬥手感不同

## combat-fx — 攻擊、技能與打怪掉落
類型: 動態
內容: 關卡內每一下戰鬥的手感。包含三職業的攻擊與技能特效: 劍士揮砍(每下約 0.15 秒)與衝刺斬(約 0.2 秒的突進)、獵人自動射箭(每 0.6 秒一發)與潛行(進入、持續中、解除; 持續期間要明顯看得出無敵可穿怪)、炸彈工的炸彈爆炸(約 0.4 秒)與震波擊飛(約 0.4 秒, 怪被撞成一串時冒「N 連鎖」)。以及命中回饋: 怪物每被打掉 1 HP 就噴出 1 份素材(一擊打掉 N HP 就噴 N 份), 血條同步減少, 盾被打壞的瞬間、怪物倒下的擊倒煙(約 0.5 秒)。要表達「每打一下都有收穫」, 攻擊力越高、噴越多的爽快感。
為什麼是核心: 「怪物每損失 1 HP 掉 1 份素材」是本輪使用者明確要的打怪划算感, 戰鬥與掉落要合成同一個爽快瞬間

## replay-map — 大地圖回放與素材飛行
類型: 動態
內容: 大地圖上每張已過關的關卡卡片, 縮圖裡不斷循環重演玩家那一趟(角色、怪物、擊倒都還原)。每當回放播到拿素材的瞬間(撿到、打怪掉落、通關獎勵), 就從縮圖裡該位置飛出一顆素材, 沿弧線約 0.7 秒飛進頂端資訊列, 飛到時持有數跳一下。過關越多、同時飛的素材越多。另有加速器等級、「新區域」標記等卡片角落標示。要表達「打一次、一直賺」與「越賺越快」, 畫面越後期越熱鬧但不雜亂。
為什麼是核心: 本作最獨特的機制(平台動作 × 放置), 使用者已確認「一堆素材飛行特效的感覺很不錯」, 是玩家停留最久的畫面

## repair-fog — 工程修復與迷霧散開
類型: 動態
內容: 每關有 3 處互不干涉、可自由順序修的工程(斷橋、崩梯、堵塞隧道、巢穴門)。未修時是斷掉 / 塞住的結構, 後方要開出的區域蓋著戰爭迷霧(迷霧下的區域有實體阻擋、進不去), 旁邊立工程牌標出這處是捷徑、寶區還是巢穴。在關卡面板花石料修好的瞬間: 結構變成完整的橋 / 階梯 / 打通的隧道 / 打開的巢穴門, 同時該區迷霧約 0.8 秒散開, 露出裡面的素材、寶箱、怪物。關卡畫面、面板預覽、大地圖縮圖都看得到修復狀態與迷霧。要表達「關卡變大了、有新東西可拿」的開拓感, 以及未修 / 已修一眼分得出。
為什麼是核心: 熟關後重新挑戰的主要動機(修好想回去重跑), 是石料唯一的用途, 也是關卡長相隨進度改變的地方

## themes — 關卡主題
類型: 靜態
內容: 8 關分成 3 個主題, 每個主題 2~3 關, 主題決定背景、地形磚、平台與裝飾、配色與出現的怪物(見 monsters):
- **翠林谷地**(第 1、2、3 關): 起點的森林與谷地, 木棧道、藤蔓、樹根平台, 明亮溫暖
- **風蝕高崖**(第 4、5、8 關): 高台與寬坑的崖壁、吊橋、風蝕岩柱, 天空開闊、偏冷色
- **地底礦坑**(第 6、7 關): 礦道、礦車軌道、木支架、裂岩牆與晶礦, 暗色中有礦燈與晶光
同主題內每關的地形配置各不相同(不是同一張圖換怪), 主題之間在縮成大地圖縮圖時也要一眼分得出。工程結構(斷橋、崩梯、堵塞隧道、巢穴門)與迷霧也要配合各主題的材質。
為什麼是核心: 使用者要求打磨版關卡重新設計、分主題且各關地形有差異; 主題是關卡畫面的主體, 也是大地圖上分辨各關的依據

## stage-panel — 關卡準備頁
類型: 靜態
內容: 從大地圖選某關進去後的準備頁: 關卡預覽(含修復狀態與迷霧)、選職業、修工程(3 處, 花石頭)、道具格(點了另開背包)、加速器、最佳紀錄 / 產量、開始挑戰。三個方案要是**版面結構完全不同**的設計(例: 左預覽右選單 / 預覽全螢幕疊面板 / 分頁步驟式), 不只是換配色。介面風格沿用已選的 ui 方案 A(options/ui-A.js)、素材圖示沿用 materials 方案 C(options/materials-C.js)。全部只用鍵盤操作, 選中狀態要清楚。
為什麼是核心: 每次出關前都在這裡做規劃決定(派誰、修哪、帶什麼), 使用者對現行版面不滿意

## skill-cd — 技能冷卻顯示
類型: 動態
內容: 關卡進行中技能冷卻與「可用」提示。現行放在頂端資訊列太不明顯、看不出冷卻好了沒。三個方案要放在**不同位置 / 不同表現**(例: 角色頭頂或腳下的環形計量、畫面下方大圖示加倒數、角色身上發光 + 冷卻完成時的閃光提示), 動畫要演出「施放 → 冷卻中倒數 → 冷卻完成」一整圈。三職業技能: 劍士衝刺斬、獵人潛行(冷卻較長)、炸彈工震波。介面風格沿用 ui 方案 A、角色沿用 hero 方案 A(options/hero-A.js)。
為什麼是核心: 技能是路線與打法的關鍵, 冷卻好沒好一眼要看得出來
