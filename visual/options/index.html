死亡動畫（death-anim，動態）

death-anim 方案 A

方案說明肢體喜劇式的「被打飛」: 命中定格一下 → 往後彈飛轉成仰躺、落地揚塵彈一下 → 胸口升起一團帶職業記號的白色魂火, 畫面四角慢慢暗下。

death-anim 方案 B

方案說明戲劇式的「定格碎裂」: 命中瞬間世界整片暗下只剩角色亮著 → 角色定格發抖、白色裂痕從命中處爬滿全身 → 碎成職業形狀的碎片(劍士方塊 / 獵人三角 / 炸彈工圓塊)飛散落地淡去。

death-anim 方案 C

方案說明呼應「這趟作廢」的「錄影訊號中斷」: 世界褪成灰階加掃描線, 這趟撿的素材碎成灰粒 → 只剩角色有顏色、像壞掉的訊號一樣錯位抖動 → 壓扁成一條白線、縮成一點熄滅。

過關動畫（clear-anim，動態）

clear-anim 方案 A

方案說明升旗歡呼——鏡頭不動, 只在旗子原地演: 旗桿伸高、綠旗爬到頂後放大並蓋下白勾, 金星往上噴, 角色連跳兩下舉劍, 收束感來自角色與旗子本身(約 1.3 秒)。

clear-anim 方案 B

方案說明素材匯聚爆開——這趟撿到的素材從角色身上彈出、繞圈匯成旗上的四色光球, 爆開後一顆顆飛進資訊列讓持有數往上跳, 直接演出「過關這一刻素材才入帳」(約 1.4 秒)。

clear-anim 方案 C

方案說明光圈收合——世界定格、鏡頭朝角色與旗子推近, 介面木板做成的金邊光圈收到只框住角色, 停一下再收成一點, 畫面整片變成木板接結算面板; 資訊列全程不動(約 1.4 秒)。

結算面板（result-panel，靜態）

result-panel 方案 A

方案說明亮底大字——「這一趟」是寬欄亮羊皮紙、數字放大到 30px 以上, 「目前回放」縮成窄欄嵌在暗木凹槽裡、小字淡色, 靠明暗與字級分主從, 一眼先看到這一趟。

result-panel 方案 B

方案說明對決外框發光——兩欄同大、左右對稱, 列名放在中間的脊上, 「這一趟」整欄金色外光加頂端吊牌標籤(金 = 按 Z 會採用的那一趟), 「目前回放」只有淡色虛線框, 脊上綠箭頭逐列指向較好的一邊。

result-panel 方案 C

方案說明卡片浮起——「這一趟」是一張微斜、帶厚陰影、蓋在舊卡上的新卡, 每列直接附「多 / 少 / 快幾秒」差值章; 「目前回放」是平貼在木板裡褪色的舊卡, 只列數值。

解鎖職業特效（unlock-fx，動態）

unlock-fx 方案 A

方案說明開鎖翻牌蓋章——特效只在職業卡上: 鎖越抖越兇, 喀一聲彈開飛出, 整張卡翻到綠色正面, 角色彈一下, 「已解鎖」章從大砸下並噴金星, 節奏是一拍一拍的手感。

unlock-fx 方案 B

方案說明光柱召喚角色躍出——金色光柱打在灰色剪影上, 顏色從腳灌到頭, 角色放大跳出卡片歡呼(背後職業色放射光 + 金星), 再落回卡上, 焦點全在角色本身。

unlock-fx 方案 C

方案說明素材換獎勵 + 全面板彩帶——花費的木材一根根跳進鎖裡(數字 30 倒數到 0), 鎖充飽後炸碎, 職業色衝擊環掃過整列, 彩帶灑滿升級所, 演出從卡片擴散到整個畫面。

大地圖關卡卡片(修復外觀與裝置格)（map-card，靜態）

map-card 方案 A

方案說明卡片木框本身殘破——沒修時邊框真的缺三塊(看得到地圖底)、裂痕伸進縮圖, 每修好一處就用一塊淺色新木板加亮釘補回一塊, 數補丁就知道修了幾處。

map-card 方案 B

方案說明縮圖像褪色舊照片——沒修時整張縮圖去色蓋灰、每處工程區域畫虛線框, 修好哪一處那塊區域就恢復原色(木框彩度也跟著回來), 3 處全修灰幕整片拿掉。

map-card 方案 C

方案說明卡片就是一間小工坊——0 處只有木樑骨架加腳手架, 修 1 處釘上牆板、2 處蓋上屋頂、3 處掛彩旗點燈, 用「蓋到第幾層」表達進度。

裝置(原道具)與裝置倉庫（devices，靜態）

devices 方案 A

方案說明鐵製機台 — 每個裝置都鉚在同一款鐵底座上, 上面是一台工業機器(圓鋸、料斗、鑽塔、吊臂、警笛、齒輪), 用素材色條標出它產出什麼; 名稱是直白的機器名: 伐木機、碎石機、鑽晶機、魔核燈柱、拾荒吊臂、誘獸警笛、巢母心爐、加速齒輪機; 倉庫是方格陣列, 同種疊成一格並標「×N」。

devices 方案 B

方案說明村落小建築 — 每個裝置是蓋在關卡地上的一座小木屋、棚或塔, 靠整體輪廓區分(矮屋 + 原木堆、斜頂棚、玻璃圓頂、亭子、條紋攤、瞭望塔、石階祭壇、水車); 名稱是地點名: 木料小屋、採石棚、晶簇溫室、魂燈亭、拾荒攤、號角塔、巢母祭壇、水車坊; 倉庫是木貨架, 一座座擺在架上、底下吊名牌。

devices 方案 C

方案說明嵌牆圓盤機關 — 每個裝置是一塊嵌在牆上的方石座圓盤, 外環顏色分種類(四種素材色 / 金 / 橘 / 紫 / 銅齒環), 中心放一個大符號, 縮到很小也只剩「色環 + 符號」一眼可讀; 名稱一律「X X 機關」: 聚木、聚石、聚晶、聚核、拾遺、驅獸、巢心、疾時機關; 倉庫是左邊清單、右邊大圖預覽。

大地圖版面(升級所與商店區)（map-layout，靜態）

map-layout 方案 A

方案說明木板側欄 — 左側一整條實心木板(介面材質)用直線硬邊加角釘壓在地圖紙上, 上升級所、下商店, 內容直接列成清單, 游標進清單就能解鎖職業、強化、買裝置, 不再開彈窗。

map-layout 方案 B

方案說明河對岸的營地 — 左側是地圖世界裡的一塊暖色石板營地, 用一條河和冷色關卡區分開、一座橋接第 1 關; 升級所與商店是兩張和關卡卡片同規格的建築卡, 選中按 Z 才開各自的頁面。

map-layout 方案 C

方案說明斜切工坊牆 + 展示架 — 左側是一面紫色工坊牆, 用銅條斜邊切開地圖; 升級所把三職業立在展台上(沒解鎖的半透明加鎖), 商店是 3×2 展示格一格一件裝置, 剩幾個、售完一眼看得到。
