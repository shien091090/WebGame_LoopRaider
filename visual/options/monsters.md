A: 圖鑑橫帶——延續現有「扁平 + 深描邊 + 紅眼」畫風(野豬 / 跳蛙 / 射手蜂直接沿用遊戲內畫法), 每種怪並排「平常 → 預備」兩態, 預備靠姿勢改變 + 紅眼發光表現; 血條每 1 HP 一格, 盾值用藍格接在血條前面。
B: 情境舞台——三主題各一欄小場景, 怪物放在真的地形上、玩家就站在旁邊, 每隻都停在要出手的那一刻, 預備動作直接畫在場地上(紅斜紋衝撞道、瞄準點線、俯衝軌跡、落石柱、爆炸圈); 造型圓潤 Q 版不描邊, 血條是圓角長條, 越耐打越長。
C: 行為字形矩陣——依打法排欄(正面推進 = 楔形、撲近 = 圓頂、空中 = 菱形、定點 = 直立 / 倒掛), 外形先告訴你要怎麼打, 主題只換材質色; 造型是多面體切面, 每隻身上一顆核心, 平常暗紅、要出手時燒成白黃放光; 血量用頭上一排血珠表示。
