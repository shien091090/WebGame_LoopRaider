A: 暖木工坊 — 面板是釘著角釘的深色木板, 資訊寫在米色羊皮紙牌上(深字好讀), 按鍵是有厚度的石鍵帽; 選中 = 金色粗框 + 整格浮起 + 頂端金色吊牌三角, 錢不夠 = 紅字 + 紅底「缺 N」小標、動作章變灰劃掉。
B: 工程藍圖 — 面板是切角深藍圖紙(細格線 + 雙線框), 數字全用等寬字像儀表讀數, 列有編號; 選中 = 整格反白成實心黃 + 外側角括號, 錢不夠 = 紅字寫成「花費/持有」(30/17) + 紅色斜線底、動作章變紅色虛線框「XX不足」。
C: 厚塊按鈕 — 淺色奶油面板、圓胖粗描邊, 每格都像一顆按得下去的實體按鈕, 資訊列拆成浮在畫面上的白色膠囊; 選中 = 整格變黃放大 + 上方彈跳箭頭, 錢不夠 = 動作鈕變灰扁平(按不下去)+ 頂上冒紅色「差 N」膠囊。
